6.2 Give the counter its own place

Beacons along a track are numbered from zero. You need to visit each one exactly once and stop after the last. The counter for this traversal has three parts that are useful to see together.

Start, test, step

Open 06-loops/P03_Example_BeaconWalk.java. Enter a count of 3.

/// # Worked example · 6.2 Give the counter its own place
/// Lesson: 02-for.html

void main() {
    int count = Integer.parseInt(IO.readln("Count: ").strip());
    for (int index = 0; index < count; index++) {
        IO.println("Beacon " + index);
    }
    IO.println("Done");
}

A for loop starts by creating the local variable index. Its middle part tests whether to continue. Its final part advances the counter after each completed body. Two semicolons in the header separate these three parts; they are not three statements inside the body.

The notation index++ adds one. It does not happen before the first print. With count equal to 3, the program therefore prints beacons 0, 1 and 2. Once index becomes 3, the test fails. The less-than sign matters: we want three visits, not a visit to number 3.

A counter created in the header belongs only to that loop. You cannot use it after the closing brace. The count can be zero: the body is skipped, and the program still prints Done. Use counts from 0 to 8 for these experiments.

Prediction: count is 1

There is just one line, Beacon 0, followed by Done. The first test reads index 0; one is added only after printing.

Task: descend from the tower

Open 06-loops/P04_Task_TowerDescent.java. The program knows the height you entered but announces only the top floor. Use for to print every floor from that height down to 1, followed by Ground. Give each floor its own line.

For height 3, expect Floor 3, Floor 2, Floor 1, Ground. For 1, print only Floor 1 and Ground. For 0, no floor is visited. Try whole-number heights from 0 to 8. Do not copy lines by hand for a particular input.

Hint 1: the counter's direction

This time, the start is not zero. After each visit, you need a lower number rather than a higher one.

Hint 2: include the last floor

One still belongs in the body; zero does not. The notation floor-- subtracts one after the body finishes.

So far, the counter only controls the order of visits. Next, you will add another variable that remembers a sum or a count of things found between rounds.
