6.1 Repeat while needed

A drone has an empty battery. Each charging step adds two units and prints the new level. Instead of copying the same step several times, describe when it should keep going.

A question before every round

Open 06-loops/P01_DroneCharge.java. First predict how many lines it will print.

void main() {
    int energy = 0;
    while (energy < 6) {
        energy = energy + 2;
        IO.println("Energy: " + energy);
    }
    IO.println("Ready");
}

A while loop repeats the body between its braces while the condition in parentheses is true. It asks the question before the first round and after every completed round. With energy 0, the first test passes: the value becomes 2 and is printed. The next rounds produce 4 and 6. Now 6 is no longer less than 6, so execution continues after the loop.

The assignment inside the body changes the value that the next test will read. Without it, energy would stay at zero and create an infinite loop. If this happens during an experiment, stop the running program with the Stop button in Output. The condition does not advance the value by itself.

Prediction: what if you start at 6?

The body never runs. You see only Ready. While does not promise at least one round: it asks first.

Task: the countdown voice speaks only once

Open 06-loops/P02_LaunchCount.java. For input 3, it currently says only 3 and Launch. Replace the single step with repetition: print every positive number from the starting value down to 1. Once the countdown is over, print Launch exactly once.

Try starting values from 0 to 9. For 3, you need the lines 3, 2, 1, Launch. For 1, print 1, Launch. For 0, print only Launch; do not include zero in the countdown. Keep the Start prompt unchanged.

Hint 1: what repeats?

Printing the current number and reducing it belong in the same body. The final Launch should not repeat.

Hint 2: follow the last round

After printing 1, the value must become zero. The next test rejects it. Write down the values before the test and after the change.

In the next lesson, you will write a counter loop in a more compact form. The principle stays the same: a start, a question, some work, and a step forward.
