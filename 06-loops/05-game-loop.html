6.5 Čti další tah

Jedna otázka nestačí pro hru na povely. Terminál má opakovaně přečíst řádek, zpracovat ho a ukázat výsledek. Hráč musí mít také jasný způsob, jak skončit.

Čtení uvnitř opakování

Otevři 06-loops/P10_Example_EchoTerminal.java. Zadej ping, potom něco jiného a nakonec q. Každou odpověď potvrď Enter.

/// # Hotový příklad · 6.5 Čti další tah
/// Lekce: 05-game-loop.html

void main() {
    while (true) {
        String command = IO.readln("Command: ");
        if (command == null || command.equals("q")) {
            break;
        }
        if (command.equals("ping")) {
            IO.println("pong");
        } else {
            IO.println("Unknown");
        }
    }
    IO.println("Closed");
}

Zápis while s true dovoluje další kolo vždy. Cestu ven poskytuje break při povelu q. Čtení je uvnitř těla: každé kolo dostane nový řádek. Čtení pouze před cyklem by stále zpracovávalo tutéž odpověď.

Volání readln může vrátit null, pokud vstup skončil bez dalšího řádku. Není to text ani prázdný řádek. Nejprve testujeme command == null; díky short-circuit evaluation (zkrácenému vyhodnocení) se pak na null nevolá equals. Při q i při konci vstupu se opakování ukončí a vypíše se Closed.

Předpověď: prázdný řádek a potom q

Prázdný řádek není konec vstupu. Nejprve dostaneš Unknown, další výzvu a po q Closed. Shoda povelů je zde přesná: PING není ping.

Úkol: ovladač malého dronu

Otevři 06-loops/P11_Task_DroneConsole.java. Smyčka i ukončení fungují, ale up a down nemění výšku. Doplň tato pravidla: up zvýší výšku o 1, down ji o 1 sníží. Výška nesmí opustit rozsah 0 až 3.

Po platném pohybu vypiš Altitude s novou hodnotou. Pokus za hranici vypíše Blocked a výšku nezmění. Jiný povel vypíše Unknown. Q není q a patří mezi neznámé povely; malé q skončí výpisem Landed bez další výšky. Konec vstupu ukonči stejně.

Vyzkoušej up, up, down, q: výšky budou 1, 2, 1. Při down hned na začátku čekej Blocked. Čtyři up za sebou mají dát 1, 2, 3, Blocked. Jedna proměnná altitude musí uchovávat stav mezi koly.

Nápověda 1: odděl pravidla

Nejdřív je připravený konec. Pak rozliš známý směr a ověř jeho hranici. Neznámý povel nesmí měnit stav.

Nápověda 2: výsledek kroku

Úspěšný pohyb mění výšku před výpisem. Odmítnutý pohyb vypíše jen Blocked, ne Altitude.

V další kapitole uložíš více hodnot vedle sebe. Cyklus pak nebude čekat na nový vstup, ale navštíví jednotlivá místa připravených dat.
