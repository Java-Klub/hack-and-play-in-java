13.4 Posouvej simulaci po malých krocích

Spusť MovingDot a stiskni Start / Restart. Tečka jede doprava až ke své mezi. Program žádá Swing o krátkou změnu každých dvacet milisekund; nekreslí uvnitř nekonečné vytěžující smyčky.

import java.awt.*;
import java.awt.image.BufferedImage;
import javax.swing.*;
import javax.swing.Timer;
import java.awt.event.WindowAdapter;
import java.awt.event.WindowEvent;

double x = 20;

void step(double seconds) {
    if (seconds < 0) throw new IllegalArgumentException("Negative time.");
    x = Math.min(180, x + 80 * seconds);
}

void draw(Graphics2D g) {
    g.setColor(Color.BLUE);
    g.fillOval((int) Math.round(x) - 8, 22, 16, 16);
}

void main() {
    SwingUtilities.invokeLater(() -> {
        var panel = new JPanel() {
            @Override protected void paintComponent(Graphics graphics) {
                super.paintComponent(graphics);
                draw((Graphics2D) graphics);
            }
        };
        panel.setPreferredSize(new Dimension(200, 60));
        panel.setBackground(Color.WHITE);
        var timer = new Timer(20, event -> {
            step(0.02);
            panel.repaint();
            if (x >= 180) ((Timer) event.getSource()).stop();
        });
        var play = new JButton("Start / Restart");
        play.addActionListener(event -> {
            x = 20;
            panel.repaint();
            timer.start();
        });
        var frame = new JFrame("Moving Dot");
        frame.setDefaultCloseOperation(JFrame.DISPOSE_ON_CLOSE);
        frame.add(panel);
        frame.add(play, BorderLayout.SOUTH);
        frame.addWindowListener(new WindowAdapter() {
            @Override public void windowClosed(WindowEvent event) {
                timer.stop();
            }
        });
        frame.pack();
        frame.setLocationByPlatform(true);
        frame.setVisible(true);
    });
}

Výslovný import Timer vybírá javax.swing.Timer. Jeho callback běží na EDT, takže může bezpečně změnit tento malý model a požádat o repaint. Zavření okna časovač zastaví; dosažení konce jej zastaví také.

Rychlost je osmdesát obrazových bodů za sekundu. Krok 0,02 sekundy proto přidá 1,6 bodu. X uchovávej jako double a zaokrouhli teprve při kreslení. Zaokrouhlení každé změny na celé číslo by složilo jiný pohyb.

Zpoždění časovače je požadavek plánovači, nikoli přesné hodiny. Příklad záměrně posouvá simulaci o pevných 0,02 sekundy při každém callback. Zpožděné volání nechá simulaci za skutečným časem; skutečné trvání automaticky nedostane.

Předpověz jiný krok

Z počátečního x=20 dojde step(0.5) na 60 a další step(0.25) na 80. Jaká pozice následuje po step(10)?

Omezení dá 180. Krok je vstup simulace a lze jej vyzkoušet bez čekání na časovač.

Úkol: počítej sekundy, nikoli callback

Oprav step v code/CountdownLamp.java. Odečti předané seconds od remaining, výsledek omez zdola nulou a záporné trvání odmítni zprávou Negative time. ještě před změnou stavu.

Ze tří sekund musí změny 0,25 a 0,75 nechat dvě. Pozdější desetisekundový krok nechá nulu, nikoli záporný pruh. Opakované Start / Restart obnoví tři; zavření okna musí ukončit jeho časovač.

Nápověda 1: čti jednotku

Callback předává trvání. Jedno volání nemusí znamenat jednu sekundu.

Nápověda 2: omez až po odečtení

Použij Math.max s nulou a vypočteným zbytkem. Kontrolu záporného vstupu nech před výpočtem.

Úhly a uplynulý čas v jiných obrázcích
double angle = Math.toRadians(degrees);
int px = (int) Math.round(cx + radius * Math.cos(angle));
int py = (int) Math.round(cy + radius * Math.sin(angle));

sin a cos přijímají radians (radiány); celá otáčka má 2π radiánů. Na obrazovce kladné y míří dolů. Animace skutečného času může měřit uplynulé sekundy přes System.nanoTime, simulace s pevným krokem může zpoždění dohnat několika omezenými změnami. Na EDT nikdy nepoužívej sleep.

Vyzkoušej pravidlo přímo a potom vrať okno

Okno předává pevné kroky po 0,1 sekundě. Pro vyzkoušení jiných trvání bez čekání si uschovej původní main v dočasném textovém dokumentu a nahraď pouze tuto metodu konzolovým pokusem. Step, draw, uložené hodnoty i import nech na místě.

void main() {
    step(0.25);
    IO.println(remaining);
    step(0.75);
    IO.println(remaining);
    step(10);
    IO.println(remaining);
    try {
        step(-1);
    } catch (IllegalArgumentException failure) {
        IO.println(failure.getMessage());
    }
    IO.println(remaining);
}

Očekávej 2.75, 2.0 a 0.0, potom zprávu Negative time a nezměněnou 0.0. Následně obnov uschované GUI main, ulož a znovu spusť. Pokus zkoumá stejnou metodu step, kterou používá časovač.

Dále odděl změny od kreslení, aby samotné překreslení nemohlo náhodně posunout kolo.
