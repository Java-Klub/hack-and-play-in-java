Slovníček prvních zápisů

Vrať se sem jen pro zápis, kterému právě nerozumíš. Příklady a úkoly najdeš v jednotlivých lekcích.

Zápis nebo pojem Co znamená
.java Koncovka souboru se zdrojovým kódem Javy.
void main() Akce, kterou Java u našich prvních programů při spuštění zahájí.
{ } Hranice block (bloku) kódu. Kroky uvnitř tvoří jeden celek.
() Za názvem akce ohraničují argumenty, tedy předávané hodnoty. V jejím popisu vymezují seznam vstupů; prázdné závorky žádné neuvádějí.
; Ukončení statement (příkazu), například výpisu nebo přiřazení.
IO.println(...) Call (volání) připravené akce, která vypíše předanou hodnotu a ukončí řádek.
"text" String literal (textový literál). Uvozovky jsou hranice zápisu a nevypisují se.
// nebo /// Začátek komentáře do konce řádku; Java jeho slova neprovádí.
Variable (proměnná) Pojmenované místo pro hodnotu určitého typu.
int Type (typ) pro celá čísla v rozsahu −2147483648 až 2147483647.
double Číselný typ, který umožňuje desetinnou část; některé hodnoty uchovává přibližně.
String Typ pro textovou hodnotu.
= Assignment (přiřazení): nejprve vypočítej pravou stranu, potom její hodnotu ulož pod jméno vlevo.
Expression (výraz) Zápis, který poskytne hodnotu, například energy - 2.
+ Sčítání čísel nebo spojování textu podle použitých hodnot.
-, *, /, % Odčítání, násobení, dělení a zbytek po dělení.
Compiler (překladač) Část JDK, která ověřuje zápis programu a převádí jej do podoby pro spuštění.
Compiler error (chyba překladu) Hlášení, že překladač nemůže zapsaný kód přijmout.
GREEN / RED Výsledek funkční kontroly hry: ověřované případy souhlasí / některý zatím nesouhlasí.
IO.readln("Question: ")Vypíše otázku, počká na Enter a poskytne celý zadaný řádek jako text.
""Prázdný String: text bez znaků.
strip()Poskytne text bez mezer a dalších bílých znaků na krajích. Vnitřní mezery zachová.
toUpperCase(Locale.ROOT)Poskytne text velkými písmeny podle pravidel nezávislých na regionálním nastavení.
replace(target, replacement)Poskytne text se všemi přesnými výskyty hledaného textu nahrazenými. Původní hodnotu nemění.
returnVrátí hodnotu z akce tomu, kdo ji zavolal.
\" / \nEscape sequences (řídicí posloupnosti): zápis uvozovky uvnitř textu a přechodu na nový řádek.
Integer.parseInt(text)Převede text se zápisem celého čísla na hodnotu typu int.
NumberFormatExceptionHlášení, že zadaný text nelze převést na požadované číslo.
boolean, true, falseTyp s hodnotami ano a ne; nejsou to texty v uvozovkách.
<, >, <=, >=Porovnání čísel; znaménko = navíc zahrnuje rovnost.
== / !=Číselná rovnost a nerovnost. U objektů == zjišťuje totožnost odkazu.
equals / equalsIgnoreCasePorovnání textového obsahu; druhá varianta ignoruje velikost písmen.
if / else if / elseVýběr větve podle boolean výsledku. V jednom řetězci se provede nejvýše jedna větev.
&& / || / !AND (zároveň), OR (alespoň jedna možnost), NOT (opačná boolean hodnota).
return;Ukončí volání akce označené void; nevrací hodnotu.
Guard clauseVčasné odmítnutí před provedením chráněné operace.
switch / case / default / ->Výběr výsledku podle hodnoty. Default určuje zbývající případy; šipka vede k výsledku.
toLowerCase(Locale.ROOT)Poskytne text malými písmeny podle pravidel nezávislých na regionálním nastavení.
