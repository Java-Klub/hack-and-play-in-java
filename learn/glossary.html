Glossary of your first Java notation

Return here for just the notation you do not understand yet. You will find examples and tasks in the individual lessons.

Notation or term What it means
.java The filename extension for a Java source file.
void main() The action Java starts when you run our first programs.
{ } The boundaries of a code block. The steps inside belong together.
() After an action's name, they enclose arguments: the values passed to it. In its declaration, they enclose the input list; empty parentheses list no inputs.
; The end of a statement, such as printing or assignment.
IO.println(...) A call to a supplied action that prints the passed value and ends the line.
"text" A String literal. The quotes mark its boundaries and are not printed themselves.
// or /// The beginning of a comment that continues to the end of the line; Java does not execute its words.
Variable A named place for a value of a particular type.
int A type for whole numbers from −2147483648 to 2147483647.
double A numeric type that allows a fractional part; some values are stored approximately.
String The type for a text value.
= Assignment: calculate the right-hand side first, then store its value under the name on the left.
Expression Notation that provides a value, such as energy - 2.
+ Adds numbers or joins text, depending on the values used.
-, *, /, % Subtraction, multiplication, division and remainder.
Compiler The part of the JDK that checks how a program is written and converts it into a form that can run.
Compiler error A message saying the compiler cannot accept the code as written.
GREEN / RED The result of a game's functional checks: the checked cases agree / at least one does not agree yet.

The glossary does not contain complete game solutions. For a particular task, use its instructions and progressive hints.
