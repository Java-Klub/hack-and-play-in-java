Slovníček prvních zápisů

Vrať se sem jen pro zápis, kterému právě nerozumíš. Příklady a úkoly najdeš v jednotlivých lekcích.

Zápis nebo pojem Co znamená
.java Koncovka souboru se zdrojovým kódem Javy.
void main() Akce, kterou Java u našich prvních programů při spuštění zahájí.
{ } Hranice block (bloku) kódu. Kroky uvnitř tvoří jeden celek.
() Za názvem akce ohraničují argumenty, tedy předávané hodnoty. V jejím popisu vymezují seznam vstupů; prázdné závorky žádné neuvádějí.
; Ukončení statement (příkazu), například výpisu nebo přiřazení.
IO.println(...) Call (volání) připravené akce, která vypíše předanou hodnotu a ukončí řádek.
"text" String literal (textový literál). Uvozovky jsou hranice zápisu a nevypisují se.
// nebo /// Začátek komentáře do konce řádku; Java jeho slova neprovádí.
Variable (proměnná) Pojmenované místo pro hodnotu určitého typu.
int Type (typ) pro celá čísla v rozsahu −2147483648 až 2147483647.
double Číselný typ, který umožňuje desetinnou část; některé hodnoty uchovává přibližně.
String Typ pro textovou hodnotu.
= Assignment (přiřazení): nejprve vypočítej pravou stranu, potom její hodnotu ulož pod jméno vlevo.
Expression (výraz) Zápis, který poskytne hodnotu, například energy - 2.
+ Sčítání čísel nebo spojování textu podle použitých hodnot.
-, *, /, % Odčítání, násobení, dělení a zbytek po dělení.
Compiler (překladač) Část JDK, která ověřuje zápis programu a převádí jej do podoby pro spuštění.
Compiler error (chyba překladu) Hlášení, že překladač nemůže zapsaný kód přijmout.
GREEN / RED Výsledek funkční kontroly hry: ověřované případy souhlasí / některý zatím nesouhlasí.
IO.readln("Question: ")Vypíše otázku, počká na Enter a poskytne celý zadaný řádek jako text.
""Prázdný String: text bez znaků.
strip()Poskytne text bez mezer a dalších bílých znaků na krajích. Vnitřní mezery zachová.
toUpperCase(Locale.ROOT)Poskytne text velkými písmeny podle pravidel nezávislých na regionálním nastavení.
replace(target, replacement)Poskytne text se všemi přesnými výskyty hledaného textu nahrazenými. Původní hodnotu nemění.
returnVrátí hodnotu z akce tomu, kdo ji zavolal.
\" / \nEscape sequences (řídicí posloupnosti): zápis uvozovky uvnitř textu a přechodu na nový řádek.
Integer.parseInt(text)Převede text se zápisem celého čísla na hodnotu typu int.
NumberFormatExceptionHlášení, že zadaný text nelze převést na požadované číslo.
boolean, true, falseTyp s hodnotami ano a ne; nejsou to texty v uvozovkách.
<, >, <=, >=Porovnání čísel; znaménko = navíc zahrnuje rovnost.
== / !=Číselná rovnost a nerovnost. U objektů == zjišťuje totožnost odkazu.
equals / equalsIgnoreCasePorovnání textového obsahu; druhá varianta ignoruje velikost písmen.
if / else if / elseVýběr větve podle boolean výsledku. V jednom řetězci se provede nejvýše jedna větev.
&& / || / !AND (zároveň), OR (alespoň jedna možnost), NOT (opačná boolean hodnota).
return;Ukončí volání akce označené void; nevrací hodnotu.
Guard clauseVčasné odmítnutí před provedením chráněné operace.
switch / case / default / ->Výběr výsledku podle hodnoty. Default určuje zbývající případy; šipka vede k výsledku.
toLowerCase(Locale.ROOT)Poskytne text malými písmeny podle pravidel nezávislých na regionálním nastavení.
Method (metoda)Pojmenovaná část programu. Definice popisuje její tělo; volání požádá o provedení.
Parameter (parametr)Lokální jméno a typ přijaté hodnoty v definici metody.
ArgumentKonkrétní hodnota nebo výraz předaný při volání.
Return type (návratový typ)Typ výsledku, který metoda slibuje vrátit; void znamená, že výslednou hodnotu neposkytuje.
Scope (oblast platnosti)Část kódu, ve které lze použít dané jméno.
Composition (skládání)Propojení menších metod: výsledek jedné může být argumentem další.
Refactoring (úprava struktury)Změna uspořádání kódu při zachování jeho pozorovatelného chování.
Loop (cyklus)Opakované provádění těla, dokud platí pokračovací podmínka.
for / whileDva zápisy opakování: for sdružuje inicializaci, podmínku a posun; while zdůrazňuje podmínku.
++ / -- / +=Přičtení jedné, odečtení jedné a přiřazení součtu k původní hodnotě.
break / continueUkonči nejbližší smyčku / přeskoč zbytek tohoto průchodu.
nullHodnota, která neodkazuje na žádný objekt. Není totéž co prázdný text.
Array (pole)Pevný počet indexovaných míst stejného typu; první index je nula.
length / length() / size()Počet míst pole / počet jednotek textu / počet prvků kolekce.
char / charAt(index)Typ jedné jednotky textu / její přečtení ze zvolené pozice.
Snapshot (snímek)Uchovaná podoba stavu. U měnitelných dat vyžaduje nezávislou kopii potřebných částí.
Record (datový záznam)Vlastní datový typ s pojmenovanými složkami, čtecími metodami a odvozenou rovností.
new / accessorVytvoření objektu / metoda pro přečtení jeho dat.
Reference (odkaz)Hodnota umožňující dosáhnout na objekt; dvě proměnné mohou označovat stejný objekt.
Enum (výčtový typ)Pevně pojmenovaná rodina možností, například směrů nebo fází hry.
List / Set / MapUspořádaná posloupnost / jedinečné prvky / hodnoty vyhledávané podle klíče.
Generic type (generický typ)Typ s upřesněním prvků, například List<String> pro seznam textů.
Lambda (lambda výraz)Krátký zápis chování předávaného jiné operaci, například porovnání nebo reakce na kliknutí.
ComparatorPravidlo porovnání dvou hodnot pro řazení; záporný výsledek řadí první před druhou.
StreamPostup zpracování posloupnosti: filter vybírá, map převádí, koncová operace vyžádá výsledek.
Instance / field (instance / datové pole)Konkrétní objekt / jeho uložený stav, dostupný i mezi voláními metod.
InvariantPravidlo, které musí platit před i po každé přijaté změně stavu.
SeedPočáteční hodnota pseudonáhodného generátoru. Stejný seed a stejné pořadí volání umožní pokus zopakovat.
Exception (výjimka)Signál, že běžné dokončení operace selhalo. Catch může vybraný druh zachytit; throws deklaruje možnost předání volajícímu.
Path / FilesPopis cesty / připravené operace pro čtení a zápis souborů.
Try-with-resourcesBlok, který po dokončení nebo selhání uzavře otevřené prostředky, například souborový stream.
Event handler (obsluha události)Kód zavolaný při konkrétní události; jeho vytvoření samo ještě událost neprovede.
EDTVlákno obsluhy událostí Swing. Vytváří a mění okna; dlouhý výpočet nebo čekání jej zablokuje.
Tick / repaintJeden krok aktualizace modelu / požadavek na nové vykreslení jeho stavu.
Interface (rozhraní)Dohoda o nabízených operacích, kterou mohou splnit různé implementace.
Sealed typeTyp s uzavřenou rodinou povolených přímých variant.
Record patternRozpoznání druhu záznamu a pojmenování jeho složek pro vybranou větev.
Recursion (rekurze)Řešení menšího případu opětovným voláním stejné metody; potřebuje konečný základní případ.
BacktrackingProzkoumání volby a návrat k místu rozhodnutí před vyzkoušením další možnosti.
