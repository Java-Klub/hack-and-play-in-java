Glossary of your first Java notation

Return here for just the notation you do not understand yet. You will find examples and tasks in the individual lessons.

Notation or term What it means
.java The filename extension for a Java source file.
void main() The action Java starts when you run our first programs.
{ } The boundaries of a code block. The steps inside belong together.
() After an action's name, they enclose arguments: the values passed to it. In its declaration, they enclose the input list; empty parentheses list no inputs.
; The end of a statement, such as printing or assignment.
IO.println(...) A call to a supplied action that prints the passed value and ends the line.
"text" A String literal. The quotes mark its boundaries and are not printed themselves.
// or /// The beginning of a comment that continues to the end of the line; Java does not execute its words.
Variable A named place for a value of a particular type.
int A type for whole numbers from −2147483648 to 2147483647.
double A numeric type that allows a fractional part; some values are stored approximately.
String The type for a text value.
= Assignment: calculate the right-hand side first, then store its value under the name on the left.
Expression Notation that provides a value, such as energy - 2.
+ Adds numbers or joins text, depending on the values used.
-, *, /, % Subtraction, multiplication, division and remainder.
Compiler The part of the JDK that checks how a program is written and converts it into a form that can run.
Compiler error A message saying the compiler cannot accept the code as written.
GREEN / RED The result of a game's functional checks: the checked cases agree / at least one does not agree yet.
IO.readln("Question: ")Prints a question, waits for Enter and provides the whole entered line as text.
""An empty String: text with no characters.
strip()Provides text with edge spaces and other whitespace removed. Keeps internal spaces.
toUpperCase(Locale.ROOT)Provides uppercase text using rules independent of regional settings.
replace(target, replacement)Provides text with all exact occurrences of the target replaced. Leaves the original value unchanged.
returnGives a value back from an action to its caller.
\" / \nEscape sequences: notation for a quote inside text and a new line.
Integer.parseInt(text)Converts text representing a whole number into an int value.
NumberFormatExceptionReports that the entered text cannot be converted to the required number.
boolean, true, falseA type with yes and no values; these are not quoted text.
<, >, <=, >=Number comparisons; adding = includes equality.
== / !=Numeric equality and inequality. For objects, == checks reference identity.
equals / equalsIgnoreCaseText-content comparison; the second version ignores letter case.
if / else if / elseSelects a branch from a boolean result. At most one branch runs in one chain.
&& / || / !AND (both), OR (at least one), NOT (the opposite boolean value).
return;Ends an action declared void; no value is returned.
Guard clauseAn early rejection before a protected operation.
switch / case / default / ->Selects a result from a value. Default covers remaining cases; the arrow leads to the result.
toLowerCase(Locale.ROOT)Provides lowercase text using rules independent of regional settings.
MethodA named part of a program. Its definition describes its body; a call asks it to run.
ParameterA local name and type for a received value in a method definition.
ArgumentAn actual value or expression supplied in a call.
Return typeThe type of result a method promises to return; void means it provides no result value.
ScopeThe part of the code where a name can be used.
CompositionConnecting smaller methods: one result can become another method’s argument.
RefactoringChanging the structure of code while preserving its observable behaviour.
LoopRepeated execution of a body while its continuation condition holds.
for / whileTwo repetition forms: for groups initialisation, condition and progress; while emphasises the condition.
++ / -- / +=Add one, subtract one, and assign a sum back to the original variable.
break / continueEnd the nearest loop / skip the rest of this pass.
nullA value that refers to no object. It is different from empty text.
ArrayA fixed number of indexed slots of one type; the first index is zero.
length / length() / size()Array slot count / text unit count / collection element count.
char / charAt(index)The type of one text unit / reading it at a selected position.
SnapshotA preserved version of state. Mutable data needs independent copies of the relevant parts.
RecordA data type with named components, accessors and derived equality.
new / accessorCreating an object / a method that reads its data.
ReferenceA value that reaches an object; two variables can refer to the same object.
EnumA fixed named family of choices, such as directions or game phases.
List / Set / MapAn ordered sequence / unique elements / values found by key.
Generic typeA type with specified element types, such as List<String> for a list of text.
LambdaA short expression for behaviour passed to another operation, such as comparison or a click response.
ComparatorA comparison rule for sorting two values; a negative result orders the first before the second.
StreamA sequence-processing pipeline: filter selects, map transforms, and a terminal operation requests the result.
Instance / fieldA particular object / its stored state, available between method calls.
InvariantA rule that must hold before and after every accepted state change.
SeedAn initial pseudorandom-generator value. The same seed and call sequence let an experiment be repeated.
ExceptionA signal that normal completion failed. Catch can handle a selected kind; throws declares that it may reach the caller.
Path / FilesA path description / supplied operations for reading and writing files.
Try-with-resourcesA block that closes opened resources, such as file streams, after completion or failure.
Event handlerCode called for a particular event; creating it does not itself perform the event.
EDTSwing's event-dispatch thread. It creates and updates windows; long calculations or waiting block it.
Tick / repaintOne model-update step / a request to redraw its state.
InterfaceAn agreement about offered operations that different implementations can fulfil.
Sealed typeA type with a closed family of permitted direct variants.
Record patternMatching a record kind and naming its components inside the selected branch.
RecursionSolving a smaller case by calling the same method again; it needs a terminating base case.
BacktrackingExploring a choice and returning to the decision point before trying another possibility.
