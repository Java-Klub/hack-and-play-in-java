13.4 Advance a simulation in small steps

Run MovingDot and press Start / Restart. A dot moves right until it reaches its limit. The program asks Swing for a short update every twenty milliseconds rather than drawing inside an endless busy loop.

import java.awt.*;
import java.awt.image.BufferedImage;
import javax.swing.*;
import javax.swing.Timer;
import java.awt.event.WindowAdapter;
import java.awt.event.WindowEvent;

double x = 20;

void step(double seconds) {
    if (seconds < 0) throw new IllegalArgumentException("Negative time.");
    x = Math.min(180, x + 80 * seconds);
}

void draw(Graphics2D g) {
    g.setColor(Color.BLUE);
    g.fillOval((int) Math.round(x) - 8, 22, 16, 16);
}

void main() {
    SwingUtilities.invokeLater(() -> {
        var panel = new JPanel() {
            @Override protected void paintComponent(Graphics graphics) {
                super.paintComponent(graphics);
                draw((Graphics2D) graphics);
            }
        };
        panel.setPreferredSize(new Dimension(200, 60));
        panel.setBackground(Color.WHITE);
        var timer = new Timer(20, event -> {
            step(0.02);
            panel.repaint();
            if (x >= 180) ((Timer) event.getSource()).stop();
        });
        var play = new JButton("Start / Restart");
        play.addActionListener(event -> {
            x = 20;
            panel.repaint();
            timer.start();
        });
        var frame = new JFrame("Moving Dot");
        frame.setDefaultCloseOperation(JFrame.DISPOSE_ON_CLOSE);
        frame.add(panel);
        frame.add(play, BorderLayout.SOUTH);
        frame.addWindowListener(new WindowAdapter() {
            @Override public void windowClosed(WindowEvent event) {
                timer.stop();
            }
        });
        frame.pack();
        frame.setLocationByPlatform(true);
        frame.setVisible(true);
    });
}

The explicit Timer import selects javax.swing.Timer. Its callback runs on the EDT, so it can update this small model and request repaint safely. Closing the window stops the timer; reaching the end also stops it.

Speed is eighty pixels per second. A step of 0.02 seconds therefore adds 1.6 pixels. Keep x as a double and round only for drawing. Rounding each update to an integer would accumulate a different movement.

A timer delay is a scheduling request, not a precise clock. This example intentionally advances a fixed 0.02 seconds per callback. A delayed callback makes the simulation lag behind real time; it does not secretly receive the elapsed duration.

Predict a different step

Starting at x=20, step(0.5) reaches 60; another step(0.25) reaches 80. What position follows step(10)?

The cap gives 180. A step is a simulation input and can be tried without waiting for a timer.

Task: count seconds rather than callbacks

Repair step in learn/practice/13/CountdownLamp.java. Subtract the supplied seconds from remaining, clamp the result at zero, and reject a negative duration with Negative time. before changing state.

From three seconds, updates of 0.25 and 0.75 must leave two. A later ten-second step leaves zero, not a negative bar. Repeated Start / Restart restores three; closing the window must finish its timer.

Hint 1: read the unit

The callback passes a duration. One callback does not necessarily mean one second.

Hint 2: clamp after subtraction

Use Math.max with zero and the computed remainder. Keep the negative-input guard before it.

Angles and elapsed time in other pictures
double angle = Math.toRadians(degrees);
int px = (int) Math.round(cx + radius * Math.cos(angle));
int py = (int) Math.round(cy + radius * Math.sin(angle));

sin and cos take radians; a full turn is 2π radians. On a screen positive y points down. A real-time animation can measure elapsed seconds with System.nanoTime, while a fixed-step simulation can make several bounded updates to catch up. Never sleep on the EDT.

Try the rule directly, then restore the window

The window supplies fixed 0.1-second steps. To test other durations without waiting, keep the original main in a temporary text document and replace only that method with this console experiment. Leave step, draw, fields and imports intact.

void main() {
    step(0.25);
    IO.println(remaining);
    step(0.75);
    IO.println(remaining);
    step(10);
    IO.println(remaining);
    try {
        step(-1);
    } catch (IllegalArgumentException failure) {
        IO.println(failure.getMessage());
    }
    IO.println(remaining);
}

Expect 2.75, 2.0 and 0.0, then the Negative time message and unchanged 0.0. Restore the saved GUI main afterwards, save and run again. This tests the same step method used by the timer.

Next separate updates from drawing so that a repaint can never advance a round by accident.
