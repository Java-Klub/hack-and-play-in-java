12.5 Ukládej až po ověření

Uložená poznámka má nahradit vybranou poznámku, nikoli jiný soubor s podobným jménem. Pracuj v pokusné složce. Následující program při přijetí nového textu záměrně nahradí note.txt.

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;

void saveNote(Path destination, String note) throws IOException {
    if (note.isBlank()) {
        throw new IllegalArgumentException("A note needs text.");
    }
    Files.writeString(destination, note.strip() + "\n");
}

void main() {
    String reply = IO.readln("Note: ");
    if (reply == null) return;
    try {
        Path destination = Path.of("note.txt");
        saveNote(destination, reply);
        IO.println("Saved " + destination.toAbsolutePath() + ".");
    } catch (IllegalArgumentException failure) {
        IO.println(failure.getMessage());
    } catch (IOException failure) {
        IO.println("Cannot save note.txt.");
    }
}

Files.writeString chybějící soubor vytvoří a existujícímu nahradí obsah. Výchozí kódování textu je UTF-8. Přidaný konec řádku vytvoří běžný jednořádkový soubor. Ke staré poznámce nic nepřipojuje.

Ověření běží před zápisem. Prázdná odpověď vyhodí výjimku dříve, než se program dotkne cíle, a předchozí poznámka zamítnutí přežije. Úspěšný návrat znamená dokončený zápis; teprve pak main vytiskne Saved a absolutní cestu, podle níž soubor najdeš.

Nejde o záruku atomic replacement (nedělitelného nahrazení): skutečné selhání během zápisu může zanechat částečný soubor. Důležité dokumenty potřebují opatrnější zápis do dočasného souboru a následné nahrazení. Zde chráníme proti chybným hodnotám ještě před otevřením výstupu.

Předpověz odmítnuté nahrazení

Když note.txt obsahuje Old note, prázdná odpověď vypíše A note needs text. a obsah zachová. Odpověď New note jej nahradí textem New note a jedním koncem řádku.

Úkol: ulož skóre do zvoleného cíle

Oprav saveScore v learn/practice/12/ScoreFile.java. Přijmi pouze skóre od nuly do 999. Jiné celé číslo odmítni zprávou Score must be 0..999. ještě před zápisem. Použij předaný destination, nikoli pevné jméno souboru.

Zkus uložit 17 do round.txt a potom jej nahraď nulou. Zamítnutá −1 musí předchozí soubor zachovat. Překlep nesmí soubor vytvořit. Absolutní cíl vypsaný po úspěchu se musí shodovat se souborem, který se skutečně změnil. Při prohlížení uloženého textu otevři právě tuto cestu.

Nápověda 1: ověřuj před účinky

Kontrolu rozsahu dej před writeString. Pozdější výjimka nedokáže vrátit dřívější zápis.

Nápověda 2: Path už máš

Předej destination přímo do writeString a zachovej konec řádku za číselným skóre.

Obrázky a proudy mají stejná pravidla vlastnictví

ImageIO přečte podporovaný obrázek do obrazových bodů a zapíše je ve zvoleném formátu. Čtení může vrátit null, pokud soubor nerozpozná žádný decoder (dekodér); zápis může vrátit false, pokud formát nepodporuje žádný writer (zapisovač). To je jiné než IOException a vyžaduje samostatné ověření.

java.awt.image.BufferedImage readPicture(Path source) throws IOException {
    var image = javax.imageio.ImageIO.read(source.toFile());
    if (image == null) throw new IOException("Unsupported image.");
    return image;
}

void writePicture(java.awt.image.BufferedImage image,
        Path destination) throws IOException {
    if (!javax.imageio.ImageIO.write(image, "png", destination.toFile())) {
        throw new IOException("No PNG writer.");
    }
}
Path input = source.toAbsolutePath().normalize();
Path output = destination.toAbsolutePath().normalize();
if (input.equals(output)) {
    throw new IllegalArgumentException("Choose a different output.");
}

ToAbsolutePath vyřeší pracovní složku; normalize upraví složky . a .. v zápisu cesty. Ani jedna operace soubor nezapisuje.

Při zachování originálu odděl source a destination. Před zápisem porovnej jejich normalizované absolutní Path. Try-with-resources uzavře proud, který otevřeš sám; uvedená souborová volání ImageIO si přístup spravují sama. Také audio input stream (vstupní zvukový proud) potřebuje uzavřít, a to i po selhání převodu.

Teď dokážeš uchovat data mezi spuštěními. Dále zobrazíš stav programu přímo v okně Javy.
