3.2 Clean up an incoming signal

The player may enter Red Fox . We do not need the spaces at the edges, but we want to keep the space between the words. We will keep the original message alongside the changed version.

One message, three values

Open learn/examples/03/MessageFilter.java. Before running it, try to predict the last two lines.

void main() {
    String raw = IO.readln("Signal: ");
    String clean = raw.strip();
    String loud = clean.toUpperCase(Locale.ROOT);
    IO.println("Signal [" + loud + "]");
    IO.println("Original [" + raw + "]");
}

Enter two spaces, Red Fox, then two more spaces. The square brackets in the output help you see the edges of the text.

Signal:   Red Fox  
Signal [RED FOX]
Original [  Red Fox  ]
NameStored textWhy
raw" Red Fox "The player's original answer.
clean"Red Fox"strip() removed the spaces at the edges. The space between the words stayed.
loud"RED FOX"toUpperCase(Locale.ROOT) created an uppercase version.

What the dot does

In raw.strip(), the dot selects an operation on the text stored in raw. The empty parentheses say that you supply no extra input. In clean.toUpperCase(Locale.ROOT), the parentheses contain a value: Locale.ROOT is a supplied setting for converting letters independently of the computer's regional settings. Use it this way for this conversion.

A String operation gives you a result. It does not overwrite the original text. That is why each call in the example has its result assigned to a name. A call to raw.strip(); on its own runs, but its result is not kept anywhere.

Task: fix the badge printer

Open learn/practice/03/SignalBadge.java. The code includes a cleaning operation, yet spaces remain in the result.

Keep raw as the original answer. Store the cleaned text in a new variable, convert it to uppercase and use it to print the badge. Also print the original. For this answer, you should get:

Badge:   nOvA  
Badge [NOVA]
Original [  nOvA  ]

Repeat the experiment with Red Fox . Expect RED FOX on the badge and both outer spaces in the original. Do not replace the supplied input with a fixed message in the code.

Hint 1: find the lost result

The right-hand side of an assignment can be a call. Find the supplied line that calls an operation without assigning its result anywhere.

Hint 2: two steps rather than one leap

Store the cleaned text first. Then you can store its uppercase version under the same new name. Leave the original raw alone. Remember: change an existing variable without writing String again.

Try the other order

In MessageFilter, swap the order of the two final print calls. Will their values change, or only their positions? Run it and explain the difference between the order of calculations and the order of printing.

You can now track original text alongside the results of changing it, and spot a discarded result.
