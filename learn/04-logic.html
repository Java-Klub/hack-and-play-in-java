4.3 Spoj pravidla dohromady

Do laboratoře patří dvě různé propustky. Kterákoli z nich stačí, ale zároveň potřebuješ energii a dveře nesmějí být zamčené.

Nebo, zároveň, opak

Otevři learn/examples/04/TwoKeys.java.

void main() {
    String badge = IO.readln("Badge: ").strip();
    int energy = Integer.parseInt(IO.readln("Energy: ").strip());
    boolean trusted = badge.equals("SUN") || badge.equals("MOON");
    boolean enough = energy >= 3;
    boolean locked = false;
    boolean enter = trusted && enough && !locked;
    IO.println("Access: " + enter);
}

Badge: SUN
Energy: 3
Access: true

|| je OR (nebo): stačí alespoň jedna pravdivá strana. && je AND (zároveň): potřebuje obě pravdivé strany. ! je NOT (opak): z true udělá false a naopak.

falsefalsefalsefalse
falsetruefalsetrue
truefalsefalsetrue
truetruetruetrue

Variable trusted odpovídá na jednu otázku o propustce. Variable enough odpovídá na otázku o energii. !locked znamená, že dveře nejsou zamčené. Poslední výraz potřebuje všechny tři souhlasy.

Při míchání OR a AND pomohou závorky nebo pojmenované mezivýsledky, jako trusted. AND má přednost před OR; závorky umožní zvolit vlastní seskupení. Znak OR se píše dvěma svislými čarami, AND dvěma znaky &.

Úkol: najdi falešné povolení

Otevři learn/practice/04/LabPermit.java. Zkus cizí propustku STAR a energii 9. Program jí udělí přístup, i když do laboratoře nepatří.

Oprav pravidla: platná je BLUE nebo GOLD, energie musí být alespoň 3 a locked musí být false. Všechny tři požadavky platí současně. Výsledkem zůstává jeden výpis Access.

Poslední případ ověř dočasnou změnou počáteční hodnoty locked na true ve zdrojáku. Potom ji vrať na false. Tato hodnota se při spuštění nečte z Output.

Nápověda

Odděl „jedna ze dvou propustek“ od „všechny požadavky pro vstup“. Porovnání energie musí přijmout také její nejmenší platnou hodnotu. V posledním výrazu využij opačnou hodnotu locked.

Kdy se druhá otázka vůbec položí

Java vyhodnocuje AND a OR zleva. U A && B po nepravdivém A přeskočí B; výsledek už musí být false. U A || B po pravdivém A přeskočí B; výsledek už musí být true. Říkáme tomu short-circuit evaluation (zkrácené vyhodnocení).

V těle main můžeš vyzkoušet tento malý fragment. Pro nulu nemá dělení smysl, ale druhá otázka se vůbec neprovede:

int pieces = 0;
boolean exact = pieces > 0 && 12 % pieces == 0;
IO.println(exact);

Vypíše se false. S pieces rovnými 3 vyjde true a s 5 false. Obrácení obou otázek by při nule začalo chybným dělením. Pořadí může chránit další výpočet.

Hackni zámek nebo oprav rozhodčího

  • L02/M07_Codebreaker.java: přidej servisní kód podle zadání. Obyčejný správný odhad musí stále fungovat a ostatní špatné odhady zůstat špatné. Hledej otázku rozhodující o výhře; připravenou kontrolu čtyř číslic zachovej.
  • L02/M08_PokerDice.java: full house potřebuje trojici i dvojici. Připravená akce dostane dvě čísla: largestGroup je velikost největší skupiny stejných kostek a pairs počet skupin tvořených právě dvěma kostkami. Z těchto čísel vytvoříš dva boolean výsledky a společný verdikt. Samotná trojice má zůstat levnější výhrou. Pomoc s pravidly hry je přímo v okně Scoring help.

Obě úlohy kontroluje L02/Check.java. V Program Arguments vyber právě řešený soubor.
