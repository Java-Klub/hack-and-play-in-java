4.4 Zastav neplatný tah včas

Hráč zadá cenu tahu. Energii mu chceme odečíst teprve tehdy, když je tah povolený. Odmítnutý pokus má původní energii zachovat.

Nejdřív odmítni, potom měň

Otevři learn/examples/04/EnergyTurn.java. Zkus cenu 0, potom 6 a nakonec 3.

void main() {
    int energy = 5;
    int cost = Integer.parseInt(IO.readln("Move cost: ").strip());
    if (cost < 1) {
        IO.println("Cost must be positive");
        IO.println("Energy: " + energy);
        return;
    }
    if (cost > energy) {
        IO.println("Not enough energy");
        IO.println("Energy: " + energy);
        return;
    }
    energy = energy - cost;
    IO.println("Move accepted");
    IO.println("Energy: " + energy);
}
Move costRozhodnutíEnergie na konci
0Cost must be positive5
6Not enough energy5
3Move accepted2

return; v main okamžitě ukončí toto volání. Proto se po odmítnutí už neprovede odečet ani zpráva o přijetí tahu. Main má v hlavičce void, a tak zde za return nepředáváme žádnou hodnotu.

Takové včasné odmítnutí nazýváme guard clause (ochranná podmínka). Na začátku odstraní zakázané možnosti. Za oběma guards zbývá platný tah, takže můžeš přímo odečíst cenu.

Při každém novém spuštění se energie tohoto malého programu nastaví znovu na 5. Jeden běh provádí jeden pokus.

Úkol: tah je odmítnutý, ale energie zmizela

Otevři learn/practice/04/SafeMove.java. Zadej cenu 6. Program současně oznámí odmítnutí i přijetí a ukáže zápornou energii. Najdi první řádek, kde změnil uložený stav příliš brzy.

Přesuň odečet za rozhodnutí. Odmítni cenu menší než 1 nebo větší než dostupná energie, vypiš Move refused a nezměněnou energii, potom ukonči main. Platný tah odečti a vypiš Move accepted se zbývající energií.

Move cost: 6
Move refused
Energy: 5

Ověř také -1, 0, 1 a 5. Poslední dvě ceny jsou platné a zanechají energii 4 a 0. Záporná cena nesmí energii přidat.

Potom změň počáteční energii na 8 a zadej cenu 6: tah musí projít a nechat energii 2. S cenou 9 musí zůstat všech 8. Nakonec vrať počáteční energii na 5.

Nápověda 1: zpráva nestačí

If provede jen svůj blok. Po jeho konci se pokračuje dalším řádkem. Kde potřebuješ ukončit celé volání, aby se zpráva o přijetí už nevypsala?

Nápověda 2: zachovej původní hodnotu

Porovnávej cenu s energií před odečtem. Do odmítacího bloku patří výpis nezměněné energie. Odečet a obě úspěšné zprávy nechej až za tímto blokem.

Připravená akce může vracet verdikt

V jiné hře neodmítáš celé main, ale jedno volání rozhodčího:

boolean accepts(int cost) {
    if (cost < 1) {
        return false;
    }
    return true;
}

boolean před accepts říká, jaký typ výsledku dostane volající. int cost pojmenovává přijaté číslo. Return false skončí toto jedno volání a předá odmítnutí; celá hra může běžet dál. Podobně může akce s výsledkem int vrátit číslo nebo akce s výsledkem String vrátit zprávu.

Hlídej moře, potom zkus rádce

  • L02/M09_SonarTreasureHunt.java: v okně jsou řádky a sloupce označené 1 až 8. Připravený vstup od každého označení odečte 1 a předá akci insideSea čísla 0 až 7. Opravuješ tuto vnitřní otázku: obě čísla musejí ležet ve svém rozsahu. Tlačítka mimo mapu nesmějí spotřebovat sondu. Hlídej všechny čtyři okraje včetně krajních platných políček.
  • L03/M02_Nim.java: hra už běží proti botovi. Sleduj jeho tahy a doplň svého rádce. Má jen doporučit počet kamenů, zatímco skutečný tah a střídání hráčů ponechá připravené hře. Pro prázdnou hromádku vrať 0. Tady využiješ také dřívější zbytek po dělení a čtení cizího kódu.

Pro ověření otevři Check.java ze stejné složky jako daná hra. U Nim si navíc všimni, zda dotaz na radu opravdu nechal aktuální hromádku beze změny.

Teď umíš odmítnout neplatnou akci před změnou hodnot a rozlišit konec main od vrácení verdiktu jedné připravené akce.
