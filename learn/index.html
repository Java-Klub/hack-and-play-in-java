Learn to program with Hack & Play in Java

Wake up a robot, change a picture or fix a small game's rule. First, explore the piece of Java you need using a few lines. Then try it out and use it in your own solution.

Starting from scratch? Open Set up your workshop. You do not need previous programming experience.

Take small steps

Read one lesson, run its example and solve its task. Predict an answer before opening it. If the result differs, look for the first step where your prediction and the program part ways.

Find your files

In NetBeans Favorites, open the file named in the lesson. Complete examples are in learn/examples; short tasks are in learn/practice. For games, the lesson gives the whole path, such as L01/M01_CafeWallLab.java.

Return to the glossary for a word or symbol you have forgotten. Comments alongside a game's code explain unfamiliar supplied parts too.

If you already know something, try the task first. Return to the explanation whenever you need to understand a result. Speed is not the goal.
