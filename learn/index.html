Learn to program with Hack & Play in Java

Step by step, you will learn to understand Java programs and write your own. Start with a few lines, try out a new idea, then use it in a small game.

Starting from scratch? Open Set up your workshop.

You need a computer with JDK 26 or later and an editor. Once downloaded, the textbook, examples and games work offline. You do not need any previous programming experience.

Your first route

Read one lesson, run its example and try its short task. There is no need to read a whole chapter first. Answers stay inside expandable sections so you can make your own prediction before opening them.

Chapter Lessons you can work through now

If you already know something, try the lesson's task first. Return to the explanation whenever you need to understand a result. This textbook does not judge you by your speed.

How the files are organised

  • learn/examples contains the complete examples used in the explanations. You can run and change them; the lesson page keeps the original version.
  • learn/practice contains short tasks. Edit the file named in each task. The lesson gives you the expected output.
  • Folders L01 to L12 contain games. A lesson will send you to a particular game once you know the basics it needs. Comments explain the parts of the supplied program that you are not writing yet.
  • The glossary of your first Java notation can help when you meet an unfamiliar symbol or word.

A textbook lesson number may differ from the number on a game folder. Follow the practice links in the lesson you are reading.

Reading on GitHub and offline

On GitHub, read the Markdown files, such as this page. For comfortable reading from your computer, open learn/index.html in the downloaded folder. The HTML pages contain the same explanations, local links and expandable answers. They need neither a server nor an internet connection.

The Czech edition uses English programming terms, with Czech explanations in parentheses where helpful. Code names and program messages are in English so both language editions can use the same code.
