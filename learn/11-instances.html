11.2 Každý robot má vlastní baterii

Dva roboti sdílejí stejné instrukce, ale nikoli jednu baterii. Class (třída) popisuje společné chování, zatímco každá instance (instance objektu) nese vlastní hodnoty polí. Vytvoření je chvíle, kdy každému robotovi dáš smysluplný počáteční stav.

Konstruktor dostane počáteční údaje

void main() {
    Drone first = new Drone("Dot", 5);
    Drone second = new Drone("Dash", 8);
    first.move();
    IO.println(first.name + ": " + first.charge);
    IO.println(second.name + ": " + second.charge);
}

class Drone {
    String name;
    int charge;

    Drone(String name, int charge) {
        this.name = name;
        this.charge = charge;
    }

    void move() {
        charge = charge - 1;
    }
}

Otevři learn/examples/11/TwoDrones.java. Drone(String name, int charge) je constructor (konstruktor). Má jméno třídy a žádný návratový typ, ani void. New Drone("Dot", 5) vytvoří objekt a provede tento konstruktor s těmito argumenty.

Parametr name dočasně překryje stejně pojmenované pole. This.name znamená pole právě vytvářeného objektu; samotné name vpravo znamená parametr. Přiřazení zkopíruje dodaný odkaz na text do pole. This.charge obdobně uloží číslo.

Každý výraz new vytvoří další instanci. First.move() změní pouze charge objektu first, z 5 na 4. Second stále má 8. Obě volání by použila stejnou definici metody, ale příjemce určuje, čí pole metoda čte a zapisuje.

Předpověz jiného příjemce

Také jedno zavolání second.move() dá Dash: 7. Co když jiné proměnné přiřadíš first a zavoláš přes ni move? Dot se znovu změní: kopírování odkazu nevytváří třetí dron.

Úkol: nakrm jen vybraného robota

Otevři learn/practice/11/PetBots.java. Uprav konstruktor, aby uložil dodané name a energy. Uprav feed, aby amount přičetla k existující energii příjemce místo jejího nahrazení. Zachovej oba vytvářené roboty i připravené krmení pouze first.

S jídlem 3 očekávej Dot: 5 a Dash: 6. S jídlem 0 očekávej Dot: 2 a Dash: 6. S jídlem 7 bude Dot mít 9. Používej množství od 0 do 100. Omezení a odmítnuté operace přijdou v další lekci.

Nápověda 1: rozliš význam stejného jména

V konstruktoru odliš this.energy od parametru energy. Přiřazení energy samo sobě by ponechalo pole na výchozí hodnotě 0.

Nápověda 2: krmení používá uložený stav

Před přičtením parametru přečti existující pole. Uvnitř feed robota znovu nevytvářej ani nenuluj jeho jméno.

Příště necháš objekt odmítnout nemožnou změnu, aniž by přitom poškodil jakoukoli část svého stavu.
