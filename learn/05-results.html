5.3 Vrať výsledek volajícímu

Výpočet ceny může být užitečný v obchodě i u rozhodčího. Nemusí pokaždé něco tisknout; místo toho poskytne výsledek místu, které se zeptalo.

Výsledek lze uložit i použít dál

Otevři learn/examples/05/TokenPrice.java. Zadej počet lektvarů 4.

void main() {
    int count = Integer.parseInt(IO.readln("Potions: ").strip());
    int tokens = price(count);
    IO.println("Tokens needed: " + tokens);
    IO.println("One extra potion: " + price(count + 1));
}

int price(int count) {
    return count * 3;
}

Potions: 4
Tokens needed: 12
One extra potion: 15

int price(int count) říká, že metoda přijme jedno celé číslo a poskytne jiné celé číslo. Return type (návratový typ) stojí před jménem. return count * 3; spočítá hodnotu, ukončí právě toto volání a předá ji volajícímu.

U int tokens = price(count); se nejprve provede price a jeho vrácená hodnota se uloží do tokens. Při count = 4 je to 12. Ve druhém výpisu argument count + 1 poskytne 5 a nové volání vrátí 15. Price samo nic nevypíše.

Return není println. Println zobrazí zprávu, return předá hodnotu. Výpočet s výsledkem 12 ještě nerozhoduje, jestli se má 12 zobrazit, přičíst k jiné ceně nebo porovnat s rozpočtem. To může udělat volající.

Každá možná cesta musí poskytnout výsledek

Otevři learn/examples/05/DragonLabel.java. Tady je výsledkem String:

void main() {
    int strength = Integer.parseInt(IO.readln("Strength: ").strip());
    String label = dragonName(strength);
    IO.println("You found: " + label);
}

String dragonName(int strength) {
    if (strength >= 5) {
        return "Ancient dragon";
    }
    return "Baby dragon";
}

Při síle 5 a vyšší se vrátí Ancient dragon; k druhému return už se nedojde. Jinak první blok neproběhne a vrátí se Baby dragon. Kdybys druhý return smazal, některé cesty by nedaly slíbený text a program by se nepřeložil.

Stejně může metoda s návratovým typem boolean předat true nebo false, jak už znáš z rozhodčích her. Samotné return; bez hodnoty patří do metody s void. Návrat z pomocné metody neukončuje celé main: main pokračuje tam, odkud ji zavolalo.

Úkol: spočítej lup a přiděl hodnost

Otevři learn/practice/05/LootScore.java. Hra už čte počty mincí a drahokamů, ale výpočty vracejí náhradní odpovědi.

Doplň score tak, aby mince měla hodnotu 1 a drahokam 5. Doplň rank tak, aby za 20 bodů a více vracelo Master, jinak Rookie. Obě metody jen vracejí výsledek; čtení a výpisy zůstávají v main. Počty v tomto úkolu zkoušej od nuly výš.

000Rookie
Nápověda: sleduj cestu jednoho výsledku

Výsledek score se uloží do points. Tuto hodnotu main vypíše a potom předá rank. Rank už nemá znovu počítat mince ani číst odpověď hráče.

Napodob stroj a zapoj kostky

  • L02/M11_NumberMachine.java: vrať se ke svým pokusům. Doplň imitation tak, aby z parametru počítalo stejný výsledek jako stroj pro všechna čísla od -20 do 20. Zkus nulu i záporné číslo a porovnej pravidlo se svou předpovědí. Referenční machine neměň.
  • L03/M10_ShutTheBox.java: napiš diceTotal pro součet obou kostek a zapoj jeho výsledek do target v roll. Správná definice, kterou nikdo nepoužije, hru neopraví. Generování firstDie a secondDie je připravené. Po spuštění musí cíl souhlasit se zobrazenými kostkami.

Obě hry ověří Check.java ze stejné složky; vyber jejich název v Program Arguments. V NumberMachine navíc vlastní přidané compare ověř spuštěním. U ShutTheBox neměň připravené hledání povolených uzávěrů.

Teď umíš napsat výpočet s výsledkem, použít jej na dvou místech a rozlišit vracení hodnoty od jejího zobrazení.
