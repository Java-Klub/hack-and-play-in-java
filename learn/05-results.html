5.3 Return a result to the caller

A price calculation can be useful in a shop or to a game referee. It does not have to print something every time; instead, it can provide a result to the place that asked for it.

You can store a result or use it further

Open learn/examples/05/TokenPrice.java. Enter 4 for the number of potions.

void main() {
    int count = Integer.parseInt(IO.readln("Potions: ").strip());
    int tokens = price(count);
    IO.println("Tokens needed: " + tokens);
    IO.println("One extra potion: " + price(count + 1));
}

int price(int count) {
    return count * 3;
}

Potions: 4
Tokens needed: 12
One extra potion: 15

int price(int count) says that the method receives one whole number and provides another whole number. The return type comes before the name. return count * 3; calculates a value, ends this particular call, and passes the value back to the caller.

In int tokens = price(count);, price runs first, and its returned value is stored in tokens. When count = 4, that value is 12. In the second print statement, the argument count + 1 provides 5, and a new call returns 15. The method price does not print anything itself.

Return is not println. Println displays a message; return passes back a value. A calculation with a result of 12 does not decide whether 12 should be displayed, added to another price, or compared with a budget. The caller can decide that.

Every possible path must provide a result

Open learn/examples/05/DragonLabel.java. Here, the result is a String:

void main() {
    int strength = Integer.parseInt(IO.readln("Strength: ").strip());
    String label = dragonName(strength);
    IO.println("You found: " + label);
}

String dragonName(int strength) {
    if (strength >= 5) {
        return "Ancient dragon";
    }
    return "Baby dragon";
}

With strength 5 or higher, it returns Ancient dragon; it never reaches the second return. Otherwise, the first block does not run, and it returns Baby dragon. If you deleted the second return, some paths would not provide the promised text, and the program would not compile.

Likewise, a method with the return type boolean can pass back true or false, as you have already seen in game referees. A plain return; without a value belongs in a method with void. Returning from a helper method does not end the whole of main: main continues from where it made the call.
