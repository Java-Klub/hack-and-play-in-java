4.5 Choose a value with switch

A spell book takes a word and chooses an effect. You can give a few exact options their results in a clear, compact form.

One input, one chosen value

Open learn/examples/04/SpellBook.java.

void main() {
    String spell = IO.readln("Spell: ").strip().toLowerCase(Locale.ROOT);
    String effect = switch (spell) {
        case "red", "r" -> "Fire";
        case "blue", "b" -> "Ice";
        case "green", "g" -> "Vines";
        default -> "Fizzle";
    };
    IO.println("Effect: " + effect);
}

Spell:  B 
Effect: Ice

toLowerCase(Locale.ROOT) is the counterpart of toUpperCase from earlier: it gives you lowercase text. After cleaning and conversion, the answer B therefore becomes b.

PartMeaning
switch (spell)Read the value of spell and choose the matching option.
case "blue", "b" -> "Ice";For either exact value, give the text Ice. The comma groups the options.
default -> "Fizzle";The result for anything that did not match a listed option.
String effect = ...;Store the chosen result under the name effect.

We call this a switch expression because it has a value. Only the chosen option runs. The semicolon after } ends the whole assignment. Then println prints the stored effect.

If conditions can check ranges and several different questions. This switch selects by the exact value of one input. All results chosen here are text, so they can be stored in a String.

The result is chosen after the arrow. The print call then only joins this finished text to the label. Remember to fix default too, so that unknown commands do not get an ordinary action.

How to distinguish four combinations

In a game with two choices, giving each combination a different number can help. Open learn/examples/04/ControlPanel.java:

void main() {
    boolean lights = true;
    boolean music = false;
    int mode = 0;
    if (lights) {
        mode = mode + 1;
    }
    if (music) {
        mode = mode + 2;
    }
    IO.println("Mode: " + mode);
}

By changing the two initial boolean values, you can try all four modes:

lightsmusicmode
falsefalse0
truefalse1
falsetrue2
truetrue3

There are two separate if statements: when both choices are on, both contributions should be added. To choose a result from this mode, you can then use a switch with options 0, 1, 2 and 3. For numbers too, add default for the remaining values. The compiler cannot infer from this calculation that no other number can occur; the expression must provide a result for every possible int value.

Choose a reward or allow a card

  • L07/M02_CooperateOrDefect.java: each player privately chooses cooperation or betrayal. The supplied reward action receives two boolean values and should return one numeric reward. Distinguish the four combinations and use switch to choose a reward according to the task's rules. The neutral ControlPanel example shows how to create a numeric key; do not confuse that key with the rewards it selects.
  • L07/M01_CrazyEightsSimpleMauMau.java: first reject a card code outside 0 to 51. The supplied rank(card) gives a value from 2 to 14; card / 13 gives the suit. An eight is always allowed; other cards must match the rank of top or the chosen suit. Use switch for the special value and combine two reasons for acceptance in the ordinary result. You only need to change the legal judge; dealing is supplied.

Both tasks are checked by L07/Check.java; select the program you are working on in Program Arguments. The same if or switch can change the behaviour of many parts of a game when they all ask one shared judge.
