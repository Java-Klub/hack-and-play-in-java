# Slovníček prvních zápisů

Vrať se sem jen pro zápis, kterému právě nerozumíš. Příklady a úkoly najdeš v [jednotlivých lekcích](README.md).

| Zápis nebo pojem | Co znamená |
| --- | --- |
| `.java` | Koncovka souboru se zdrojovým kódem Javy. |
| `void main()` | Akce, kterou Java u našich prvních programů při spuštění zahájí. |
| `{ }` | Hranice block (bloku) kódu. Kroky uvnitř tvoří jeden celek. |
| `()` | Za názvem akce ohraničují argumenty, tedy předávané hodnoty. V jejím popisu vymezují seznam vstupů; prázdné závorky žádné neuvádějí. |
| `;` | Ukončení statement (příkazu), například výpisu nebo přiřazení. |
| `IO.println(...)` | Call (volání) připravené akce, která vypíše předanou hodnotu a ukončí řádek. |
| `"text"` | String literal (textový literál). Uvozovky jsou hranice zápisu a nevypisují se. |
| `//` nebo `///` | Začátek komentáře do konce řádku; Java jeho slova neprovádí. |
| Variable (proměnná) | Pojmenované místo pro hodnotu určitého typu. |
| `int` | Type (typ) pro celá čísla v rozsahu −2147483648 až 2147483647. |
| `double` | Číselný typ, který umožňuje desetinnou část; některé hodnoty uchovává přibližně. |
| `String` | Typ pro textovou hodnotu. |
| `=` | Assignment (přiřazení): nejprve vypočítej pravou stranu, potom její hodnotu ulož pod jméno vlevo. |
| Expression (výraz) | Zápis, který poskytne hodnotu, například `energy - 2`. |
| `+` | Sčítání čísel nebo spojování textu podle použitých hodnot. |
| `-`, `*`, `/`, `%` | Odčítání, násobení, dělení a zbytek po dělení. |
| Compiler (překladač) | Část JDK, která ověřuje zápis programu a převádí jej do podoby pro spuštění. |
| Compiler error (chyba překladu) | Hlášení, že překladač nemůže zapsaný kód přijmout. |
| GREEN / RED | Výsledek funkční kontroly hry: ověřované případy souhlasí / některý zatím nesouhlasí. |

Slovníček neobsahuje hotová řešení her. Pro konkrétní úkol používej jeho zadání a postupné nápovědy.
