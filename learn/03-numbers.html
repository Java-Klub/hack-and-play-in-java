3.4 Z odpovědi udělej číslo

Hráč zadá počet spoluhráčů. Program spočítá, kolik žetonů potřebujete. Zadaná číslice je nejprve text; před počítáním z ní potřebuješ získat číslo.

Text není počet

Otevři learn/examples/03/TicketCounter.java. Každý hráč dostane tři žetony.

void main() {
    String text = IO.readln("Players: ");
    int players = Integer.parseInt(text.strip());
    int tokens = players * 3;
    IO.println("Tokens needed: " + tokens);
}

Players: 4
Tokens needed: 12

Integer.parseInt(...) je připravená akce Javy pro převod textu na celé číslo typu int. Velké I v Integer a velké I uprostřed parseInt jsou součástí názvu.

Krok pro odpověď 4 Výsledek
textText " 4 ".
text.strip()Text "4" bez krajních mezer.
Integer.parseInt(text.strip())Číslo 4. Nejprve se provede vnitřní volání strip; jeho výsledek dostane parseInt.
players * 3Číslo 12.

Vnořené závorky se čtou od vnitřního výpočtu: nejdřív očištění textu, potom převod. Výsledek pod jménem players je číslo. Proto s ním můžeš násobit.

Úkol: oprav energetický zesilovač

Otevři learn/practice/03/PowerBoost.java. Po zadání 4 stroj tvrdí, že energie je 42. Sleduj, co je skutečně uložené v text.

Získej ze vstupu celé číslo a spočítej dvojnásobek původní energie plus dvě jednotky navíc. Výsledek vypiš se stávajícím popiskem. Výpočet ulož do pojmenované hodnoty před výpisem.

Energy: 4
Boosted energy: 10

Se vstupem 8 musí stejný program vypsat Boosted energy: 18. Přijmout má také krajní mezery, například kolem 10; tehdy očekávej 22.

Nápověda 1: proč vzniklo 42

Jakmile je vlevo u + text, další hodnota se připojuje jako text. Samotné závorky kolem textu z něj číslo neudělají. Převod musí přijít před výpočtem.

Nápověda 2: odděl tři kroky

Ponech čtení, přidej přiřazení s převodem do int a další s číselným výpočtem. Až potom připoj hotový výsledek k popisku. Neutrální příklad převodu je int count = Integer.parseInt("7");.

Zkus slovo místo čísla

Spusť TicketCounter a napiš four. V Output najdeš NumberFormatException: daný text nelze přečíst jako int a program se ukončí před výpočtem. Spusť jej znovu a zadej číslo. Tento příklad předpokládá zápis celého čísla, například 4 nebo 12; desetinné 4.5 také není int.

Nemusíš rozumět celému chybovému výpisu. Důležité je rozlišit chybu ve zdrojáku od nepřevoditelné odpovědi při běhu. Jak takovou odpověď zachytit a dovolit opravu, si vyzkoušíš při práci s exceptions (výjimkami).

Malá vlastní výzva

Vrať se k TicketCounter. Přidej otázku na počet žetonů pro jednoho hráče. Převeď i druhou odpověď a použij ji místo pevné trojky. Se čtyřmi hráči a pěti žetony na hráče očekávej 20. Potom vyzkoušej tři hráče a dva žetony: výsledek má být 6.

Teď umíš načíst text, převést jej na celé číslo a použít pro výpočet místo pevné hodnoty.
