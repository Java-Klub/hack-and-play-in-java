3.4 Turn an answer into a number

The player enters how many people are playing. The program calculates how many tokens you need. An entered digit starts as text; before calculating, you need to get a number from it.

Text is not a quantity

Open learn/examples/03/TicketCounter.java. Each player gets three tokens.

void main() {
    String text = IO.readln("Players: ");
    int players = Integer.parseInt(text.strip());
    int tokens = players * 3;
    IO.println("Tokens needed: " + tokens);
}

Players: 4
Tokens needed: 12

Integer.parseInt(...) is a supplied Java action for converting text to a whole number of type int. The capital I in Integer and the capital I inside parseInt are part of the name.

Step for the answer 4 Result
textThe text " 4 ".
text.strip()The text "4", without outer spaces.
Integer.parseInt(text.strip())The number 4. The inner call must produce its result first.
players * 3The number 12.

Read nested parentheses from the inside out: clean the text first, then convert it. The result stored under players is a number, so you can multiply it.

Task: fix the energy booster

Open learn/practice/03/PowerBoost.java. Entering 4 makes the machine claim the energy is 42. Track what is actually stored in text.

Convert the input to a whole number and calculate double the original energy plus two extra units. Print the result with the existing label. Store the calculation in a named value before printing.

Energy: 4
Boosted energy: 10

With input 8, the same program must print Boosted energy: 18. It should also accept outer spaces, for example around 10; then expect 22.

Hint 1: why you got 42

Once the value on the left of + is text, the next value is joined as text. Putting parentheses around text does not turn it into a number. Convert it before calculating.

Hint 2: separate three steps

Keep the input call, add an assignment that converts it to int, then another with the numeric calculation. Only then join the finished result to the label. A neutral conversion example is int count = Integer.parseInt("7");.

Try a word instead of a number

Run TicketCounter and enter four. You will find NumberFormatException in Output: that text cannot be read as an int, so the program ends before calculating. Run it again and enter a number. This example expects a whole number written as text, such as 4 or 12; the decimal 4.5 is not an int either.

You do not need to understand the entire error message. What matters is distinguishing a mistake in the source code from an answer that cannot be converted while the program runs. You will try catching such an answer and allowing a correction when working with exceptions.

A small challenge of your own

Return to TicketCounter. Add a question asking how many tokens each player gets. Convert the second answer too and use it instead of the fixed three. With four players and five tokens each, expect 20. Then try three players and two tokens: the result should be 6.

You can now read text, convert it to a whole number and use it in a calculation instead of a fixed value.
