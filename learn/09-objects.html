9.2 Jeden popis, více objektů

Mapa potřebuje výchozí bod i místo příjezdu. Mají stejný tvar, ale nemusejí mít stejné souřadnice. Type (typ) chápej jako popis a každý vytvořený object (objekt) jako jednu konkrétní sadu údajů.

Vytvoření převezme nynější hodnoty

void main() {
    int x = 2;
    Point first = new Point(x, 3);
    x = 8;
    Point second = new Point(x, 3);
    Point copy = new Point(2, 3);
    IO.println("First: " + first.x() + "," + first.y());
    IO.println("Second: " + second.x() + "," + second.y());
    IO.println("Same values: " + first.equals(copy));
}

record Point(int x, int y) {
}

Otevři learn/examples/09/MapSnapshots.java. První constructor (vytváření objektu) dostane nynější hodnotu x, tedy 2. Pozdější přiřazení změní lokální proměnnou x na 8. Nezasáhne zpětně do již vytvořeného Point. Jeho složka zůstane 2.

Další new Point použije 8 a 3. Definice Point je napsaná jednou, ale vytváření může proběhnout mnohokrát s různými argumenty. Je to stejný princip předávání hodnot, který znáš z parametrů metod, tentokrát pro sestavení dat.

Record (záznam) dodá equals pro porovnání hodnot složek. first.equals(copy) je true, protože oba body mají x rovno 2 a y rovno 3. Ptáme se na shodu dat, ne na shodu napsaných jmen proměnných. U textových složek porovnání záznamů porovnává i obsah textu.

Předpověz nový snímek

Před vytvořením second znovu nastav x na 2. Oba vypsané body pak budou 2,3. Pozdější změna x stále nezmění ani jeden bod. Co vrátí first.equals(second)? True, protože hodnoty jejich složek souhlasí.

Úkol: ponech za sebou kontrolní bod

Otevři learn/practice/09/Checkpoint.java. Zachovej start a vytvoř finish o dva sloupce doprava a jeden řádek nahoru: k x přičti 2 a od y odečti 1. Použij čtecí metody start, aby nový bod vznikl z uložené pozice.

Pro vstup 2 a 3 musí Start zůstat 2,3 a Finish být 4,2. Back at start musí být false. Vyzkoušej také -2 a 0: očekávej start -2,0 a finish 0,-1. Záporné souřadnice jsou povolené; neomezuj je nulou.

Nápověda 1: změněná pozice potřebuje nová data

Přiřazení start do finish žádný pohyb nepočítá. Vytvoř Point se dvěma vypočtenými hodnotami složek.

Nápověda 2: zachovej kontrolní bod

Při výpočtu finish nenahrazuj start. Dva řádky výpisu umožňují ověřit pohyb i zachování původního bodu.

Příště rozlišíš sdílení objektu od vytvoření samostatného obalu pro více objektů. Na tom záleží, když náhled nesmí změnit skutečné karty hráče.
