5.5 Slož malé rozhodčí

Kniha kouzel má tři úkoly: očistit vstup, poznat povolené kouzlo a zvolit efekt. Každý kousek může mít vlastní jméno a vracet výsledek dalšímu.

Od odpovědi k efektu

Otevři learn/examples/05/SpellPipeline.java. Spusť program dvakrát: jednou zadej RED s mezerami, podruhé neznámé green.

void main() {
    String input = IO.readln("Spell: ");
    String spell = clean(input);
    IO.println("Effect: " + effect(spell));
}

String clean(String input) {
    return input.strip().toLowerCase(Locale.ROOT);
}

boolean isKnown(String spell) {
    return spell.equals("red") || spell.equals("blue");
}

String effect(String spell) {
    if (!isKnown(spell)) {
        return "Fizzle";
    }
    return switch (spell) {
        case "red" -> "Fire";
        default -> "Ice";
    };
}

Spell:  RED 
Effect: Fire

Main obstará čtení a zobrazení. Clean vrátí očištěný text. Effect se zeptá isKnown na boolean; pokud kouzlo nezná, vrátí Fizzle. Jinak vybere efekt. Default v tomto switch už znamená blue, protože všechny jiné možnosti byly odmítnuté před ním.

Jde o composition (skládání) metod. Sleduj jedno volání: effect dostane red → zavolá isKnown(red) → dostane true → přeskočí odmítnutí → vybere Fire → vrátí ho do main. Return true v isKnown ukončí pouze isKnown; effect teprve pokračuje.

Výpočet kouzla nic nečte ani netiskne. Pro pokus bez dotazování hráče dočasně nahraď tělo main jediným příkazem IO.println(effect("blue")); a očekávej Ice. Definice pomocných metod ponech. Potom vrať původní tělo main. Effect dostává už očištěný text; pro libovolný vstup používej nejprve clean. Každá metoda má malý, konkrétní slib.

Úkol: sestav rozhodčího arény

Otevři learn/practice/05/ArenaReferee.java. Main je hotové. Rozhodčí zatím schvaluje úplně všechno.

Doplň tři spolupracující metody. Clean vrátí text bez krajních mezer a velkými písmeny. Cost dostane očištěný povel: JUMP stojí 3, DUCK stojí 1, neznámý povel má cenu 0. Verdict nejprve použije clean a cost; pro neznámý povel vrátí UNKNOWN, pro nedostatek energie TIRED, jinak GO.

Čtení a výpis zůstanou jen v main. Verdict použije oba pomocníky, nebude jejich pravidla opisovat. Vstupní energii zkoušej od nuly výš. Přijetí zde energii neodečítá: program posuzuje jeden navržený tah.

MoveEnergyVerdict
jump 3GO
JUMP2TIRED
duck1GO
DUCK0TIRED
wait nebo prázdný řádek20UNKNOWN
Nápověda 1: cesta hodnot

Verdict přijme původní move, uloží výsledek clean pod novým jménem a teprve tento očištěný text předá cost. Výsledná cena potom stačí pro dvě odmítací podmínky.

Nápověda 2: pořadí odmítnutí

Cena 0 označuje neznámý povel, nikoli tah zdarma. Nejdřív odmítni neznámý povel, potom porovnej energii s cenou. Rovnost ceny a energie je povolená.

Žáby potřebují směr, ne vlastní kopii výpočtu

V L03/M12_ToadsAndFrogs.java mají ropuchy číslo druhu 1 a jdou doprava; žáby číslo 2 a jdou doleva. Hrací pole je zpočátku:

positions:  0 1 2 3 4 5 6
creatures:  T T T . F F F
toads:      →
frogs:      ←

Direction vrací znaménko pohybu. Destination dostane origin (vnitřní pozici), distance (kladnou délku kroku nebo skoku) a piece (druh tvora). Má zavolat direction a vrátit kandidátní cílovou pozici. Například origin 4, distance 1 a piece 2 má dát 3. Pro origin 2, distance 1 a piece 1 také vyjde 3; pro žábu z 5 se skokem délky 2 rovněž 3.

Obě metody jen počítají. Připravené move ověří prázdné políčko, povolený skok i okraje a provede skutečný přesun. Neupravuj pole. Pozice na obrazovce jsou pro hráče číslované 1 až 7: klávesa 5 na začátku požádá první žábu o přesun do mezery. R obnoví začátek. Kontrolu vyber v L03/Check.java.

Vrať se k příběhu nebo odměnám

  • L02/M05_MadLibsStoryMachine.java: zkontroluj, jak headline získává očištěné jméno. Pokud čištění opisuje přímo, nahraď je voláním cleanWord. Pokud už ji používá, nic neopisuj. Vysvětli cestu jména od vstupu přes pomocníka až do titulku. Stejné pravidlo má zůstat na jednom místě.
  • L07/M02_CooperateOrDefect.java: připravené play se ptá reward dvakrát, jednou pro každého hráče. U volání s prohozenými argumenty se prohodí pohled na to, kdo spolupracuje. Předpověz vlastní odměnu i soupeřovu pro jednu spolupráci a jednu zradu, potom ověř hrou. Pravidla odměn už znáš z podmínek.

Teď umíš rozdělit pravidlo do menších metod, sledovat cestu argumentů a výsledků a ponechat vstup a výstup oddělené od výpočtů.
