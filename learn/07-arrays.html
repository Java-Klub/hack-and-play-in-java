7.1 Dej hodnotám očíslovaná místa

Tři schránky obsahují různé množství drahokamů. Tři samostatná jména by šla použít, ale pak by se obtížně vybíralo místo podle čísla od hráče. Array (pole) spojí hodnoty stejného typu do očíslované řady.

První místo má číslo nula

Otevři learn/examples/07/GemSlots.java. Pro slot 2 předpověz obsah ještě před spuštěním.

void main() {
    int[] gems = {3, 0, 5};
    int slot = Integer.parseInt(IO.readln("Slot: ").strip());
    if (slot < 0 || slot >= gems.length) {
        IO.println("Invalid slot");
    } else {
        IO.println("Gems: " + gems[slot]);
    }
    IO.println("Slots: " + gems.length);
}

Zápis int[] označuje pole celých čísel. Hodnoty ve složených závorkách vytvoří tři elements (prvky) v uvedeném pořadí. Zápis gems[slot] čte jeden prvek; číslo v hranatých závorkách je index (pořadové číslo místa).

Indexy jsou 0, 1 a 2, takže slot 2 obsahuje 5. Length (délka) je naproti tomu 3: říká počet prvků, nikoli nejvyšší platný index. Zápis gems.length nemá kulaté závorky. Je to vlastnost pole, ne volání metody.

Nejdřív se ověří meze, až pak se čte prvek. Index -1 ani index rovný délce neoznačují platné místo. Java mimo pole přístup nepovolí; tady tomu předejdeme srozumitelnou zprávou. Hranaté závorky tedy nevymýšlejí nové místo podle potřeby.

Předpověď: slot 1 a slot 3

Slot 1 obsahuje 0 a program také oznámí tři místa. Slot 3 je neplatný: vypíše Invalid slot a Slots: 3.

Úkol: kam vede vybraný portál?

Otevři learn/practice/07/PortalCodes.java. Pole obsahuje SUN, MOON a STAR. Připravená kontrola mezí funguje, ale každý platný výběr hlásí první portál. Oprav čtení tak, aby použilo hráčem vybraný slot.

Pro 0 čekej Portal: SUN, pro 1 Portal: MOON a pro 2 Portal: STAR. Vstupy -1 a 3 mají oba dát No portal. Nevybírej text řetězcem podmínek pro každý jednotlivý index; potřebné údaje už leží v poli.

Nápověda 1: odděl místo a obsah

Proměnná slot je číslo místa. Proměnná destination má dostat text, který na tom místě leží.

Nápověda 2: rozšiř data

Po opravě můžeš přidat čtvrtý text COMET do pole. Délka a kontrola mezí se mají přizpůsobit bez dalších zvláštních větví.

Příště projdeš všechna místa automaticky. Nebudeš potřebovat znát předem přesný počet hodnot ani každou pojmenovávat zvlášť.

Procvič ve hře

  • DotsAndBoxes · L05/M03_DotsAndBoxes.java
    DotsAndBoxes potřebuje správné čtyři hrany pro každé číslo boxu. V box rozliš horní, dolní a boční indexy; nevracej vždy první čtveřici.
  • PegDrop · L06/M06_PegDrop.java
    V PegDrop vrať ze scoreAt hodnotu skutečně vybraného koše. Dotaz nesmí přičítat body; vyzkoušej první i poslední index.
