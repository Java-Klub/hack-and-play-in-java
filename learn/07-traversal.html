7.2 Visit values without picking each one

A robot team sends its power levels in one array. This time, you care about each robot's value rather than its place number. There is a shorter form for this kind of traversal.

One value after another

Open learn/examples/07/RobotPowers.java. Add up the array's values before running it.

void main() {
    int[] powers = {2, 7, 4};
    int total = 0;
    for (int power : powers) {
        IO.println("Power: " + power);
        total += power;
    }
    IO.println("Total: " + total);
}

An enhanced for loop, often called for-each, reads elements in order from start to end. In for (int power : powers), powers means the whole array and power means the current value. You can read the colon as “for each power in powers”.

In the first round, power is 2; then it is 7, and then 4. It is not an index: seven is not a place number. The loop handles advancing and the array length itself, so you cannot forget the last visit. For an empty array, the body never runs, and the sum remains zero.

The accumulator total works just as it did for the deliveries read from input. The difference is where values come from: they are already stored in memory. If you also needed each place number, you would use an ordinary for loop with an index and the array's length.

Prediction: append 0 to the array

There is an extra Power: 0 line. The sum stays at 13. The number of elements visited and their sum are different things.

Task: choose robots for an expedition

Open learn/practice/07/ExpeditionPowers.java. The array contains power levels 4, 5, 9 and 0. The player enters the minimum acceptable power. The program currently counts all the robots.

Change the traversal: Ready should be the number of robots whose power is at least the threshold. Power should be the sum of only those accepted power levels. For threshold 5, expect Ready: 2 and Power: 14. For 0, accept all four, with a sum of 18. For 10, nobody qualifies, and both results are 0.

Hint 1: one test for two results

Change both the count and sum when the same condition passes. Decide using the current value, not the array length.

Hint 2: include the boundary

A robot whose power exactly equals the threshold qualifies. First check threshold 5 and power 5 by hand.

Next, you will change elements rather than only read them. You will need to distinguish a copy of the current value from an actual place in the array.

Traverse the letters of text too

For our words made from A–Z, read a letter with word.charAt(index). The first position is 0, and word.length() gives the number of positions. Unlike an array, length has parentheses here. The type char holds one text unit; write a letter in single quotes, such as 'A', while "A" is a String.

word.toCharArray() supplies an array for for (char letter : word.toCharArray()). The operation word.indexOf(letter) returns the first matching position or -1. Zero therefore also means a match. To read backwards, start at length minus one and decrease the index while it is nonnegative. Empty text has no valid position.

Practise in a game

    KochSnowflakeCards misses one side. The outer snowflake loop must visit corner indices 0, 1 and 2 once; recursive edge is supplied.

    Jotto forgets earlier matches. In matches keep a running count of all shared letters and compare words with one and several matches.

    In YatzyScorecard sum filled categories; -1 means unfilled. Separately accumulate the first six for the supplied bonus starting at 63 points.
