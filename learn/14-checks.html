14.1 Vyber příklady, které odhalí chyby

Výsledek, který vypadá uvěřitelně, je slabý důkaz. Functional check (funkční kontrola) zavolá pravidlo se známým vstupem a porovná vrácenou hodnotu s nezávisle zvoleným očekáváním. Při neshodě má vysvětlit rozdíl.

int boost(int streak) {
    return streak >= 3 ? streak * 2 : streak;
}

void equal(int expected, int actual, String name) {
    if (expected != actual) {
        throw new AssertionError(name + ": expected " + expected + ", actual " + actual);
    }
}

void main() {
    equal(0, boost(0), "empty streak");
    equal(2, boost(2), "before the boundary");
    equal(6, boost(3), "first doubled streak");
    IO.println("PASS 3 checks");
}

Pomocné equal při neshodě vyhodí AssertionError. Jeho jméno je obyčejný kód, nikoli zvláštní testovací syntaxe. Očekávaná hodnota jde první, skutečná druhá. Vyhozená chyba zabrání závěrečnému PASS, takže úspěch znamená dokončení všech předchozích kontrol.

Očekávané hodnoty odvoď ze zadaného pravidla, nikoli zkopírováním výrazu implementace do kontroly. Jinak se stejná chyba může opakovat na obou stranách. Použij běžnou hodnotu, meze a zvláštní případy.

Všimla by si slabší kontrola?

Kdyby boost chybně používalo > 3, kontroly nuly a dvojky projdou. Vstup tři vrátí tři místo šesti a chybu odhalí. Jaký další vstup prozkoumá pravidlo za hranicí?

Úkol: otestuj pravidlo doručení

V learn/practice/14/DeliveryChecks.java vytvoř příklady, nikoli nový vzorec ceny. Vzdálenosti nula až tři stojí dvě; vzdálenosti čtyři až devět stojí pět. Každý Example uchovává vstup a tvůj očekávaný výsledek. Používej pouze vstupy 0..9.

Zahrň poslední blízkou vzdálenost a vzdálenou hodnotu. Ověř také uvedené krajní body. Připravené ověření nejprve přijme správné pravidlo ceny a potom zjišťuje, zda tvoje příklady odmítnou tři záměrně chybná pravidla: posunutou hranici, vždy dvě a vždy pět.

IntUnaryOperator je připravená role, která přijímá jeden int a vrací jeden int. applyAsInt tuto roli zavolá. Method reference (odkaz na metodu) this::price předá chování price tohoto programu, aniž je hned zavolá; následující lambda výrazy dodají chybné alternativy.

Nápověda 1: donuť chybnou hranici nesouhlasit

Vyber vstup, kde distance < 3 a distance <= 3 dají odlišné odpovědi.

Nápověda 2: zahrň obě ceny

Sada obsahující pouze blízké vstupy neodmítne pravidlo vždy dvě. Přidej správně oceněný vzdálený příklad.

Kontroly zkoumají chování, nikoli formátování nebo vnitřní názvy metod implementace. Dále definuješ vlastní roli, jejíž chování mohou zaměnitelně dodávat různé objekty.
