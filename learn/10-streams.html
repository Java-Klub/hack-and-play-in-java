10.5 Nech data projít filtrem

Batoh obsahuje různé druhy kořisti, ale obchod má ukázat jen cenné předměty. Stream (proud zpracování) popisuje posloupnost kroků: vyber potřebné prvky, proměň je a shromáždi odpovědi. Původní kolekce může zůstat nedotčená.

Každá operace má jeden malý úkol

void main() {
    List<String> words = List.of("sun", "moon", "star", "a");
    List<String> loud = words.stream()
        .filter(word -> word.length() >= 4)
        .map(word -> word.toUpperCase(Locale.ROOT))
        .toList();
    IO.println("Selected: " + loud);
    IO.println("Original: " + words);
}

Otevři learn/examples/10/SpellFilter.java. Stream zahájí zpracování prvků seznamu. Filter dostane lambdu vracející boolean: true nynější prvek zachová, false jej odmítne. Zde sun a a neprojdou, protože mají méně než čtyři znaky.

Map dostane další lambdu, která pro každý zachovaný prvek vrátí náhradní hodnotu. Promění moon na MOON a star na STAR. Tato operace map není obal Map pro klíče a hodnoty: jedna prvky proměňuje, druhý uchovává přiřazení.

ToList dokončí pipeline (posloupnost zpracování) a shromáždí výsledné hodnoty do neměnného seznamu. Zalomení řádku výraz neukončuje; tečky jej prodlužují až po středník. Bez dokončující operace by samotný popis těchto kroků zpracování neprovedl.

Původní seznam se vypíše beze změny. Tyto lambdy pouze čtou prvky a vracejí odpovědi; do výchozího seznamu nepřidávají. Stream se spotřebuje jednou. Pro další výpočet zahaj další stream z kolekce místo ukládání a opětovného používání starého proudu.

Předpověz další slovo

Přidání "gate" do zdroje vytvoří GATE na konci Selected. A co přidání "go"? Zůstane jen v Original, protože filter jej odmítne ještě před map.

Úkol: proměň užitečnou kořist v seznam jmen

Otevři learn/practice/10/LootFilter.java. Doplň valuableNames: zachovej jen Loot s value přísně větší než 0 a potom vrať jejich jména v původním pořadí. Vrať List<String>, nikoli záznamy nebo jeden spojený text. Vstupní seznam neměň.

Očekávej Names: [Gem, Coin], Empty: [] a Original size: 4. Stone s 0 musí vypadnout stejně jako Debt s -2. Prázdný vstupní seznam přirozeně vrátí prázdný výstup bez čtení vstupu nebo přidávání náhradního jména.

Nápověda 1: odděl výběr a proměnu

První lambda odpovídá na otázku o value. Druhá vrací name. Filtrování jmen před čtením value by potřebnou informaci ztratilo.

Nápověda 2: sleduj typ prvku

Stream zprvu nese Loot. Po výběru stále nese Loot. Po převedení na jména nese String připravené pro toList.

Příště přejdeš od neměnných snímků dat k objektům, jejichž vlastní stav se během hry mění.

Co znamená dvojtečka v připraveném převodu?

V Nonogram je výsledný převod už hotový. Integer::intValue je method reference (odkaz na metodu), krátký zápis chování odpovídajícího value -> value.intValue(). mapToInt vytváří stream základních int a toArray() z nich vytvoří int[]. Tím se nasbíraná délka každé skupiny dostane do pevného pole pro vykreslení. Tuto část při opravě poslední skupiny neměň.
