3.3 Nech příběh měnit hráče

Krátký příběh může reagovat na jméno a místo, které dodá hráč. Místo několika ručních kopií připravíš jednu textovou šablonu.

Vyměň značky za odpovědi

Otevři learn/examples/03/StoryMachine.java. Přečti si nejprve text v proměnné story. Kde se má objevit stejný pilot dvakrát?

void main() {
    String pilot = IO.readln("Pilot: ");
    String place = IO.readln("Place: ");
    String story = "PLAYER shouts \"Go!\" in PLACE.\nPLAYER runs.";
    story = story.replace("PLAYER", pilot);
    story = story.replace("PLACE", place);
    IO.println(story);
}

Po spuštění může vzniknout tento rozhovor:

Pilot: Nova
Place: Moon
Nova shouts "Go!" in Moon.
Nova runs.

story.replace("PLAYER", pilot) poskytne text, kde jsou všechny přesné výskyty PLAYER nahrazené hodnotou pilot. Oddělující čárka rozděluje dvě předané hodnoty: hledaný text a jeho náhradu. Přiřazení uloží výsledek zpět do story. Druhé přiřazení stejně vyplní PLACE. Velikost písmen se musí shodovat.

Uvozovky uvnitř zprávy

V kódu je před každou uvozovkou kolem Go! zpětné lomítko. Java ho potřebuje, aby tuto uvozovku nečetla jako konec celého textu. Podobně umí uvnitř textu zapsat přechod na nový řádek.

Zápis ve zdrojákuCo je v textové hodnotě
\"Jedna dvojitá uvozovka.
\nJeden přechod na nový řádek.

Říkáme tomu escape sequence (řídicí posloupnost). Vnější uvozovky ukončující celý String před sebou lomítko nemají. Nový řádek uvnitř story způsobí, že jedno volání println vypíše příběh na dva řádky.

Úkol: příběh zapomněl jméno i lup

Otevři learn/practice/03/SecretStory.java. Čte jméno a předmět, ale místo nich stále tiskne NAME a ITEM.

Oprav uložení výsledku první náhrady a doplň druhou náhradu. Obě místa NAME musí použít přijaté jméno a ITEM přijatý předmět.

Name: Nova
Item: a rubber duck
Nova steals a rubber duck. Nova escapes.

Ověř i Red Fox a a jetpack. Celé fráze mají zůstat pohromadě. Neupravuj šablonu na pevné jméno jednoho člověka.

Nápověda

replace se chová jako strip: výsledek je třeba uložit. Každá značka potřebuje vlastní náhradu. Čárka v závorkách odděluje hledanou značku od nové hodnoty.

Pokus: pilot se jmenuje PLACE

V příkladu StoryMachine zadej pilotovi jméno PLACE a jako místo Moon. První náhrada vytvoří více míst s textem PLACE. Druhá náhrada potom změní všechna na Moon, včetně jména pilota. Zkus to a vysvětli, proč se druhé volání dívá na již upravený text. Pořadí operací ovlivňuje výsledek i tady.

Jak číst připravenou akci v další hře

Následující hry mají kousek k úpravě v připravené akci. Třeba:

String label(String word) {
    return "Found: " + word;
}

První String říká, že výsledkem akce bude text; dřívější void main() žádnou výslednou hodnotu nevracelo. label je jméno akce. String word pojmenovává předaný text. return dává výsledek zpět tam, odkud přišlo volání: label("map") poskytne "Found: map". Tato definice se sama nespustí; používá ji další část programu. Celý zápis vlastních akcí prozkoumáš v kapitole o methods (metodách). Pro nynější hry potřebuješ sledovat předaný text a upravit výraz za return.

Použij text ve hrách

  • L01/M03_TypeMelody.java: z textu vzniká melodie. Změň dodanou zprávu podle zadání a poslouchej rozdíl mezi písmeny a mezerami.
  • L01/M04_BitmapBanner.java: rozsvítíš nápis úpravou jeho textu. Písmena se promění v připravené pixelové řádky.
  • L01/M05_ProgramMirror.java: oprav text vypadající jako Java příkaz. Využiješ uvozovky uvnitř uvozovek.
  • L02/M05_MadLibsStoryMachine.java: očisti krajní mezery a sestav titulek z přijatého jména. Připravený program potom použije tvůj titulek u delšího absurdního příběhu.
  • L02/M06_AnagramRounds.java: hádáš přesmyčky, ale rozhodčí neuznává malá písmena. Oprav zpracování odpovědi a zachovej čištění krajních mezer. V připraveném řetězci volání další tečka vybírá operaci nad výsledkem předchozího volání.

U každé úlohy nejprve přečti její konkrétní cíl. Pro kontrolu otevři Check.java ze stejné složky a v Program Arguments vyber právě řešený soubor. Postup připomíná úvodní lekce.

Teď umíš vyplnit textovou šablonu, zapsat uvozovku uvnitř zprávy a sledovat text vrácený připravenou akcí.
