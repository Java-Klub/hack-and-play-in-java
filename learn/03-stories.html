3.3 Let the player shape the story

A short story can respond to a name and place supplied by the player. Instead of making several copies by hand, you will prepare one text template.

Replace markers with answers

Open learn/examples/03/StoryMachine.java. First read the text in story. Where should the same pilot appear twice?

void main() {
    String pilot = IO.readln("Pilot: ");
    String place = IO.readln("Place: ");
    String story = "PLAYER shouts \"Go!\" in PLACE.\nPLAYER runs.";
    story = story.replace("PLAYER", pilot);
    story = story.replace("PLACE", place);
    IO.println(story);
}

Running it could produce this conversation:

Pilot: Nova
Place: Moon
Nova shouts "Go!" in Moon.
Nova runs.

story.replace("PLAYER", pilot) gives you text in which every exact occurrence of PLAYER is replaced by the value of pilot. The comma separates two supplied values: the text to find and its replacement. The assignment stores the result back in story. The second assignment fills in PLACE in the same way. Uppercase and lowercase letters must match.

Quotes inside a message

In the code, each quote around Go! has a backslash before it. Java needs that backslash so it does not read the quote as the end of the whole text. It also has a way to write a line break inside text.

Notation in the sourceWhat is in the text value
\"One double quote.
\nOne line break.

This is called an escape sequence. The outer quotes that end the whole String have no backslash before them. The line break inside story makes a single println call print the story on two lines.

Task: the story forgot the name and the loot

Open learn/practice/03/SecretStory.java. It reads a name and an item, but still prints NAME and ITEM in their place.

Fix how the first replacement's result is stored, and add the second replacement. Both NAME markers must use the entered name, and ITEM must use the entered item.

Name: Nova
Item: a rubber duck
Nova steals a rubber duck. Nova escapes.

Also try Red Fox and a jetpack. Whole phrases should stay together. Do not change the template to contain one person's fixed name.

Hint

replace behaves like strip: you need to store the result. Each marker needs its own replacement. The comma in the parentheses separates the marker you are looking for from the new value.

Experiment: a pilot named PLACE

In StoryMachine, enter PLACE as the pilot's name and Moon as the place. The first replacement creates more occurrences of PLACE. The second then changes all of them to Moon, including the pilot's name. Try it and explain why the second call works on text that has already changed. The order of operations affects the result here too.

How to read a supplied action in the next game

The next games have a small part for you to edit inside a supplied action. For example:

String label(String word) {
    return "Found: " + word;
}

The first String says that the action returns text; the earlier void main() did not return a result value. label is the action's name. String word names the text passed in. return gives the result back to the place that made the call: label("map") provides "Found: map". This definition does not run on its own; another part of the program uses it. You will explore how to write your own actions in the chapter on methods. For these games, you need to follow the text passed in and change the expression after return.

Use text in games

  • L01/M03_TypeMelody.java: text becomes a melody. Change the supplied message as the task asks and listen to the difference between letters and spaces.
  • L01/M04_BitmapBanner.java: light up a sign by changing its text. Letters become supplied rows of pixels.
  • L01/M05_ProgramMirror.java: fix text that looks like a Java statement. You will use quotes inside quotes.
  • L02/M05_MadLibsStoryMachine.java: remove outer spaces and build a headline from the entered name. The supplied program then uses your headline with a longer, absurd story.
  • L02/M06_AnagramRounds.java: you guess anagrams, but the judge rejects lowercase letters. Fix how the answer is processed while keeping the removal of outer spaces. In the supplied chain of calls, the next dot selects an operation on the previous call's result.

Read each task's specific goal first. To check your work, open Check.java from the same folder and select the file you are working on in Program Arguments. The introductory lesson reminds you how.

You can now fill a text template, write a quote inside a message and follow text returned by a supplied action.
