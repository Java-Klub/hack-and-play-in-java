13.3 Dej událostem jeden jasný úkol

Několikrát klikni na Louder. Zobrazená hlasitost vyroste na pět a tam zůstane. Quieter používá stejné pravidlo se zápornou změnou. Tlačítka žádají o změnu; společný handler (zpracování události) rozhoduje o přípustnosti.

import javax.swing.*;

int volume = 2;

boolean adjust(int delta) {
    int next = volume + delta;
    if (next < 0 || next > 5) return false;
    volume = next;
    return true;
}

void main() {
    SwingUtilities.invokeLater(() -> {
        var status = new JLabel("Volume: " + volume);
        var quieter = new JButton("Quieter");
        var louder = new JButton("Louder");
        quieter.addActionListener(event -> {
            adjust(-1);
            status.setText("Volume: " + volume);
        });
        louder.addActionListener(event -> {
            adjust(1);
            status.setText("Volume: " + volume);
        });
        var panel = new JPanel();
        panel.add(quieter);
        panel.add(status);
        panel.add(louder);
        var frame = new JFrame("Volume Buttons");
        frame.setDefaultCloseOperation(JFrame.DISPOSE_ON_CLOSE);
        frame.add(panel);
        frame.pack();
        frame.setLocationByPlatform(true);
        frame.setVisible(true);
    });
}

addActionListener zaregistruje callback (zpětné volání). Parametr event popisuje aktivaci, ale příklad jeho podrobnosti nepotřebuje. Tělo běží později po stisku tlačítka, nikoli během jeho vytváření.

Každý callback zavolá adjust a obnoví popisek podle výsledné uložené hodnoty. JLabel.setText nahradí zobrazený text. Samotné pravidlo neodkazuje na popisky, tlačítka ani okna; lze je zavolat i z obyčejné metody.

Posluchače tlačítek i kreslení běží na EDT. Udržuj tyto akce krátké, aby okno mohlo reagovat na další událost. Dlouhý výpočet nebo sleep uvnitř posluchače by ovládání zastavil, přestože se okno vytvořilo správně.

Předpověz odmítnutou změnu

Z počáteční hlasitosti dva vrátí adjust(3) true a uloží pět. Další adjust(1) vrátí false a pět zachová. Předpověz adjust(-5) a potom adjust(-1).

Úkol: počítej lidi, nikoli stisky tlačítek

Dokonči handle v learn/practice/13/RoomCounter.java. Místnost pojme nejvýše tři lidi. add přijme jednoho pouze při volném místě; leave odebere jednoho pouze tehdy, když je někdo uvnitř. reset vždy obnoví nulu. Neznámé příkazy vracejí false.

Pro přijatý příkaz vrať true a pro odmítnutí false. Odmítnutý příkaz musí count zachovat. Zkus opustit prázdnou místnost, čtyřikrát vstoupit, jednou odejít a obnovit stav. Popisek musí vždy popisovat skutečný stav.

Připravená smyčka vytváří jedno tlačítko pro každý příkaz. Posluchač zachytí command daného průchodu; později jej nehledá podle viditelného popisku. Zapojení zachovej a oprav jen vlastní pravidlo.

Nápověda 1: ověř před změnou

Před zvětšením ověř kapacitu a před zmenšením prázdnost. Vrátit false až po změně count je pozdě.

Nápověda 2: reset má vlastní význam

Reset zpracuj samostatně; obnovení už prázdné místnosti je stále přijatý příkaz.

Dále bude timer (časovač) opakovaně žádat o malé změny. Stejné oddělení udrží jeho callback srozumitelný.
