4.1 Polož otázku kódu

Dveře potřebují tři jednotky energie. Dosud jsi počítal, kolik jí zbude. Teď zjistíš odpověď na otázku: stačí jí vůbec?

Odpověď true nebo false

Otevři learn/examples/04/DoorQuestion.java. Zadej energii 3 a propustku MOON.

void main() {
    int energy = Integer.parseInt(IO.readln("Energy: ").strip());
    String pass = IO.readln("Pass: ");
    boolean enough = energy >= 3;
    boolean recognised = pass.equals("MOON");
    IO.println("Enough energy: " + enough);
    IO.println("Recognised pass: " + recognised);
}

Energy: 3
Pass: MOON
Enough energy: true
Recognised pass: true

boolean je type (typ) se dvěma hodnotami: true znamená ano a false ne. Jsou to přímo hodnoty Javy, píšeme je malými písmeny bez uvozovek. Podobně jako int můžeš boolean uložit pod jménem, použít a vypsat.

energy >= 3 je comparison (porovnání). Poskytne boolean: při třech jednotkách true, při dvou false. Variable enough tedy uchovává výsledek otázky. Výpis odpovědi zatím dveře neotevírá; program zde jen vyhodnocuje dvě otázky.

Porovnej čísla

ZápisOtázkaPříklad
< / >Je číslo menší / větší?3 > 3 je false.
<= / >=Je menší nebo stejné / větší nebo stejné?3 >= 3 je true.
==Jsou číselné hodnoty stejné?3 == 3 je true.
!=Jsou číselné hodnoty různé?3 != 3 je false.

Jediné = už znáš: ukládá hodnotu. Dvojité == při porovnání čísel hodnotu nemění.

Porovnej obsah textu

pass.equals("MOON") poskytne true, když je obsahem pass přesně MOON. Malé moon poskytne false: velikost písmen se počítá. Pro porovnání bez rozlišení velkých a malých písmen slouží equalsIgnoreCase, například pass.equalsIgnoreCase("MOON").

U String operátor == zjišťuje, zda jde o tentýž uložený objekt. Stejně znějící odpovědi proto nemusí tímto porovnáním projít. Pro shodu textového obsahu používej equals nebo equalsIgnoreCase. Podrobněji se k objektům vrátíš při práci s vlastními daty.

Úkol: oprav nespravedlivou bránu

Oprav obě boolean otázky: energie stačí od tří včetně; propustka MOON je rozpoznaná bez ohledu na velikost písmen. Zachovej dva samostatné výpisy.

Rovnost patří do pravidla pro energii. U textu hledej operaci, která porovnává obsah a záměrně ignoruje velikost písmen. Neměň přijatou odpověď na pevný text.

Oprav kouzelnický trik

Otevři L02/M10_MagicNumberCards.java. Mysli si číslo a odpovídej, na kterých kartách se vyskytuje. Připravená akce yesAnswer musí považovat malé i velké y za souhlas a n za nesouhlas. boolean před jejím jménem říká, že vrací odpověď true/false. Výraz za return je místo k úpravě.

Pro číslo 5 odpověz postupně y, n, y, n, n, n. Ověř, že funguje také Y. Kontrolu této hry vybereš v L02/Check.java pomocí Program Arguments M10_MagicNumberCards.java.

Teď umíš uložit výsledek porovnání a rozlišit číselnou rovnost od porovnání textového obsahu.
