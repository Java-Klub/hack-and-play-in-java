5.2 Pošli metodě hodnoty

Každé místo na mapě má jiné jméno a polohu. Jedna metoda může připravit všechny popisky, když jí při každém volání dodáš správné hodnoty.

Jména rolí a skutečné hodnoty

Otevři learn/examples/05/MapLabels.java. Předpověz oba řádky.

void main() {
    mark("Portal", 2);
    mark("Dragon", 7);
}

void mark(String name, int position) {
    IO.println(name + " at " + position);
}

Portal at 2
Dragon at 7

String name a int position jsou parameters (parametry) v definici. Pojmenovávají hodnoty, které metoda při volání dostane. Naproti tomu "Portal" a 2 jsou arguments (argumenty): skutečně předané hodnoty v prvním volání.

Voláníname uvnitř markposition uvnitř mark
mark("Portal", 2)Portal2
mark("Dragon", 7)Dragon7

Čárka odděluje jednotlivé role i předané hodnoty. Jejich pořadí, počet a typy musejí souhlasit. Jméno parametru samo žádné údaje nevyhledává. Při dalším volání dostane nové hodnoty.

Argumentem může být také proměnná nebo výpočet: mark("Exit", 2 + 3); předá polohu 5. V definici uvádíš typ a jméno, při volání jen hodnoty nebo výrazy, které je poskytují.

Úkol: portály vozí cestující špatně

Otevři learn/practice/05/PortalRoutes.java. Zadej Start Moon a Finish Mars. Místo cesty tam a zpět vidíš dvakrát Mars → Mars.

Oprav první volání tak, aby vedlo ze start do finish. Druhé má vést zpátky. Uvnitř route oprav výpis tak, aby použil oba parametry ve správných rolích. Názvy planet nezapisuj napevno do výpisu.

Start: Moon
Finish: Mars
Moon -> Mars
Mars -> Moon

Vyzkoušej také Red Planet a Club Base. Zůstávají celé názvy a správný směr? Oba argumenty mají typ String, takže překladač jejich prohození nerozpozná: význam rolí hlídáš ty.

Nápověda: přenes hodnoty do malé tabulky

Pro každé volání si zapiš, jakou hodnotu dostane from a jakou to. Pořadí se určuje u volání, ne podle toho, zda se argument jmenuje stejně jako parametr.

Pošli otázku číselnému stroji

Otevři L02/M11_NumberMachine.java. Spusť jej a sleduj dvojice výsledků. V main přidej další volání compare s vlastním číslem, které pomůže odhalit pravidlo stroje. Zatím nech referenční machine sbalenou a imitation neřeš.

Compare má parametr number, takže compare(-3); připraví jeden pokus se zápornou trojkou. Nepotřebuješ měnit jeho tělo pro každý nový vstup. Opiš si předpověď a skutečný výsledek; v další lekci vyrobíš vlastní napodobeninu.

Teď umíš rozlišit parametr od argumentu a určit, jaké hodnoty metoda při konkrétním volání dostane.
