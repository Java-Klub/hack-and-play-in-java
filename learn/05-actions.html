5.1 Pojmenuj vlastní krok

Dron umí rozsvítit světla a zablikat. Chceš jeho představení měnit skládáním krátkých povelů místo kopírování jejich vnitřností.

Definice čeká, volání ji spustí

Otevři learn/examples/05/DroneShow.java. Než program spustíš, spočítej, kolikrát se objeví FLASH.

void main() {
    wake();
    flash();
    flash();
    IO.println("Show finished");
}

void wake() {
    IO.println("Drone awake");
    IO.println("Lights ready");
}

void flash() {
    IO.println("* FLASH *");
}

Drone awake
Lights ready
* FLASH *
* FLASH *
Show finished

wake a flash jsou naše methods (metody): pojmenované části programu. Dosavadní „připravené akce“ jsou také metody. Jejich definition (definice) popisuje, co mají dělat; call (volání) požádá o provedení.

ZápisCo znamená
void flash() { ... }Definuj metodu flash. Tělo tvoří příkazy mezi složenými závorkami.
flash();Zavolej ji právě tady. Kulaté závorky patří k volání; středník ukončí tento příkaz.
voidToto volání neposkytuje výslednou hodnotu. Může ale něco udělat, například vypsat zprávu.
()Této metodě nepředáváme žádnou hodnotu.

Při spuštění Java začne v main. Dojde na wake(), provede jeho dva výpisy a vrátí se na další příkaz v main. Stejně provede každé volání flash. Definice pod main se samy od sebe nespustí. Jejich pořadí v souboru neurčuje pořadí představení.

Nové metody zapisuj vedle main, za jeho koncovou složenou závorkou. Nevkládej definici jedné metody do těla druhé.

Úkol: ukliď poplach, neměň jeho zvuk

Otevři learn/practice/05/AlarmRemix.java. Poplach funguje, ale stejná dvojice výpisů je zkopírovaná dvakrát.

Vytvoř vedle main metodu void alarm(), která vypíše Intruder! a Lights red. Obě kopie těchto dvou řádků v main nahraď voláním alarm(). Výpisy o dveřích ponech mezi nimi na původních místech.

Celý výstup má zůstat stejný: poplach, dveře A, poplach, dveře B. Tentokrát není cílem změna chování, ale refactoring (úprava struktury při zachování chování).

Nápověda: kam která závorka patří

Main i alarm mají vlastní pár složených závorek. V main zbývají čtyři příkazy: dvě volání a dva výpisy. V alarm jsou dva výpisy.

Jedna úprava, dvě místa

Po úpravě změň pouze uvnitř alarm zprávu Lights red na Lights purple. Po spuštění se musí změnit oba poplachy. Přidej do main třetí zamčené dveře s dalším voláním. Uvnitř alarm nemusíš kvůli třetím dveřím přidávat nic.

Otázka: co udělá samotná definice?

Pokud odstraníš všechna volání alarm z main, definice zůstane v souboru, ale žádný poplach se nevypíše. Zkus předpověď a potom volání vrať.

Teď umíš vytvořit vlastní metodu bez parametrů, zavolat ji vícekrát a sledovat návrat k dalšímu příkazu volajícího.
