3.1 Zeptej se hráče

Robot už umí mluvit. Teď ho naučíš počkat na odpověď a použít ji ve své zprávě.

Program může čekat

Ve Favorites otevři learn/examples/03/NameTag.java a spusť Run File.

void main() {
    String pilot = IO.readln("Pilot name: ");
    IO.println("Welcome, " + pilot + "!");
}

V Output se objeví Pilot name: . Program teď čeká. V dolním panelu Output klikni za výzvu Pilot name:, napiš Nova a potvrď Enter. Zeleně je níže tvoje odpověď; tu nepíše program.

Pilot name: Nova
Welcome, Nova!

Odkud přišla hodnota

ZápisCo se právě děje
IO.readln("Pilot name: ")Vypíše otázku a přečte jeden celý řádek. Čeká, dokud jej nepotvrdíš Enter. Výsledkem volání je zadaný text.
String pilot = ...;Uloží tento výsledek pod jméno pilot. Před odpovědí tento krok ještě není hotový.
IO.println("Welcome, " + pilot + "!");Přečte uloženou odpověď a sestaví pozdrav. Teprve tento krok přidá další vypsaný řádek.

Nové je, že hodnota za = vznikne až při běhu. IO.println něco vypíše; IO.readln ti navíc poskytne text pro další práci. Závorky obou volání nesou předávané hodnoty.

Předpověz dvě odpovědi

Spusť program znovu a místo Nova napiš Red Fox. Potom jej spusť potřetí a stiskni jen Enter. Co čekáš v obou pozdravech?

Porovnej výsledky

Celá odpověď Red Fox zůstane pohromadě, včetně vnitřní mezery. Samotný Enter poskytne prázdný text, takže vznikne Welcome, !. Enter ukončil čtení, ale není součástí uloženého textu. Uvozovky při odpovědi nepíšeš: patří k zápisu textu v Javě, nikoli k běžnému psaní do Output.

Úkol: robot opakuje tvoje heslo

Otevři learn/practice/03/EchoRoom.java. Robot stále opakuje svoje staré offline.

Nahraď pevné heslo čtením odpovědi s otázkou Your code: . Zadanou hodnotu ponech ve code; připravený výpis ji má zopakovat. S odpovědí Open sesame čekej:

Your code: Open sesame
Robot repeats: Open sesame

Zkus ještě jiné heslo. Musí se změnit výsledek bez další změny zdrojového souboru.

Nápověda

Podívej se, odkud získává pilot svoji hodnotu. Volání pro čtení patří na pravou stranu při zavedení code. Text otázky obsahuje mezeru za dvojtečkou.

Program čeká, ale nic se nestalo

Odpověď piš do Output spuštěného programu a potvrď Enter. Psaní do editoru mění zdroják. Když vstup místo potvrzení ukončíš, čtení může poskytnout zvláštní hodnotu null; pro tento pokus program znovu spusť a napiš běžnou odpověď.

Teď umíš nechat hodnotu zadat hráče a použít ji později v programu.
