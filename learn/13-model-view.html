13.5 Nech kreslení pozorovat model

Okno se může překreslit po odkrytí, změně velikosti nebo požadavku Swingu. Žádná taková událost neznamená, že hráč získal bod. Spusť HitMeter: počet zelených polí mění jen Hit a Reset začíná znovu.

import java.awt.*;
import java.awt.image.BufferedImage;
import javax.swing.*;

int points = 0;

boolean hit() {
    if (points >= 5) return false;
    points++;
    return true;
}

void reset() {
    points = 0;
}

void draw(Graphics2D g) {
    for (int i = 0; i < 5; i++) {
        g.setColor(i < points ? Color.GREEN : Color.LIGHT_GRAY);
        g.fillRect(10 + i * 30, 10, 24, 40);
    }
}

void main() {
    SwingUtilities.invokeLater(() -> {
        var panel = new JPanel() {
            @Override protected void paintComponent(Graphics graphics) {
                super.paintComponent(graphics);
                draw((Graphics2D) graphics);
            }
        };
        panel.setPreferredSize(new Dimension(170, 60));
        panel.setBackground(Color.WHITE);
        var hit = new JButton("Hit");
        hit.addActionListener(event -> { hit(); panel.repaint(); });
        var reset = new JButton("Reset");
        reset.addActionListener(event -> { reset(); panel.repaint(); });
        var buttons = new JPanel();
        buttons.add(hit);
        buttons.add(reset);
        var frame = new JFrame("Hit Meter");
        frame.setDefaultCloseOperation(JFrame.DISPOSE_ON_CLOSE);
        frame.add(panel);
        frame.add(buttons, BorderLayout.SOUTH);
        frame.pack();
        frame.setLocationByPlatform(true);
        frame.setVisible(true);
    });
}

Model (uložený stav a pravidla) tvoří points a akce, které je mění. View (zobrazení) body čte a kreslí jejich podobu. Posluchač je propojí: požádá model o změnu a potom vyžádá nové kreslení.

Všimni si, že draw nic nezvětšuje. Jedno i deset volání nechá points beze změny. Pět obdélníků představuje totéž uložené číslo, nikoli pět nezávislých počítadel.

Hit vlastní změnu stavu a ověří mez před jakoukoli změnou. Šestý zásah vrátí false a zachová pět. Reset vlastní jinou změnu. Oddělení pravidel od kreslení dovolí model vyzkoušet také bez otevírání okna.

Předpověz odkryté okno

Po dvou zásazích je points dva. Několikrát zakryj a odkryj okno: hodnota zůstane dva. Třetí zásah ji změní na tři. Co mají udělat dvě volání draw po resetu?

Úkol: odstraň bonus za překreslení

V learn/practice/13/ScoreBadge.java skóre chybně zvětšuje kreslení, zatímco Hit nic nedělá. Přenes odpovědnost do hit: každé přijaté volání přidá právě jedna, trojka vyhrává a další zásahy vracejí false bez změny score.

Draw musí dál umět zobrazit běžný i vítězný stav, ale smí je jen číst. Reset musí obnovit nulu a následné kreslení ji musí zachovat. Zkus dva zásahy, několik překreslení, vítězný zásah, další zásah a Reset.

Neopravuj viditelný příznak odečítáním bodu někde jinde. Rozhodni, která událost smí měnit stav. Výsledek nesmí záviset na tom, jak často operační systém požádá okno o kreslení.

Nápověda 1: dvě různé odpovědnosti

Odstraň změnu score z draw a vlož přijatou změnu do hit.

Nápověda 2: zastav před zvětšením

Nejprve ověř mez výhry. Potom přidej jedna a vrať true; odmítající cesta vrací false.

Teď máš pravidla, která lze volat a ověřovat nezávisle na zobrazení. Poslední kapitola toto oddělení využije pro testy, zaměnitelné chování a větší návrhy.
