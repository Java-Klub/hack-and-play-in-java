4.2 Choose what happens

The radar knows how far away the dragon is. It should use that distance to print one message. You will now use a boolean answer to choose the next step.

One path based on the answer

Open learn/examples/04/DragonRadar.java. First predict the result for -1, 3 and 4.

void main() {
    int distance = Integer.parseInt(IO.readln("Distance: ").strip());
    if (distance < 0) {
        IO.println("Behind you");
    } else if (distance <= 3) {
        IO.println("Very close");
    } else {
        IO.println("Far away");
    }
}
Compare your predictions

For -1 it prints Behind you, for 3 Very close, and for 4 Far away. There is exactly one message each time.

if asks the boolean question inside its parentheses. If it is true, the block between the following braces runs. If it is false, the program moves on to else if. The final else covers all remaining cases.

Once a branch in this chain is chosen, the others are skipped. For -1, distance <= 3 is also true, but that later question never gets asked.

A block can contain several steps: printing, assignments and other calls. Braces determine which steps belong to each branch. We do not add another semicolon after closing the whole if/else chain here.

Task: the alarm must not speak twice

Open learn/practice/04/DroneAlarm.java. For distance 2, it prints both Near and Danger. Read how many separate questions it asks.

Rebuild the decision as one if / else if / else chain with a single resulting message:

DistanceMessage
2 or lessDanger
More than 2, up to 5Near
More than 5Clear

Try 0, 2, 3, 5 and 6. Each run must produce exactly one message. For 2, expect:

Distance: 2
Danger
Hint 1: which case takes priority?

Consider the closest distance first. If everything up to five were chosen earlier, the closest case would never get its own turn in the chain.

Hint 2: separate if statements

Two separate if statements ask independent questions. Else if belongs to the previous decision and only asks its question when the preceding branch did not match.

Decide who won

In L03/M03_BlackjackTwentyOne.java, you will complete the supplied compareTotals action. It receives the numbers human and house. Based on them, return should give back one message:

humanhouseResult

A player over 21 has lost before ordinary totals are compared. After that, consider a dealer over 21, the larger valid total, or equality. As soon as return runs, this action call ends and hands its text to the supplied game. Do not print the message inside compareTotals instead of returning it. To check your work, use L03/Check.java and M03_BlackjackTwentyOne.java.
