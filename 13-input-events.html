13.2 Proměň kliknutí ve volbu

Okno může čekat na akce bez konzolové otázky. Spusť ClickSlots a klikej na tři šedé dlaždice. Vybraná dlaždice zezelená; další kliknutí výběr změní.

import java.awt.*;
import java.awt.image.BufferedImage;
import javax.swing.*;

int picked = -1;

void choose(int x, int y) {
    if (x < 0 || x >= 120 || y < 0 || y >= 40) return;
    picked = x / 40;
}

void draw(Graphics2D g) {
    for (int slot = 0; slot < 3; slot++) {
        g.setColor(slot == picked ? Color.GREEN : Color.LIGHT_GRAY);
        g.fillRect(slot * 40 + 2, 2, 36, 36);
    }
}

void main() {
    SwingUtilities.invokeLater(() -> {
        var panel = new JPanel() {
            @Override protected void paintComponent(Graphics graphics) {
                super.paintComponent(graphics);
                draw((Graphics2D) graphics);
            }
        };
        panel.setPreferredSize(new Dimension(120, 40));
        panel.setBackground(Color.WHITE);
        panel.addMouseListener(new java.awt.event.MouseAdapter() {
            @Override public void mousePressed(java.awt.event.MouseEvent event) {
                choose(event.getX(), event.getY());
                panel.repaint();
            }
        });
        var frame = new JFrame("Click Slots");
        frame.setDefaultCloseOperation(JFrame.DISPOSE_ON_CLOSE);
        frame.add(panel);
        frame.pack();
        frame.setLocationByPlatform(true);
        frame.setVisible(true);
    });
}

Mouse event (událost myši) popisuje jednu akci včetně její polohy. addMouseListener zaregistruje objekt, jehož mousePressed Swing později zavolá. MouseAdapter nabízí prázdná zpracování ostatních oznámení myši, proto program nahrazuje jen potřebné zpracování.

Souřadnice události se vztahují k této ploše, nikoli k celé obrazovce nebo rámu okna. Callback (zpětné volání) předá do choose obyčejné argumenty int. Metoda změní model (uložený stav); repaint požádá Swing, aby ukázal jeho aktuální hodnotu.

repaint kreslení naplánuje. Nevolej draw s ručně získaným nástrojem obrazovky a neočekávej, že se obrazovka změní ještě před návratem repaint. Swing podle potřeby spojí čekající žádosti o kreslení.

Guard (ochranná podmínka) před dělením odmítne pozice mimo pás. Pro nezáporné x přiřadí celočíselné dělení čtyřiceti pozice 0..39 dlaždici nula, 40..79 dlaždici jedna a 80..119 dlaždici dva. Počáteční −1 označuje žádný výběr.

Předpověz okraj

Kliknutí na (80,20) vybere dlaždici dva. Požadavek (120,20) se odmítne a zachová předchozí výběr. Co vybere (39,0)?

Úkol: vybírej všechny čtyři dlaždice

Oprav choose v code/FourTiles.java. Plocha má 160 krát 160 obrazových bodů a dělí se do dvou řádků a dvou sloupců velikosti 80. Dlaždice čísluj zleva doprava, potom shora dolů: 0, 1, 2, 3.

Použij obě souřadnice a bez změny picked odmítni x nebo y mimo 0..159. Ověř čtyři rohy, hranici x=80 i bod těsně za každým okrajem. Připravený posluchač i kreslení již fungují.

Nápověda 1: dvě nezávislé souřadnice

Z x vypočítej sloupec a z y řádek. Dolní dlaždice potřebuje jiné číslo, i když se x nezměnilo.

Nápověda 2: spoj souřadnice až po ověření

Po ochranné podmínce použij řádek krát počet sloupců plus sloupec.

Vyzkoušej pravidlo přímo a potom vrať okno

Kliknutí mimo plochu se tomuto posluchači nepředá. Pro ověření mezí metody si nejprve uschovej původní main v dočasném textovém dokumentu. Nahraď pouze tuto metodu následujícím konzolovým pokusem; choose, draw, uložené hodnoty i import zachovej.

void main() {
    choose(10, 100);
    IO.println(picked);
    choose(159, 159);
    IO.println(picked);
    choose(-1, 0);
    choose(160, 20);
    choose(20, -1);
    choose(20, 160);
    IO.println(picked);
    choose(80, 0);
    IO.println(picked);
}

S opraveným pravidlem jsou čtyři vypsané hodnoty 2, 3, 3 a 1. Volání mimo rozsah zachovají předchozí výběr. Potom vlož původní GUI main zpět, ulož a znovu spusť klikací verzi.

Posluchač má zůstat krátký. Dále necháš několik tlačítek používat jedno pojmenované zpracování.
