10.2 Remember a first visit

An explorer should receive a discovery message once per place, even after walking in circles. You could scan a list each time, but a set directly represents membership: a value is either present or absent. It does not store duplicate entries.

One operation can answer and remember

void main() {
    Set<String> badges = new HashSet<>();
    IO.println("First Moon: " + badges.add("Moon"));
    IO.println("Second Moon: " + badges.add("Moon"));
    badges.add("Sun");
    IO.println("Has Sun: " + badges.contains("Sun"));
    IO.println("Unique badges: " + badges.size());
}

Open code/BadgeSet.java. Set<String> describes unique String elements; HashSet is its prepared implementation. The diamond <> again takes its element type from the declaration. A set has size and membership operations, but no numbered position such as get(0).

Add returns true when it inserts a new element and false when an equal element is already present. It still remembers Moon after the second call. Contains only asks a question; it does not insert anything. Size counts distinct values, not attempted insertions.

HashSet does not promise the order of its elements. Do not judge a discovery log by printing the whole set and expecting input order. Print the message at insertion time instead. For Strings, equality is case-sensitive: Moon and moon are different names in this lesson.

Predict another badge

Adding Sun again returns false and leaves size 2. What would contains("Star") return before insertion? False. Calling it repeatedly still leaves Star absent because a question does not change membership.

Task: announce only real discoveries

Open code/FirstVisits.java. The prepared loop reads place names until an empty answer. Replace the unconditional first result with an operation that both remembers the place and tells whether this is its first appearance. Keep the existing condition and final count.

Enter Moon, Moon, Sun and then an empty line. Expect discovery messages for Moon and Sun only, with Unique places: 2. Ending immediately gives 0. Spaces around a name are stripped before comparison; do not change the internal spelling or letter case.

Hint 1: choose a changing operation

A contains question can recognize a repeat only if something has already stored the name. Find the operation that returns whether insertion happened.

Hint 2: use the returned boolean

Let the prepared if use the answer from the set. There is no need for a second counter or an extra search loop.

Next, remember not just which place appeared, but an associated number such as its accumulated score.
