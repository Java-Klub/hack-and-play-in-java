11.2 Each robot has its own battery

Two robots share the same instructions but not one battery. A class describes their common behavior, while every instance carries its own field values. Construction is the moment to give each robot a meaningful starting state.

The constructor receives the starting data

void main() {
    Drone first = new Drone("Dot", 5);
    Drone second = new Drone("Dash", 8);
    first.move();
    IO.println(first.name + ": " + first.charge);
    IO.println(second.name + ": " + second.charge);
}

class Drone {
    String name;
    int charge;

    Drone(String name, int charge) {
        this.name = name;
        this.charge = charge;
    }

    void move() {
        charge = charge - 1;
    }
}

Open code/TwoDrones.java. Drone(String name, int charge) is a constructor. It has the class name and no return type, not even void. New Drone("Dot", 5) creates an object and runs this constructor with those arguments.

The parameter name temporarily hides the field name. This.name means the field belonging to the object being constructed; the plain name on the right means the parameter. Assignment copies the supplied text reference into the field. This.charge similarly stores the number.

Each new expression creates another instance. First.move() changes only first’s charge, from 5 to 4. Second still has 8. Both calls would use the same method definition, but the receiver determines which object’s fields that method reads and writes.

Predict a different receiver

Calling second.move() once as well makes Dash: 7. What if another variable is assigned first and move is called through it? Dot changes again: copying a reference does not create a third drone.

Task: feed only the intended robot

Open code/PetBots.java. Make the constructor store its supplied name and energy. Make feed add amount to the receiver’s existing energy instead of replacing it. Preserve the two constructed robots and the prepared call feeding only first.

With food 3, expect Dot: 5 and Dash: 6. With food 0, expect Dot: 2 and Dash: 6. With food 7, Dot becomes 9. Use amounts from 0 to 100. Limits and rejected operations come in the next lesson.

Hint 1: find which name means which value

In the constructor, distinguish this.energy from parameter energy. Assigning energy to itself would leave the field at its default 0.

Hint 2: feeding uses the saved state

Read the existing field before adding the parameter. Do not recreate the robot or reset its name inside feed.
