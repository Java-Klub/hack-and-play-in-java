6.1 Opakuj, dokud je potřeba

Dron má prázdnou baterii. Nabíječka při každém kroku přidá dvě jednotky a vypíše nový stav. Nechceš stejný krok šestkrát opisovat; chceš popsat, kdy ještě pokračovat.

Otázka před každým kolem

Otevři code/DroneCharge.java. Nejdřív odhadni, kolik řádků program vypíše.

void main() {
    int energy = 0;
    while (energy < 6) {
        energy = energy + 2;
        IO.println("Energy: " + energy);
    }
    IO.println("Ready");
}

While loop (cyklus while) opakuje tělo mezi složenými závorkami, dokud condition (podmínka) v kulatých závorkách platí. Otázku položí před prvním kolem i po každém dokončeném kole. S energií 0 projde první test, vznikne 2 a vypíše se. Další kola vytvoří 4 a 6. Pak už 6 není menší než 6 a pokračuje se za cyklem.

Assignment (přiřazení) uvnitř těla mění hodnotu, kterou bude číst další test. Bez něj by energie zůstala nulová a vznikl by infinite loop (nekonečný cyklus). Kdyby se to při pokusu stalo, zastav spuštěný program tlačítkem Stop v Output. Samotná podmínka hodnotu neposouvá.

Předpověď: co když začneš na 6?

Tělo neproběhne ani jednou. Uvidíš jen Ready. While neslibuje alespoň jedno kolo; nejprve se ptá.

Úkol: hlas odpočítává jen jednou

Otevři code/LaunchCount.java. Pro vstup 3 zatím zazní jen 3 a Launch. Nahraď jednorázový krok opakováním: vypiš všechna kladná čísla od zadané hodnoty dolů po jedné. Po dokončení vypiš Launch právě jednou.

Zkoušej počáteční hodnoty od 0 do 9. Pro 3 potřebuješ řádky 3, 2, 1, Launch. Pro 1 vznikne 1, Launch. Pro 0 pouze Launch; nulu do odpočtu nepřidávej. Výzva Start zůstává beze změny.

Nápověda 1: co se opakuje?

Výpis aktuálního čísla a jeho snížení patří do stejného těla. Závěrečné Launch se opakovat nemá.

Nápověda 2: sleduj poslední kolo

Po vypsání jedničky musí hodnota přejít na nulu. Další test ji odmítne. Sepiš si hodnoty před testem a po změně.
