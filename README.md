# Hack & Play in Java

**[English](https://github.com/Java-Klub/hack-and-play-in-java/tree/main) · [Česky](https://github.com/Java-Klub/hack-and-play-in-java/tree/ceska-verze)**

**Nauč se programovat v Javě. A pak změň pravidla hry.**

![Šest programů z Hack & Play in Java: MiniInvaders, MiniPacman, MirrorLaser, SunflowerSpiral, ReactionDiffusionSkins a FractalTreeGarden.](cover.png)

Zažeň vetřelce, proveď laser mezi zrcadly nebo oživ vlastní obrázek. V učebnici nejprve pochopíš potřebný kousek Javy. Potom jej použiješ k opravě, dokončení nebo proměně malého programu.

## Začni učebnicí

**[Otevři učebnici →](learn/README.md)**

Pořadí určuje učivo: krátký výklad → spustitelný příklad → vlastní úprava programu → ověření výsledku. Dřívější dovednosti se vracejí v nových souvislostech. Předchozí znalost programování nepotřebuješ.

Všech **145 her, hádanek a tvořivých programů** postupně začleňujeme do kapitol jako procvičení. Každý dostane místo podle potřebných znalostí, výklad před úkolem a srozumitelný cíl. Při zapracování upravujeme i samotná zadání. Složky se zdrojovými soubory slouží tomuto společnému postupu učebnicí.

**Hotové jsou první dvě kapitoly** s pěti lekcemi, přípravou prostředí a slovníčkem. Pokrývají čtení a spuštění programu, pořadí kroků, hodnoty, jejich změny a výpočty. Další kapitoly jsou v obsahu označené jako plán.

## Otevři kurz v NetBeans

Potřebuješ **JDK 26 nebo novější** a NetBeans s podporou Java source file launcheru.

1. Stáhni a rozbal celou jazykovou větev kurzu.
2. V NetBeans otevři **Window → Favorites**. V okně Favorites zvol **Add to Favorites…** a přidej hlavní složku s tímto README.
3. Pokračuj podle [úvodní lekce](learn/00-start.md). Soubory budeš otevírat přímo ve Favorites, ukládat a spouštět přes **Run → Run File** (`Shift+F6`). Stejně spustíš i připravené kontroly.

Na GitHubu čti Markdown z odkazu na učebnici. Pro čtení offline otevři `learn/index.html` z rozbalené složky. Výklad, příklady i programy máš po stažení u sebe.

## Co si postupně osvojíš

| Co chceš umět | Co k tomu použiješ |
| --- | --- |
| Přečíst a změnit malý program | Statements (příkazy), values (hodnoty), variables (proměnné), text a výpočty |
| Zapsat herní pravidlo | Conditions (podmínky), methods (metody), loops (cykly) a kontroly chování |
| Postavit herní svět | Arrays (pole), grids (mřížky), records, `List`, `Set` a `Map` |
| Oživit a rozšířit program | State (stav), callbacks, časové kroky, soubory, interfaces (rozhraní) a pattern matching |

Programy používají moderní Javu a knihovny JDK. Výklad vede od konkrétních malých příkladů k vlastním programům; nápovědy k úkolům otevíráš podle potřeby.
