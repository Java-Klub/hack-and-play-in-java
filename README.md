# Hack & Play in Java

**[English](https://github.com/Java-Klub/hack-and-play-in-java/tree/main) · [Česky](https://github.com/Java-Klub/hack-and-play-in-java/tree/ceska-verze)**

**Learn to program in Java. Then change the rules of the game.**

![Six programs from Hack & Play in Java: MiniInvaders, MiniPacman, MirrorLaser, SunflowerSpiral, ReactionDiffusionSkins and FractalTreeGarden.](cover.png)

Send aliens packing, steer a laser through mirrors or bring your own picture to life. First, the textbook explains the piece of Java you need. Then you use it to repair, finish or transform a small program.

## Start with the textbook

**[Open the textbook →](learn/README.md)**

Skills determine the route: a short explanation → a runnable example → your own program change → checking the result. Earlier skills return in new combinations. You do not need previous programming experience.

All **145 games, puzzles and creative programs** are being incorporated into the chapters as practice. Each gets a place based on the knowledge it needs, an explanation before the task and a clear goal. We also adapt the tasks as we integrate them. The source folders support this shared route through the textbook.

**The first two chapters are ready**, with five lessons, setup instructions and a glossary. They cover reading and running a program, statement order, values, changing values and calculations. The contents mark later chapters as planned.

## Open the course in NetBeans

You need **JDK 26 or later** and NetBeans with Java source file launcher support.

1. Download and extract the whole course branch in your language.
2. In NetBeans, choose **Window → Favorites**. In the Favorites window, choose **Add to Favorites…** and add the main folder containing this README.
3. Follow the [setup lesson](learn/00-start.md). You will open files directly from Favorites, save them and run them with **Run → Run File** (`Shift+F6`). Prepared checks run the same way.

On GitHub, read the Markdown textbook using the link above. To read offline, open `learn/index.html` from the extracted folder. After downloading, the explanations, examples and programs are all on your computer.

## What you will learn

| What you want to do | What you will use |
| --- | --- |
| Read and change a small program | Statements, values, variables, text and calculations |
| Write a game rule | Conditions, methods, loops and behavioural checks |
| Build a game world | Arrays, grids, records, `List`, `Set` and `Map` |
| Bring a program to life and extend it | State, callbacks, time steps, files, interfaces and pattern matching |

The programs use modern Java and JDK libraries. Explanations lead from concrete small examples to your own programs; open task hints as you need them.
