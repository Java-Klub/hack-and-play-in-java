4.5 Vyber hodnotu pomocí switch

Kouzelnická kniha přijme slovo a vybere efekt. Několik přesných možností můžeš přehledně přiřadit k výsledkům.

Jeden vstup, jedna vybraná hodnota

Otevři 04-decisions/P16_Example_SpellBook.java.

/// # Hotový příklad · 4.5 Vyber hodnotu pomocí switch
/// Lekce: 05-switch.html

void main() {
    String spell = IO.readln("Spell: ").strip().toLowerCase(Locale.ROOT);
    String effect = switch (spell) {
        case "red", "r" -> "Fire";
        case "blue", "b" -> "Ice";
        case "green", "g" -> "Vines";
        default -> "Fizzle";
    };
    IO.println("Effect: " + effect);
}

Spell:  B 
Effect: Ice

toLowerCase(Locale.ROOT) je protějšek dřívějšího toUpperCase: poskytne text malými písmeny. Po očištění a převodu tedy odpověď B znamená b.

ČástVýznam
switch (spell)Přečti hodnotu spell a vyber odpovídající možnost.
case "blue", "b" -> "Ice";Pro kteroukoli z obou přesných hodnot poskytni text Ice. Čárka sdružuje možnosti.
default -> "Fizzle";Výsledek pro vše, co se neshodovalo s žádnou uvedenou možností.
String effect = ...;Ulož vybraný výsledek pod jménem effect.

Tomuto zápisu říkáme switch expression (výraz switch), protože má hodnotu. Provede se jen vybraná možnost. Středník za } ukončuje celé přiřazení. Potom println vypíše uložený efekt.

Podmínky if mohou posuzovat rozsahy a více různých otázek. Tento switch vybírá podle přesné hodnoty jediného vstupu. Všechny zde vybrané výsledky jsou text, aby šly uložit do String.

Úkol: oprav porouchané rádio

Otevři 04-decisions/P17_Task_RepairRadio.java. Známý povel odmítne, neznámý naopak přeloží jako Move.

Uprav switch tak, aby po připraveném očištění a převodu písmen vybíral tyto výsledky. Krátké a dlouhé zápisy sdružuj do jednoho case.

Přijatý povelAction
go nebo gMove
look nebo lScan
rest nebo rRecharge
Vše ostatní, včetně prázdného řádkuUnknown command

Zkus každý dlouhý i krátký zápis a také jump. S odpovědí L očekávej:

Command:  L 
Action: Scan
Nápověda

Výsledek se vybírá už za šipkou. Výpis potom jen připojí tento hotový text k popisku. Nezapomeň opravit také default, aby neznámé povely nedostaly běžnou akci.

Jak rozlišit čtyři kombinace

Ve hře se dvěma volbami pomůže každé kombinaci přidělit jiné číslo. Otevři 04-decisions/P18_Example_ControlPanel.java:

/// # Hotový příklad · 4.5 Vyber hodnotu pomocí switch
/// Lekce: 05-switch.html

void main() {
    boolean lights = true;
    boolean music = false;
    int mode = 0;
    if (lights) {
        mode = mode + 1;
    }
    if (music) {
        mode = mode + 2;
    }
    IO.println("Mode: " + mode);
}

Změnou dvou počátečních boolean hodnot můžeš vyzkoušet všechny čtyři režimy:

lightsmusicmode
falsefalse0
truefalse1
falsetrue2
truetrue3

Jsou tu dvě samostatná if: obě zapnuté volby se mají přičíst. Pro výběr výsledku podle tohoto mode pak můžeš použít switch s možnostmi 0, 1, 2 a 3. Také u čísel doplň default pro zbývající hodnoty. Překladač neumí z tohoto výpočtu odvodit, že jiné číslo nevznikne; výraz musí poskytovat výsledek pro každou možnou hodnotu int.

Vyber odměnu nebo povol kartu

  • 04-decisions/P19_Task_CooperateOrDefect.java: každý hráč soukromě zvolí spolupráci nebo zradu. Připravené reward dostane dvě boolean hodnoty a má vrátit jednu číselnou odměnu. Rozliš čtyři kombinace a podle pravidel v zadání vyber odměnu pomocí switch. Neutrální ControlPanel ukazuje, jak si vytvořit číselný klíč; sčítané hodnoty odměn si s tímto klíčem nepleť.
  • 04-decisions/P20_Task_CrazyEightsSimpleMauMau.java: nejprve odmítni kód karty mimo 0 až 51. Připravené rank(card) poskytne hodnotu 2 až 14; barvu zjistíš pomocí card / 13. Osmička je povolená vždy, ostatní karty musejí odpovídat hodnotě karty top nebo barvě suit. Použij switch pro zvláštní hodnotu a v běžném výsledku spoj dvě možnosti přijetí. Stačí upravit rozhodčího legal; rozdělování karet je připravené.

Obě úlohy ověří 04-decisions/Check.java; v Program Arguments vyber řešený program. Stejný if nebo switch může měnit chování mnoha částí hry, když se všechny ptají jednoho společného rozhodčího.

Teď umíš vybrat výsledek podle konkrétní hodnoty a zkombinovat výběr s podmínkami i bezpečným odmítnutím.
