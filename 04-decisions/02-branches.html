4.2 Vyber, co se stane

Radar zná vzdálenost draka. Podle ní má vypsat jednu zprávu. Boolean odpověď teď použiješ k výběru dalšího kroku.

Jedna cesta podle odpovědi

Otevři 04-decisions/P05_Example_DragonRadar.java. Nejdřív předpověz výsledek pro -1, 3 a 4.

/// # Hotový příklad · 4.2 Vyber, co se stane
/// Lekce: 02-branches.html

void main() {
    int distance = Integer.parseInt(IO.readln("Distance: ").strip());
    if (distance < 0) {
        IO.println("Behind you");
    } else if (distance <= 3) {
        IO.println("Very close");
    } else {
        IO.println("Far away");
    }
}
Porovnej předpovědi

Pro -1 se vypíše Behind you, pro 3 Very close a pro 4 Far away. Vždy vznikne právě jedna zpráva.

if se ptá na boolean výraz v kulatých závorkách. Když je true, provede block (blok) mezi následujícími složenými závorkami. Když je false, pokračuje k else if. Závěrečné else použije pro všechny zbývající případy.

Jakmile se v tomto řetězci vybere jedna branch (větev), ostatní se přeskočí. Při -1 je pravdivé také distance <= 3, ale tato pozdější otázka už na řadu nepřijde.

Blok může obsahovat více kroků: výpis, přiřazení i další volání. Složené závorky určují, které kroky do dané větve patří. Za uzavřením celého if/else řetězce tu další středník nepíšeme.

Úkol: poplach nesmí mluvit dvakrát

Otevři 04-decisions/P06_Task_DroneAlarm.java. Pro vzdálenost 2 vypíše Near i Danger. Přečti, kolik samostatných otázek se v něm provádí.

Přestav rozhodování na jeden if / else if / else řetězec s jedinou výslednou zprávou:

VzdálenostZpráva
2 a méněDanger
Více než 2, nejvýše 5Near
Více než 5Clear

Zkus 0, 2, 3, 5 a 6. Při každém spuštění musí zaznít právě jedna zpráva. Pro 2 očekávej:

Distance: 2
Danger
Nápověda 1: kdo má přednost

Uvažuj nejprve nejbližší vzdálenost. Pokud by se dřív vybralo vše do pěti, pro nejbližší případ už by v řetězci nezbyla příležitost.

Nápověda 2: samostatné if

Dvě samostatná if se ptají nezávisle. Else if patří k předchozímu rozhodování a ptá se pouze tehdy, když předchozí větev neuspěla.

Rozhodni, kdo vyhrál

V 04-decisions/P07_Task_BlackjackTwentyOne.java dokončíš připravenou akci compareTotals. Dostane čísla human a house. Podle nich má return vrátit jednu zprávu:

humanhouseVýsledek
2019You win
2121Draw
1822You win
2223You bust
1820Dealer wins

Hráč nad 21 prohrál ještě před porovnáním běžných součtů. Po něm rozhoduje dealer nad 21, větší platný součet nebo rovnost. Jakmile se provede return, toto volání akce končí a předává text připravené hře. Zprávu tedy nevypisuj uvnitř compareTotals místo jejího vrácení. Pro kontrolu použij 04-decisions/Check.java a P07_Task_BlackjackTwentyOne.java.

Teď umíš vybrat jednu z několika cest a vysvětlit, proč na pořadí otázek záleží.
