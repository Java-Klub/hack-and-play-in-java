4.1 Ask a question in code

The door needs three units of energy. Until now, you have calculated how much would remain. Now you will answer a question: is there enough in the first place?

An answer of true or false

Open 04-decisions/P01_DoorQuestion.java. Enter energy 3 and the pass MOON.

void main() {
    int energy = Integer.parseInt(IO.readln("Energy: ").strip());
    String pass = IO.readln("Pass: ");
    boolean enough = energy >= 3;
    boolean recognised = pass.equals("MOON");
    IO.println("Enough energy: " + enough);
    IO.println("Recognised pass: " + recognised);
}

Energy: 3
Pass: MOON
Enough energy: true
Recognised pass: true

boolean is a type with two values: true means yes and false means no. These are Java values, written in lowercase without quotes. Like an int, you can store a boolean under a name, use it and print it.

energy >= 3 is a comparison. It gives a boolean: true for three units, false for two. The variable enough therefore stores the answer to a question. Printing the answer does not open a door yet; this program only evaluates two questions.

Compare numbers

NotationQuestionExample
< / >Is the number smaller / larger?3 > 3 is false.
<= / >=Is it smaller or equal / larger or equal?3 >= 3 is true.
==Are the numeric values equal?3 == 3 is true.
!=Are the numeric values different?3 != 3 is false.

You already know a single =: it stores a value. The double == compares numbers without changing their values.

Compare the contents of text

pass.equals("MOON") gives true when pass contains exactly MOON. Lowercase moon gives false: letter case matters. To compare without distinguishing uppercase and lowercase, use equalsIgnoreCase, as in pass.equalsIgnoreCase("MOON").

For a String, the == operator asks whether it is the very same stored object. Answers containing the same text may therefore fail that comparison. Use equals or equalsIgnoreCase to compare text contents. You will return to objects in more detail when working with your own data.

You can now store a comparison's result and distinguish numeric equality from comparing text contents.

What does the question mark in the club door mean?

ClubDoor selects its message with the shorthand condition ? first : second. This is a conditional expression: true selects the first value, otherwise the second. IO.println(ready ? "Go" : "Wait"); therefore prints Go when ready is true. Today you are following the data supplied to the condition, leaving this supplied selection in place.
