8.3 Ptej se okolních buněk

Senzor nepotřebuje přečíst celou mapu: zajímá ho nejbližší okolí vybraného místa. Nejdřív si ale musíš ujasnit pravidla sousedství. Počítají se i rohy? Počítá se vlastní buňka?

Malý průchod kolem středu

Otevři code/NeighbourScan.java. Jednička znamená zapnutou buňku. Vyber střed 1, 1.

void main() {
    int[][] board = {{0, 1, 0}, {1, 1, 1}, {0, 1, 0}};
    int x = Integer.parseInt(IO.readln("X: ").strip());
    int y = Integer.parseInt(IO.readln("Y: ").strip());
    IO.println("Neighbours: " + neighbours(board, x, y));
}

int neighbours(int[][] board, int x, int y) {
    int count = 0;
    for (int dy = -1; dy <= 1; dy++) {
        for (int dx = -1; dx <= 1; dx++) {
            if (dx != 0 || dy != 0) {
                int nx = x + dx;
                int ny = y + dy;
                if (inside(board, nx, ny) && board[ny][nx] == 1) {
                    count++;
                }
            }
        }
    }
    return count;
}

boolean inside(int[][] board, int x, int y) {
    return x >= 0 && x < board[0].length && y >= 0 && y < board.length;
}

Nested loops (vnořené cykly) procházejí všechny dvojice posunů. Pro každé dy od -1 do 1 proběhne celé dx od -1 do 1. Jde o devět dvojic; každá popisuje místo vzhledem ke středu, nikoli absolutní souřadnice.

Offset (posun) -1, 0 znamená jeden sloupec doleva, posun 1, 1 diagonálně doprava dolů. Dvojice 0, 0 označuje vlastní buňku, proto ji odmítáme. Zbývá nejvýše osm sousedů včetně diagonál.

Souřadnice souseda vzniknou přičtením posunu ke středu. Než je použijeme, zavoláme inside. Díky AND se čtení buňky neprovede, pokud místo leží mimo mapu. Soused za okrajem se tedy nepočítá a nepřechází na opačnou stranu.

Předpověď: střed a levý horní roh

Střed má čtyři zapnuté sousedy; jeho vlastní jednička se nepočítá. Roh 0, 0 má tři: doprava, dolů a diagonálně doprava dolů.

Úkol: senzor vidí pouze čtyři směry

Otevři code/CardinalSensors.java. Doplň cardinal tak, aby počítalo jedničky pouze vlevo, vpravo, nad a pod místem. Diagonály a vlastní buňku nezahrnuj. Připravené isOn vrátí false i mimo mapu.

Zadávej x a y od 0 do 2. Pro 1, 1 čekej Neighbours: 2. Pro 0, 0 je odpověď 1; pro 2, 0 je 2; pro 0, 2 je 0. Tyto případy odlišují směry, roh i prázdné okolí.

Nápověda 1: nakresli čtyři kandidáty

Ke středu si napiš čtyři dvojice souřadnic. Každý kandidát mění právě jednu souřadnici o jednu.

Nápověda 2: bezpečné otázky

Každé kladné isOn přidá jednu do výsledku. Pomocník už vyřeší okraje; jeho vnitřní pravidlo nemusíš čtyřikrát opisovat.

Příště využiješ průchod řádky a sloupci pro vytvoření nového vzoru, nejen pro čtení hotových dat.

Čtyři porty v jediném čísle

Net ukládá sever, východ, jih a západ jako příznaky s hodnotami 1, 2, 4 a 8. Číslo 5 znamená sever a jih, protože obsahuje 1 + 4. Výraz 1 << direction vytvoří masku pro směr 0 až 3. (ports & mask) != 0 potom ověří přítomnost konkrétního portu. Jediné & porovnává bity čísel; dvojité && spojuje boolean podmínky. Nejde o zaměnitelné zápisy.

Pro spojení ověř oba konce: protilehlý směr je (direction + 2) % 4. Nejdřív ověř souřadnice souseda, teprve potom čti jeho porty. Hledání celé sítě je připravené; tvůj rozhodčí posuzuje jeden místní spoj.
