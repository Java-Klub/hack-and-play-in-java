3.1 Ask the player

The robot can already talk. Now you will teach it to wait for an answer and use it in a message.

A program can wait

In Favorites, open 03-text-input/P01_NameTag.java and use Run File.

void main() {
    String pilot = IO.readln("Pilot name: ");
    IO.println("Welcome, " + pilot + "!");
}

Pilot name: appears in Output. The program is now waiting. In the bottom Output pane, click after Pilot name:, type Nova and press Enter. The green text below is your reply, not something the program prints.

Pilot name: Nova
Welcome, Nova!

Where the value came from

NotationWhat happens here
IO.readln("Pilot name: ")Prints a prompt and reads one whole line. It waits until you press Enter. The call's result is the text you entered.
String pilot = ...;Stores that result under the name pilot. This step is not complete until you answer.
IO.println("Welcome, " + pilot + "!");Reads the stored answer and builds a greeting. Only this step adds the next printed line.

The new idea is that the value after = only becomes available while the program is running. IO.println prints something; IO.readln also gives you text to work with. The parentheses in both calls hold the values you pass in.

Predict two answers

Run the program again and enter Red Fox instead of Nova. Then run it a third time and just press Enter. What greeting do you expect in each case?

Compare the results

The whole answer Red Fox stays together, including the space between the words. Enter on its own supplies empty text, giving Welcome, !. Enter ends the line but is not part of the stored text. Do not type quotes around your answer: they belong to the way Java code represents text, not to ordinary typing in Output.

Task: the robot repeats your code

Open 03-text-input/P02_EchoRoom.java. The robot keeps repeating its old offline.

Replace the fixed code with a call that reads an answer, using the prompt Your code: . Keep the entered value in code; the supplied print call should repeat it. With the answer Open sesame, expect:

Your code: Open sesame
Robot repeats: Open sesame

Try another code too. The result must change without another edit to the source file.

Hint

Look at where pilot gets its value. The reading call belongs on the right-hand side when you introduce code. The prompt text includes a space after the colon.

The program is waiting, but nothing happened

Type your answer in the running program's Output and press Enter. Typing in the editor changes the source code. If you end the input instead of submitting a line, reading may provide the special value null; for this experiment, run the program again and enter an ordinary answer.

You can now let the player supply a value and use it later in the program.
