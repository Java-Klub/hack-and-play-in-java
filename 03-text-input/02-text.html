3.2 Vyčisti přijatý signál

Hráč může zadat Red Fox . Mezery na krajích nepotřebujeme, mezeru mezi slovy chceme zachovat. Původní zprávu si necháme vedle upravené.

Jedna zpráva, tři hodnoty

Otevři 03-text-input/P03_Example_MessageFilter.java. Před spuštěním zkus odhadnout poslední dva řádky.

/// # Hotový příklad · 3.2 Vyčisti přijatý signál
/// Lekce: 02-text.html

void main() {
    String raw = IO.readln("Signal: ");
    String clean = raw.strip();
    String loud = clean.toUpperCase(Locale.ROOT);
    IO.println("Signal [" + loud + "]");
    IO.println("Original [" + raw + "]");
}

Odpověz dvěma mezerami, Red Fox a dalšími dvěma mezerami. Hranaté závorky ve výpisu pomohou vidět okraje textu.

Signal:   Red Fox  
Signal [RED FOX]
Original [  Red Fox  ]
JménoUložený textProč
raw" Red Fox "Původní odpověď od hráče.
clean"Red Fox"strip() odstranilo krajní mezery. Vnitřní mezera zůstala.
loud"RED FOX"toUpperCase(Locale.ROOT) vytvořilo verzi velkými písmeny.

Co dělá tečka

V raw.strip() vybírá tečka operaci nad textem uloženým v raw. Prázdné závorky říkají, že nedodáváš další vstup. V clean.toUpperCase(Locale.ROOT) jsou závorky vyplněné: Locale.ROOT je připravené nastavení pro převod písmen nezávislý na regionálním nastavení počítače. Pro tento převod ho používej takto.

String operation (operace s textem) poskytne výsledek. Původní text tím nepřepíše. Proto má každé volání ve vzoru výsledek přiřazený do jména. Samotné raw.strip(); se provede, ale jeho výsledek nikde nezůstane uložený.

Úkol: oprav tiskárnu odznaků

Otevři 03-text-input/P04_Task_SignalBadge.java. Čištění je v kódu napsané, přesto ve výsledku zůstávají mezery.

Ponech raw jako původní odpověď. Ulož očištěný text do nové variable (proměnné), převeď ho na velká písmena a použij pro výpis odznaku. Přidej také výpis originálu. Pro tuto odpověď máš dostat:

Badge:   nOvA  
Badge [NOVA]
Original [  nOvA  ]

Zopakuj pokus s Red Fox . Na odznaku očekávej RED FOX, v originálu obě krajní mezery. Neměň původní zprávu přímo v zadání.

Nápověda 1: najdi ztracený výsledek

Pravá strana přiřazení může být volání. Zjisti, který připravený řádek dnes volá operaci, ale nemá výsledek přiřazený vůbec nikam.

Nápověda 2: dva kroky místo jednoho skoku

Nejdřív ulož očištěný text, potom můžeš pod stejným novým jménem uložit jeho verzi velkými písmeny. Originál raw přitom nechej být. Připomínka: už zavedenou variable měníš bez opakování String.

Zkus opačné pořadí

V příkladu MessageFilter prohoď pořadí obou konečných výpisů. Změní se jejich hodnoty, nebo jen jejich umístění? Spusť a vysvětli rozdíl mezi pořadím výpočtu a pořadím výpisu.

Teď umíš sledovat původní text i výsledky jeho úprav a poznat zahozený výsledek.
