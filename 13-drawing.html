13.1 Draw in a Java window

Make a small picture appear directly when your program runs. The example opens a window containing a blue card and a yellow circle. Close that window to finish the program.

import java.awt.*;
import java.awt.image.BufferedImage;
import javax.swing.*;

void draw(Graphics2D g) {
    g.setColor(Color.BLUE);
    g.fillRect(20, 20, 100, 60);
    g.setColor(Color.YELLOW);
    g.fillOval(50, 30, 40, 40);
}

void main() {
    SwingUtilities.invokeLater(() -> {
        var panel = new JPanel() {
            @Override protected void paintComponent(Graphics graphics) {
                super.paintComponent(graphics);
                draw((Graphics2D) graphics);
            }
        };
        panel.setPreferredSize(new Dimension(160, 100));
        panel.setBackground(Color.WHITE);
        var frame = new JFrame("Shape Card");
        frame.setDefaultCloseOperation(JFrame.DISPOSE_ON_CLOSE);
        frame.add(panel);
        frame.pack();
        frame.setLocationByPlatform(true);
        frame.setVisible(true);
    });
}

JFrame is the window and JPanel is its drawing surface. The imports make these Java desktop types available. All window creation runs inside SwingUtilities.invokeLater: the lambda is queued for Swing’s event dispatch thread, or EDT.

Swing calls paintComponent whenever the panel needs drawing. @Override marks this supplied hook’s replacement. Calling super.paintComponent first clears the panel. Your draw method receives the current drawing tool; it does not open a window itself.

Graphics2D adds drawing operations to the general Graphics tool. The cast (Graphics2D) names the more specific tool supplied for this Swing painting. Do not close or dispose this borrowed tool. A separate tool created with image.createGraphics belongs to its creator and does need dispose.

The body after new JPanel customises this one panel. Its painting method replaces the supplied version; the rest of JPanel still works normally. You do not need a separate named window class.

Coordinates start at the panel’s top-left corner: x grows rightward, y downward. fillRect takes x, y, width and height. fillOval uses the same four values as a bounding rectangle. Later paint covers earlier paint.

Predict one covered point

Point (70, 50) is yellow because it lies inside the circle painted last. Point (25, 25) remains blue. Which colour would the centre have if the rectangle were painted last?

These are pixel positions, not character positions. Changing the size of a printed label does not change them.

Task: give the badge two eyes

In code/RobotBadge.java, finish draw with two yellow circular eyes. Their bounding rectangles are (40,35,20,20) and (100,35,20,20). Preserve the blue body and white surrounding area.

Hint 1: choose paint before painting

setColor affects the following drawing calls. One selected yellow can paint both eyes.

Hint 2: keep the layers

Add the two fillOval calls after the body rectangle, using the four coordinates for each eye.

Save and run again to see the changed picture. Next the player will choose a position by clicking it.

Practise in a game

  • PixelMonsters · L01/M09_PixelMonsters.java
    In PixelMonsters change the shared eye colour rather than individual pixels. Try white, then choose another contrasting colour.
  • Untangle · L10/M04_Untangle.java
    In Untangle draw a circle around the supplied position and a contrasting label. Use the existing Graphics2D; do not move the node to draw it.
  • MirrorArt · L10/M06_MirrorArt.java
    In MirrorArt move a point into canvas-centred coordinates, optionally reflect it, rotate it, then move back. Transform returns a new point and preserves the original stroke.
  • Moire · L10/M07_Moire.java
    Moire rotates its grid around the wrong vertical position. Repair the centre coordinates and check stability as the angle changes.
  • StarTunnel · L10/M08_StarTunnel.java
    Remove StarTunnel's extra depth offset that distorts star scale. Preserve protection against division by an excessively small depth.

The source also contains the task and controls. Check your selected game using Check.java in the same folder; the setup lesson explains how.
