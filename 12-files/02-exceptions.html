12.2 Oznam neúspěšnou operaci

Rozdělit dvanáct žetonů mezi nula hráčů nemá použitelnou odpověď. Vrácená nula by chybu schovala jako úspěšný výpočet. Exception (výjimka) oznamuje, že požadovaná operace nedokázala vytvořit svůj běžný výsledek.

Spusť příklad s 3, 0 a three. Sleduj zobrazenou zprávu; každé spuštění projde jen jednou ze tří cest.

12-files/P05_Example_TokenShare.java

/// # Hotový příklad · 12.2 Oznam neúspěšnou operaci
/// Lekce: 02-exceptions.html

int share(int tokens, int players) {
    if (players < 1) {
        throw new IllegalArgumentException("Players must be positive.");
    }
    return tokens / players;
}

void main() {
    String reply = IO.readln("Players: ");
    if (reply == null) return;
    try {
        int players = Integer.parseInt(reply.strip());
        IO.println("Each gets " + share(12, players) + ".");
    } catch (NumberFormatException failure) {
        IO.println("Use a whole number.");
    } catch (IllegalArgumentException failure) {
        IO.println(failure.getMessage());
    }
}

throw new IllegalArgumentException(...) vytvoří selhání s vysvětlením a předá je volajícímu. Zbývající řádky v share se přeskočí. Na této cestě se žádný počet žetonů nevrací.

Blok try označuje práci, jejíž selhání chceš zpracovat. Java hledá odpovídající catch. Jeho parametr dostane objekt výjimky; getMessage() přečte vysvětlení. Po zpracování pokračuje program za celým příkazem try/catch.

NumberFormatException je konkrétnějším druhem IllegalArgumentException. Její catch patří první. Opačné pořadí by konkrétnější catch učinilo nedosažitelným. Nezachytávej všechna možná selhání jen proto, aby se vytiskla zpráva o úspěchu.

Sleduj překlep a zakázané číslo

Pro three selže převod ještě před zavoláním share. Pro 0 převod uspěje, ale share vyhodí výjimku. Pro 3 share vrátí čtyřku a žádný catch se neprovede. Co nastane pro -2?

Catch neopakuje příkaz, který selhal. Pokud chceš hráči nabídnout další pokus, potřebuješ okolní smyčku.

Úkol: čtení hlasitosti se smluvenými pravidly

Dokonči readVolume v 12-files/P06_Task_VolumeReader.java. Přijmi text celého čísla s okrajovými mezerami a vracej pouze hodnoty od nuly do deseti včetně. Pro číslo mimo rozsah vyhoď IllegalArgumentException s přesnou zprávou Volume must be 0..10..

Zachovej připravené zpracování překlepu. Ověř 0, 10 , -1, 11 a loud. Ke zprávě o úspěchu dojdou pouze platná čísla.

Nápověda 1: neztrať selhání převodu

Zachovej parseInt. Za převod a před vrácení výsledku přidej kontrolu rozsahu.

Nápověda 2: zamítnutí není hlasitost

Ve větvi mimo rozsah použij throw new IllegalArgumentException(...). Nevracej náhradní hodnotu.

Volající program nyní po jedné odpovědi skončí. Dále zachováš stejnou operaci, ale dáš hráči další pokus.
