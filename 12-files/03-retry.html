12.3 Nech hráče opravit odpověď

Překlep v čísle by neměl člověka nutit znovu spouštět celý program. Spoj známý loop (smyčku) s úzkým catch: zeptej se, zkus jeden převod a při neúspěchu se zeptej znovu.

Spusť příklad a na třech samostatných řádcích zadej ten, 0 a 4. Program vysvětlí obě zamítnutí a nakonec přijme čtyřku. Zadání q rozhovor ukončí.

12-files/P09_LengthRetry.java

void main() {
    while (true) {
        String reply = IO.readln("Code length: ");
        if (reply == null || reply.strip().equalsIgnoreCase("q")) {
            IO.println("Stopped.");
            return;
        }
        try {
            int length = Integer.parseInt(reply.strip());
            if (length < 1 || length > 8) {
                IO.println("Use 1..8.");
                continue;
            }
            IO.println("Ready: " + length);
            return;
        } catch (NumberFormatException failure) {
            IO.println("Use a whole number.");
        }
    }
}

Volání vstupu patří dovnitř smyčky. Jediné čtení před smyčkou by nechalo navždy uloženou stejnou vadnou odpověď. Každý nový průchod musí získat nový text.

continue přeskočí zbytek těla a začne další průchod. return ukončí celé main. Po zachyceném překlepu program dojde na konec těla a přirozeně opakuje; nepotřebuje další rekurzivní volání.

Ukončený vstup poskytne null, samotný Enter prázdný text. Příklad skončí pro null a q, prázdný řádek však považuje za další nepovedené číslo. Null ověř před voláním textových operací.

Předpověz krátký rozhovor

Pro odpovědi 9 a potom 2 první vstup vypíše Use 1..8.; druhý vypíše Ready: 2 a skončí. Co nastane po překlepu následovaném q?

Úkol: dokonči jednu rezervaci, nikoli několik

Připravený 12-files/P10_TicketRetry.java čte jen jednou. Přestav main tak, aby se znovu ptalo po překlepu i po čísle mimo jedna až šest. Zachovej pravidla readTickets i dvě odlišné chybové zprávy.

Úspěšná rezervace vypíše právě jedno potvrzení a skončí. q a ukončený vstup vypíší Stopped. a skončí. Zkus 0 a potom 2, prázdný řádek a 6 i many a q. Zamítnutý pokus nesmí vytvořit rezervaci.

Nápověda 1: přesuň celý pokus

Opakuj společně výzvu, kontrolu ukončení a try/catch. Neopakuj samotný převod.

Nápověda 2: vyber místo ukončení

Bezprostředně za zprávu o úspěchu vlož return. Bloky catch mají okolní smyčce dovolit pokračovat.

Stejné rozlišení platného výsledku a neúspěšného pokusu bude důležité i tehdy, když odpověď přijde ze souboru místo od člověka.
