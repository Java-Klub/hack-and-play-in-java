8.4 Make a pattern from coordinates

You do not need to store a pattern as a long list of hand-written symbols. For a checkerboard or frame, a small coordinate rule can decide every place. Changing the size then creates a different map automatically.

Create, fill, display

Open code/CheckerTiles.java. Enter size 3.

void main() {
    int size = Integer.parseInt(IO.readln("Size: ").strip());
    String[][] tiles = new String[size][size];
    for (int y = 0; y < size; y++) {
        for (int x = 0; x < size; x++) {
            if ((x + y) % 2 == 0) {
                tiles[y][x] = "#";
            } else {
                tiles[y][x] = ".";
            }
        }
    }
    show(tiles);
}

void show(String[][] tiles) {
    for (String[] row : tiles) {
        String line = "";
        for (String tile : row) {
            line += tile;
        }
        IO.println(line);
    }
}

The expression new String[size][size] creates a square grid. Its text places do not yet hold our symbols, so we then fill every one. The outer loop selects row y; the inner loop visits all its columns x. For every new row, x starts again at zero.

The rule alternates symbols using the parity of the coordinate sum. At 0, 0, the sum is even and produces #. At 1, 0, it is odd and produces a dot. At 0, 1, it is also a dot. That is why neighbouring rows do not start with the same symbol.

The helper show only displays the finished data. Its first for-each receives whole rows of type String[], and its second receives individual texts. The variable line starts empty for each row and joins its symbols. This output is a text map in Output, not a graphical window.

Prediction: size 2

These two rows appear:

#.
.#

With size 0, there are no rows, so nothing follows the prompt. Try the example with sizes from 0 to 6.

Task: a hollow panel

Open code/HollowPanel.java. Complete frame: every edge of the square must be #, and every interior place must be a dot. Both main and show are complete. Change the rule for an individual cell rather than printing rows by hand.

Try sizes from 1 to 6. For 1, the whole result is a single #. For 2, both rows are ##. For 4, expect top and bottom rows of #### and two middle rows of #..#. The only place at size 1 belongs to all four edges at once.

Hint 1: four ways to be on an edge

A cell is on an edge if it belongs to the first or last row, or the first or last column. One of these is enough.

Hint 2: the last index

The last valid index is one less than the size. Fill the other cells too, or they will not receive a text symbol.

Next, the rule will depend not just on coordinates but on the neighbourhood in the grid's previous state.

Practise in a game

  • Quarto · L05/M04_Quarto.java
    Quarto recognises rows but misses columns and diagonals. Extend won with the missing groups and let the supplied line judge each quartet.
  • Reversi · L05/M05_Reversi.java
    In Reversi award three points for a corner and one for another occupied square. The same score must drive both the live display and final winner.
  • LightUp · L08/M04_LightUp.java
    LightUp must see a bulb along the whole open corridor up to a wall or border. In visible continue beyond the immediate neighbour.
