7.5 A memory is not a second name

You want to remember a row of tiles before a move. But if the “memory” refers to the same array, changing the game also rewrites the past. Undo needs its own saved values.

Two names, or two arrays?

Open code/RouteMemory.java. Predict the first number in both outputs before running it.

void main() {
    int[] route = {1, 2, 3};
    int[] shared = route;
    int[] saved = route.clone();
    shared[0] = 9;
    IO.println("Route: " + Arrays.toString(route));
    IO.println("Saved: " + Arrays.toString(saved));
}

Assigning an array does not copy its elements. The variable shared receives a reference to the same array as route. Changing its first place to 9 through shared is also visible when reading through route.

The call route.clone() creates a new array with the same numeric values. The saved array therefore stays at 1, 2, 3. For our one-dimensional int array, this separates the values. Do not assume this is a rule for data of any complexity; you will return to sequences containing other sequences later.

route  -----> [9, 2, 3]
shared -----^
saved  -----> [1, 2, 3]

Another way to create an array is new int[3]. It provides three places, initially containing 0. The size in the square brackets is a count, not the last index. You can then transfer values one by one with an ordinary loop.

Prediction: change saved[1] to 8

Saved becomes [1, 8, 3], but route remains [9, 2, 3]. Changing an independent copy does not affect the original array in the other direction either.

Task: fix the memory and undo

Open code/TileUndo.java. The method remember must return an independent copy of the starting array. The method undo must transfer all saved values back into the existing array board. Both arrays have the same length.

The program changes the first tile using your input. For 7, Saved must remain [2, 0, 1], and Restored must also be [2, 0, 1]. Expect the same restored sequence for inputs 0 or 2. Try tile values from 0 to 9.

Hint 1: an independent photograph

The method remember must not return the same array under another name. Use a copy, or create a new array and transfer its values.

Hint 2: undo changes contents

Assigning a new array only to the local parameter board in undo will not help. The caller still holds the original array. Write into its numbered places.

Next, several rows will form a grid. One place number will no longer be enough: you will need both a row and a column.
