13.2 Turn a click into a choice

A window can wait for actions without asking a console question. Run P08_ClickSlots.java and click the three grey tiles. The chosen tile becomes green; another click changes the choice.

import java.awt.*;
import java.awt.image.BufferedImage;
import javax.swing.*;

int picked = -1;

void choose(int x, int y) {
    if (x < 0 || x >= 120 || y < 0 || y >= 40) return;
    picked = x / 40;
}

void draw(Graphics2D g) {
    for (int slot = 0; slot < 3; slot++) {
        g.setColor(slot == picked ? Color.GREEN : Color.LIGHT_GRAY);
        g.fillRect(slot * 40 + 2, 2, 36, 36);
    }
}

void main() {
    SwingUtilities.invokeLater(() -> {
        var panel = new JPanel() {
            @Override protected void paintComponent(Graphics graphics) {
                super.paintComponent(graphics);
                draw((Graphics2D) graphics);
            }
        };
        panel.setPreferredSize(new Dimension(120, 40));
        panel.setBackground(Color.WHITE);
        panel.addMouseListener(new java.awt.event.MouseAdapter() {
            @Override public void mousePressed(java.awt.event.MouseEvent event) {
                choose(event.getX(), event.getY());
                panel.repaint();
            }
        });
        var frame = new JFrame("Click Slots");
        frame.setDefaultCloseOperation(JFrame.DISPOSE_ON_CLOSE);
        frame.add(panel);
        frame.pack();
        frame.setLocationByPlatform(true);
        frame.setVisible(true);
    });
}

A mouse event describes one action, including its position. addMouseListener registers an object whose mousePressed method Swing will call later. MouseAdapter supplies empty implementations for the other mouse notifications, so this program only replaces the one it needs.

The event coordinates are relative to this panel, not the whole screen or the window frame. The callback passes ordinary int arguments to choose. That method changes the model; repaint asks Swing to show its current value.

repaint schedules drawing. Do not call draw with a manually obtained screen tool, and do not expect the screen to have changed before repaint returns. Swing combines pending painting requests when appropriate.

The guard rejects positions outside the strip before division. For nonnegative x, integer division by 40 maps positions 0..39 to slot zero, 40..79 to slot one, and 80..119 to slot two. The initial -1 means no selection.

Predict the edge

A click at (80,20) selects slot two. A request at (120,20) is refused and preserves the previous selection. What does (39,0) select?

Task: select all four tiles

Repair choose in 13-windows/P09_FourTiles.java. The panel is 160 by 160 pixels, split into two rows and two columns of size 80. Number tiles left to right, then top to bottom: 0, 1, 2, 3.

Use both coordinates and reject any x or y outside 0..159 without changing picked. Check the four corners, the boundary at x=80, and a point just outside each edge. The supplied listener and drawing already work.

Hint 1: two independent coordinates

Compute a column from x and a row from y. A lower tile needs a different number even when x is unchanged.

Hint 2: flatten after validation

After the guard, use row times the number of columns plus column.

Try the rule directly, then restore the window

A click outside the panel is not delivered to this listener. To try the method boundaries, first keep a copy of the original main in a temporary text document. Replace only that main method with the following console experiment; keep choose, draw, fields and imports.

void main() {
    choose(10, 100);
    IO.println(picked);
    choose(159, 159);
    IO.println(picked);
    choose(-1, 0);
    choose(160, 20);
    choose(20, -1);
    choose(20, 160);
    IO.println(picked);
    choose(80, 0);
    IO.println(picked);
}

With the repaired rule, the four printed values are 2, 3, 3 and 1. The outside calls leave the previous choice unchanged. Afterwards paste the original GUI main back, save and run again to resume clicking.

The listener should remain short. Next you will let several buttons reuse one named handler.
