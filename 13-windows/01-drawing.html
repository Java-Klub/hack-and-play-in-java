13.1 Kresli v okně Javy

Nech při spuštění programu rovnou vzniknout malý obrázek. Příklad otevře okno s modrou kartou a žlutým kruhem. Zavřením okna program dokončíš.

13-windows/P01_ShapeCard.java

import java.awt.*;
import java.awt.image.BufferedImage;
import javax.swing.*;

void draw(Graphics2D g) {
    g.setColor(Color.BLUE);
    g.fillRect(20, 20, 100, 60);
    g.setColor(Color.YELLOW);
    g.fillOval(50, 30, 40, 40);
}

void main() {
    SwingUtilities.invokeLater(() -> {
        var panel = new JPanel() {
            @Override protected void paintComponent(Graphics graphics) {
                super.paintComponent(graphics);
                draw((Graphics2D) graphics);
            }
        };
        panel.setPreferredSize(new Dimension(160, 100));
        panel.setBackground(Color.WHITE);
        var frame = new JFrame("Shape Card");
        frame.setDefaultCloseOperation(JFrame.DISPOSE_ON_CLOSE);
        frame.add(panel);
        frame.pack();
        frame.setLocationByPlatform(true);
        frame.setVisible(true);
    });
}

JFrame je okno a JPanel jeho kreslicí plocha. Import zpřístupní uvedené desktopové typy Javy. Celé vytváření okna běží uvnitř SwingUtilities.invokeLater: lambda (odložená funkce) se zařadí pro Swing event dispatch thread, zkráceně EDT (vlákno událostí).

Swing zavolá paintComponent, kdykoli plocha potřebuje překreslit. @Override označuje nahrazení tohoto připraveného hook (vstupního bodu). Volání super.paintComponent nejprve plochu vyčistí. Tvoje draw dostane právě používaný kreslicí nástroj; samo okno neotevírá.

Graphics2D rozšiřuje obecný nástroj Graphics o kreslicí operace. Cast (přetypování) (Graphics2D) pojmenuje konkrétnější nástroj dodaný pro toto kreslení Swingu. Vypůjčený nástroj neuzavírej pomocí dispose. Samostatný nástroj vytvořený image.createGraphics patří svému tvůrci a dispose potřebuje.

Tělo za new JPanel přizpůsobuje tuto jednu plochu. Jeho kreslicí metoda nahradí připravenou verzi; zbytek JPanel dál funguje obvykle. Samostatnou pojmenovanou třídu okna nepotřebuješ.

Souřadnice začínají v levém horním rohu plochy: x roste doprava a y dolů. fillRect přijímá x, y, šířku a výšku. fillOval používá stejné čtyři hodnoty jako obdélník ohraničující ovál. Pozdější barva překryje dřívější.

Předpověz jeden překrytý bod

Bod (70, 50) je žlutý, protože leží uvnitř kruhu kresleného posledního. Bod (25, 25) zůstane modrý. Jakou barvu by měl střed, kdyby se obdélník kreslil poslední?

Jde o pozice obrazových bodů, nikoli znaků. Změna délky vypsaného popisku tyto souřadnice nijak nezmění.

Úkol: přidej cedulce dvě oči

V 13-windows/P02_RobotBadge.java dokonči draw dvěma žlutými kruhovými očima. Jejich ohraničující obdélníky jsou (40,35,20,20) a (100,35,20,20). Zachovej modré tělo a bílé okolí.

Nápověda 1: vyber barvu před kreslením

setColor ovlivní následující kreslicí volání. Jednou vybranou žlutou můžeš nakreslit obě oči.

Nápověda 2: zachovej vrstvy

Přidej dvě volání fillOval za obdélník těla; každému předej jeho čtyři souřadnice.

Ulož a spusť program znovu, abys viděl změněný obrázek. Dále hráč vybere pozici kliknutím.

Procvič ve hře

  • PixelMonsters · 13-windows/P03_PixelMonsters.java
    V PixelMonsters změň společnou barvu očí, ne jednotlivé pixely. Vyzkoušej bílou a potom vlastní kontrastní barvu.
  • Untangle · 13-windows/P04_Untangle.java
    V Untangle nakresli kruh kolem předané pozice a kontrastní popisek. Použij existující Graphics2D; neposouvej uzel kvůli jeho vykreslení.
  • MirrorArt · 13-windows/P05_MirrorArt.java
    V MirrorArt převeď bod do středu plátna, případně odraz, otoč a vrať zpět. Transform musí vrátit nový bod a zachovat původní tah.
  • Moire · 13-windows/P06_Moire.java
    Moire otáčí mřížku kolem špatné svislé polohy. Oprav obě souřadnice středu a sleduj stabilitu při změně úhlu.
  • StarTunnel · 13-windows/P07_StarTunnel.java
    Ve StarTunnel odstraň přidaný posun hloubky, který mění měřítko hvězd. Ochrana před dělením příliš malou hloubkou musí zůstat.

Zadání a ovládání najdeš také přímo ve zdrojáku. Vybranou hru ověř pomocí Check.java ve stejné složce; postup připomíná úvodní lekce.
