13.5 Let painting observe the model

A window may repaint when uncovered, resized or requested by Swing. None of those events means that the player scored. Run P26_HitMeter.java: only Hit changes the green count, and Reset starts again.

import java.awt.*;
import java.awt.image.BufferedImage;
import javax.swing.*;

int points = 0;

boolean hit() {
    if (points >= 5) return false;
    points++;
    return true;
}

void reset() {
    points = 0;
}

void draw(Graphics2D g) {
    for (int i = 0; i < 5; i++) {
        g.setColor(i < points ? Color.GREEN : Color.LIGHT_GRAY);
        g.fillRect(10 + i * 30, 10, 24, 40);
    }
}

void main() {
    SwingUtilities.invokeLater(() -> {
        var panel = new JPanel() {
            @Override protected void paintComponent(Graphics graphics) {
                super.paintComponent(graphics);
                draw((Graphics2D) graphics);
            }
        };
        panel.setPreferredSize(new Dimension(170, 60));
        panel.setBackground(Color.WHITE);
        var hit = new JButton("Hit");
        hit.addActionListener(event -> { hit(); panel.repaint(); });
        var reset = new JButton("Reset");
        reset.addActionListener(event -> { reset(); panel.repaint(); });
        var buttons = new JPanel();
        buttons.add(hit);
        buttons.add(reset);
        var frame = new JFrame("Hit Meter");
        frame.setDefaultCloseOperation(JFrame.DISPOSE_ON_CLOSE);
        frame.add(panel);
        frame.add(buttons, BorderLayout.SOUTH);
        frame.pack();
        frame.setLocationByPlatform(true);
        frame.setVisible(true);
    });
}

The model is the stored points and the rules that change them. The view reads those points and paints a representation. A listener connects the two by asking the model for a change and then requesting a redraw.

Notice that draw contains no increment. Calling it once or ten times leaves points unchanged. The five rectangles are representations of the same stored number, not five independent counters.

hit owns the transition and checks its limit before changing anything. A sixth hit returns false and preserves five. reset owns a different transition. Keeping these rules out of painting also lets you try the model without opening a window.

Predict an uncovered window

After two hits, points is two. Cover and uncover the window several times: the value stays two. A third hit changes it to three. What should two calls to draw do after a reset?

Task: remove the repaint bonus

In 13-windows/P27_ScoreBadge.java, the score is wrongly increased by drawing, while Hit does nothing. Move responsibility to hit: each accepted call adds exactly one, three wins, and later hits return false without changing score.

Keep draw able to show both the ordinary and won states, but make it read-only. Reset must restore zero, and drawing afterwards must preserve zero. Try two hits, several repaints, the winning hit, another hit and Reset.

Do not repair the visual symptom by subtracting a point elsewhere. Decide which event has the right to change state. The result must be independent of how often the operating system asks the window to paint.

Hint 1: two different responsibilities

Remove the score change from draw and put the accepted transition in hit.

Hint 2: stop before incrementing

Check the win limit first. Then add one and return true; the refusal path returns false.

You now have rules that can be called and checked independently of their presentation. The last chapter uses that separation for tests, interchangeable behaviour and larger designs.

Practise in a game

  • SpringToy · 13-windows/P28_SpringToy.java
    SpringToy changes physics while repainting. Remove model advancement from draw and verify repeated repainting cannot move a paused weight.
  • Breakout · 13-windows/P29_Breakout.java
    Create unlimited Breakout practice without a loss counter. A miss serves a new ball while preserving bricks and score; keep real victory and full restart.
  • RippleTank · 13-windows/P30_RippleTank.java
    RippleTank stops propagation immediately after a valid tap. Repair the state transition so a new disturbance can run, preserving pause controls.
  • PictureMusic · 13-windows/P31_PictureMusic.java
    Add a semitone shift to PictureMusic's pitchFrequency. +12 doubles frequency, -12 halves it and zero preserves the sound; keep input bounds.
  • SecretBeeps · 13-windows/P32_SecretBeeps.java
    SecretBeeps must use the requested word gap instead of a fixed seven. Preserve gaps within letters and the original seven-unit mode.

The source also contains the task and controls. Check your selected game using Check.java in the same folder; the setup lesson explains how.
