13.3 Give events one clear job

Click Louder several times. The displayed volume rises to five and stays there. Quieter uses the same rule with a negative change. The buttons request changes; the shared handler decides whether they are allowed.

13-windows/P12_VolumeButtons.java

import javax.swing.*;

int volume = 2;

boolean adjust(int delta) {
    int next = volume + delta;
    if (next < 0 || next > 5) return false;
    volume = next;
    return true;
}

void main() {
    SwingUtilities.invokeLater(() -> {
        var status = new JLabel("Volume: " + volume);
        var quieter = new JButton("Quieter");
        var louder = new JButton("Louder");
        quieter.addActionListener(event -> {
            adjust(-1);
            status.setText("Volume: " + volume);
        });
        louder.addActionListener(event -> {
            adjust(1);
            status.setText("Volume: " + volume);
        });
        var panel = new JPanel();
        panel.add(quieter);
        panel.add(status);
        panel.add(louder);
        var frame = new JFrame("Volume Buttons");
        frame.setDefaultCloseOperation(JFrame.DISPOSE_ON_CLOSE);
        frame.add(panel);
        frame.pack();
        frame.setLocationByPlatform(true);
        frame.setVisible(true);
    });
}

addActionListener registers a callback. The lambda’s event parameter describes the activation, but this example does not need its details. The body runs later, when someone presses the button, not while the button is being constructed.

Each callback calls adjust and refreshes the label from the resulting stored value. JLabel.setText replaces displayed text. The rule itself does not refer to labels, buttons or windows; it can also be called from an ordinary method.

Button listeners and painting run on the EDT. Keep these actions short so the window can react to the next event. A long calculation or sleep inside a listener would freeze interaction even though the window was created correctly.

Predict a refused change

Starting at volume two, adjust(3) returns true and stores five. The next adjust(1) returns false and keeps five. Predict adjust(-5), followed by adjust(-1).

Task: count people, not button presses

Finish handle in 13-windows/P13_RoomCounter.java. The room holds at most three people. add admits one only when there is space; leave removes one only when someone is inside. reset always restores zero. Unknown commands return false.

Return true for each accepted command and false for a refusal. A refused command must preserve count. Try leaving an empty room, entering four times, leaving once and resetting. The label must always describe the actual state.

The supplied loop creates one button per command. Each iteration’s command is captured by its listener; it is not looked up from the visible label later. Keep that wiring and repair only the domain rule.

Hint 1: guard before changing

Check capacity before incrementing and emptiness before decrementing. Returning false after changing count is too late.

Hint 2: reset has its own meaning

Handle reset independently; resetting an already empty room is still an accepted command.

Next a timer will request small updates repeatedly. The same separation keeps its callback easy to understand.

Practise in a game

  • MiniInvaders · 13-windows/P14_MiniInvaders.java
    Give each new MiniInvaders pulse exactly two distinct hits. Follow its creation, collision and end; a fresh pulse must not inherit a spent allowance.
  • SoftLanding · 13-windows/P15_SoftLanding.java
    Find SoftLanding's real engine gates and create unlimited practice without consuming fuel. Preserve thrust strength, gravity and landing rules.
  • AsteroidDrift · 13-windows/P16_AsteroidDrift.java
    In AsteroidDrift rewire F to fire and Space to brake both velocities. First sketch the event route; preserve steering and firing cooldown.
  • FireworkPainter · 13-windows/P17_FireworkPainter.java
    FireworkPainter needs a delayed burstAction with two mirrored bursts. Constructing an action must not release particles; clicking should.
  • ShadowPlayground · 13-windows/P18_ShadowPlayground.java
    Build ShadowPlayground's lightAction so it snaps both coordinates down to multiples of 20 and calls moveLight only when the event occurs.

The source also contains the task and controls. Check your selected game using Check.java in the same folder; the setup lesson explains how.
