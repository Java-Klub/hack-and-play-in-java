7.3 Změň skutečné místo

Panel má několik světel. Kliknutí zde nahradíme číslem napsaným do Output: zvolená kontrolka má přepnout stav, ostatní mají zůstat stejné. Nestačí přepsat pracovní kopii hodnoty.

Hranaté závorky vlevo i vpravo

Otevři code/ChargeSlot.java. Zadej slot 1.

void main() {
    int[] charges = {2, 5, 1};
    int slot = Integer.parseInt(IO.readln("Slot: ").strip());
    if (slot >= 0 && slot < charges.length) {
        charges[slot] = charges[slot] + 2;
    } else {
        IO.println("Invalid slot");
    }
    IO.println(Arrays.toString(charges));
}

Výraz napravo od rovná se přečte starou hodnotu vybraného místa a přičte dvě. Zápis charges[slot] = charges[slot] + 2; uloží výsledek zpět právě na toto místo. Ze stavu 2, 5, 1 vznikne 2, 7, 1.

Metoda Arrays.toString(charges) poskytne čitelný text se všemi hodnotami a hranatými závorkami. Používáme ji pouze k zobrazení; neprovádí změnu. Její výsledek se například hodí k porovnání stavu před tahem a po něm.

U číselného pole by přiřazení do proměnné power uvnitř for-each změnilo jen tuto local variable (lokální proměnnou). Pro zápis do konkrétního element (prvku) potřebuješ samotné pole a jeho index. Vybraný index proto nejprve ověřujeme.

Předpověď: slot -1

Vypíše se Invalid slot a potom nezměněné [2, 5, 1]. Odmítnutý výběr neprovede žádné přiřazení do pole.

Úkol: přepínač světla

Otevři code/LightSwitch.java. Čtyři světla jsou na začátku vypnutá. Pro platný slot změň pouze vybrané světlo na opačnou boolean hodnotu. Tím bude tentýž krok umět zapínat i vypínat.

Pro slot 2 čekej [false, false, true, false]. Pro 0 má být true pouze první hodnota, pro 3 poslední. Pro -1 nebo 4 vypiš Invalid slot a potom čtyři false. Neplatná volba nemění ani jiné světlo.

Po opravě změň počáteční druhé světlo na true a zadej 1. Musí se vypnout. Potom vrať původní počáteční pole. Tento pokus rozliší přepnutí od pouhého přiřazování true.

Nápověda 1: opačná odpověď

Operátor NOT už znáš z podmínek. Umí z true vytvořit false i naopak.

Nápověda 2: cíl přiřazení

Výsledek ulož do prvku na vybraném indexu, nikoli do čísla slot ani do celé proměnné lights.

Příště nebude hráč znát potřebný index. Napíšeš hledání, které správné místo vybere podle jeho obsahu.
