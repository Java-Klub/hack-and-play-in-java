9.4 Data can know their operations

A battery plan should answer how much charge remains without erasing the original plan. A method inside a record can read its components and return a calculated value or another record. Data and the operations that make sense for it stay together.

The receiver supplies the component values

void main() {
    Battery original = new Battery(8);
    IO.println("Ready: " + original.canSpend(3));
    Battery after = original.spend(3);
    IO.println("Original: " + original.charge());
    IO.println("After: " + after.charge());
}

record Battery(int charge) {
    boolean canSpend(int cost) {
        return cost >= 0 && charge >= cost;
    }

    Battery spend(int cost) {
        return new Battery(charge - cost);
    }
}

Open 09-data/P08_BatteryPlan.java. In original.canSpend(3), original is the receiver of the call. Its charge is 8 and cost receives 3, so the answer is true. Calling the same method on a battery with charge 2 would answer false.

Inside a record method, a component name such as charge reads that receiver’s component. No extra Battery parameter is needed. The return type Battery says spend constructs a result of the same data type. Original still prints 8 because the result was stored separately.

Spend is a calculation with a stated precondition: call it only for a nonnegative cost that canSpend accepts. For the prepared cost 3, the condition holds; canSpend simply displays true. A method name does not automatically enforce another method’s rule. Later you will design objects that protect changes themselves.

Predict another plan

Spending 0 returns a battery with charge 8. Spending 8 returns charge 0. Both leave original at 8. What if you discard the result of original.spend(3)? Original still has charge 8; returned data are not an assignment.

Task: leave a trail of positions

Open 09-data/P09_VectorTrail.java. Complete moved so it returns a new Vector shifted by dx and dy. Complete distanceSquared so it returns x times x plus y times y for its receiver. Keep the starting vector unchanged.

The prepared movement is 2,-1. From 0,0 it ends at 2,-1 with squared distance 5. From -2,1 it reaches 0,0 with distance 0. From 1,3 it reaches 3,2 with distance 13. No square root is needed.

Hint 1: which position belongs to this call?

The special name this means the current receiver. Returning this simply returns the old vector; it does not apply the displacement.

Hint 2: separate the two answers

Moved constructs two new coordinates. DistanceSquared returns one number. Neither method needs to read input or print a message.

Next, give a fixed family of choices meaningful names instead of remembering which arbitrary number means which direction.
