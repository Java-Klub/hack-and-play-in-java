10.1 A bag need not know its size ahead of time

Your explorer collects equipment along the way. An array has a fixed length; a list can grow or shrink while preserving order. You still use indices, but the container takes care of finding room for added elements.

A readable type and a changeable container

void main() {
    List<String> starting = List.of("Rope", "Torch");
    List<String> bag = new ArrayList<>(starting);
    bag.add("Map");
    bag.set(1, "Lantern");
    IO.println("First: " + bag.get(0));
    IO.println("Size: " + bag.size());
    IO.println("Bag: " + bag);
    IO.println("Starting: " + starting);
}

Open 10-collections/P01_GrowingBag.java. List<String> means a list whose elements are Strings. The angle brackets contain a type argument, not a numeric comparison. Java checks the element type, so adding a number directly to this bag is not allowed.

List names the operations you need; ArrayList is a prepared Java implementation that stores the elements. The empty <> in new ArrayList<>(starting) lets Java infer String from the declaration. This copy constructor creates a new list containing the original element references.

List.of creates an unmodifiable list: do not add, remove or replace its elements. The ArrayList copy permits those operations. Add appends; set replaces an existing element; get reads it. Indices start at 0 and stay below size(), which replaces an array’s length here.

Predict an extra item

After adding Map the size is 3. Replacing Torch with Lantern keeps size 3. What would one more add("Key") do? Size becomes 4, with Key last. Starting still contains Rope and Torch.

Task: make room in the bag

Open 10-collections/P02_BagEditor.java. Complete edit: remove the original second item, Torch, then append the supplied item only if it is not empty. Modify the supplied list; returning another list without using it would not change this bag.

Remove with an index, for example bag.remove(1), closes that gap and shifts following elements left. With Compass expect [Rope, Map, Compass] and size 3. With an empty answer expect [Rope, Map] and size 2. Internal spaces in Spare rope must remain.

Hint 1: count positions from zero

The second item has index 1. Remove it before deciding whether to add a replacement.

Hint 2: the parameter shares the list

The parameter holds a copied reference to the same mutable list. Calling its operations changes that list; assigning a new list only to the parameter would not redirect main’s variable.

A list keeps duplicates. Next, choose a container whose job is remembering whether something has already appeared.

Practise in a game

  • Flood · 10-collections/P03_Flood.java
    Flood must also process neighbours added during the search. Repair spread's continuation condition and retain the supplied neighbour checks.
  • SameGame · 10-collections/P04_SameGame.java
    SameGame abandons a group too early. In group track processed and discovered cells and finish the entire growing work list.
  • DragonCurve · 10-collections/P05_DragonCurve.java
    DragonCurve makes fewer folds than requested. Repair only foldTurns' outer loop: zero means no folding; a positive number means exactly that many passes.
  • EvilHangman · 10-collections/P06_EvilHangman.java
    Count EvilHangman's family by accumulating contributions. An empty family has size zero; do not return a fixed answer or just the last contribution.
  • WordChain · 10-collections/P07_WordChain.java
    WordChain's choices should retain every discovered option. Find the line that replaces earlier results and preserve the menu order.
  • Hex · 10-collections/P08_Hex.java
    Repair Hex's neighbour directions inside connected. Keep the supplied search; construct connections that require each of the six directions.
  • SetStyleTripleHunt · 10-collections/P09_SetStyleTripleHunt.java
    SetStyleTripleHunt needs every triple of distinct cards, including the last card. Repair the three loop bounds and leave triple to judge each selection.
  • Shikaku · 10-collections/P10_Shikaku.java
    Shikaku needs a separate rectangle-list copy for Undo. Copy membership; immutable Box values can stay shared.
  • GapHopper · 10-collections/P11_GapHopper.java
    GapHopper returns a recycled pipe to the wrong queue end. Follow obstacle order across several cycles rather than just the first picture.
  • FlipbookStudio · 10-collections/P12_FlipbookStudio.java
    Complete FlipbookStudio's undo: remove the latest Edit and restore its old colour in its own frame and coordinates. An empty history returns false.
