10.3 Each name has its own account

Several teams earn points in mixed order. A list of numbers loses the names, and parallel arrays need careful matching. A map associates each key with one value, so a team name can directly select that team’s running score.

Look up, calculate, store

void main() {
    Map<String, Integer> counts = new HashMap<>();
    String[] signals = {"Moon", "Sun", "Moon"};
    for (String signal : signals) {
        int previous = counts.getOrDefault(signal, 0);
        counts.put(signal, previous + 1);
    }
    IO.println("Moon: " + counts.getOrDefault("Moon", 0));
    IO.println("Sun: " + counts.getOrDefault("Sun", 0));
    IO.println("Star: " + counts.getOrDefault("Star", 0));
    IO.println("Names: " + counts.size());
}

Open 10-collections/P20_SignalCounts.java. Map<String, Integer> has two type arguments: String keys and Integer values. Generic collections cannot use primitive int as a type argument. Integer is its object wrapper; Java automatically boxes an int when storing it and unboxes it for arithmetic. The same rule gives List<Integer> for a list of whole numbers; List<int> is not valid.

GetOrDefault reads a key’s value or supplies the second argument when no mapping exists. It does not insert that default. Put stores one value under the key, replacing any previous value there. It does not automatically add to an existing number.

Trace Moon: the first visit reads 0 and stores 1; the second reads 1 and stores 2. Sun gets a separate entry. Asking about Star returns 0 without changing size, which counts keys. HashMap does not guarantee a useful iteration order, so this example asks for specific names.

Predict a new signal

One more Moon would give Moon: 3 and Names: 2. One Star would instead make Names: 3. Which operation creates that third entry? Put, not the earlier getOrDefault question.

Task: accumulate the team scores

Open 10-collections/P21_TeamScores.java. Complete award so repeated entries add points to the same team instead of overwriting its history. A new team starts from 0. Keep other teams unchanged, and preserve the prepared reading and query loop.

Enter Moon with 4, Sun with 2, Moon with 3, then an empty team name and query Moon. Expect Score: 7 and Teams: 2. No entries followed by a Star query gives 0 and 0. Awards 4 then -4 give score 0 but still one team.

Hint 1: writing is not adding

Find the old value before calling put. Use a default that makes a first award work without a separate branch.

Hint 2: preserve the key

Store the calculated total under the same name you looked up. Do not use the points as a key or remove zero-score teams.
