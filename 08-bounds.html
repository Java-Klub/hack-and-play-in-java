8.2 Nejdřív zkontroluj okraj

Radar může dostat souřadnice za mapou. Nejsou to další skryté buňky. Program musí nejprve rozhodnout, zda místo existuje, a teprve pak číst jeho obsah.

Čtyři podmínky pro obdélník

Otevři code/MapBoundary.java. Vyzkoušej x = 2, y = 1 a potom x = 3, y = 1.

void main() {
    int[][] map = {{2, 0, 1}, {0, 3, 7}};
    int x = Integer.parseInt(IO.readln("X: ").strip());
    int y = Integer.parseInt(IO.readln("Y: ").strip());
    if (inside(map, x, y)) {
        IO.println("Value: " + map[y][x]);
    } else {
        IO.println("Outside");
    }
}

boolean inside(int[][] map, int x, int y) {
    return x >= 0 && x < map[0].length && y >= 0 && y < map.length;
}

Metoda inside vrací boolean (logickou hodnotu). Potřebuje, aby současně platily čtyři požadavky: x není záporné, x je menší než počet sloupců, y není záporné a y je menší než počet řádků. Operátor AND všechny požadavky spojí.

Nejvyšší platná souřadnice je o jednu menší než odpovídající délka. Mapa široká tři buňky má x od 0 do 2, nikoli do 3. Přesnou horní hranici proto testujeme pomocí menší než, ne menší nebo rovno.

Kontrola v main stojí před přístupem do pole. Výpis Outside nepotřebuje žádnou buňku přečíst. Stejně jako minule předpokládáme neprázdnou obdélníkovou mřížku; tento pomocník neřeší různě dlouhé řádky ani chybějící pole.

Předpověď: x = 0, y = -1

X je v pořádku, ale záporné y odmítne celý výběr. Výsledek je Outside. Nestačí, aby vyhovovala jen jedna souřadnice.

Úkol: odemkni radar jen uvnitř mapy

Otevři code/DroneRadar.java. Připravené main už podle inside vybírá, zda ukázat signál. Pomocník zatím odmítá všechno. Doplň pravidlo pro skutečné rozměry předaného pole; rozměry nezapisuj napevno jako čísla.

Pro 3, 1 čekej Signal: 9, pro 1, 0 Signal: 4. Pro 4, 1 a 0, 2 už čekej Outside. Stejně se odmítnou -1, 0 i 3, -1. Všimni si, že mapa je širší než vyšší: prohození rozměrů by pokazilo pravý okraj.

Metoda nemá souřadnice opravovat ani je přesouvat na nejbližší okraj. Jen odpovídá, zda existují. Neplatný výběr tedy nesmí zobrazit obsah jiné buňky.

Nápověda 1: napiš meze zvlášť

Pro každou souřadnici si nejprve napiš nejmenší a největší povolenou hodnotu. Potom z nich sestav společný test.

Nápověda 2: rozměry předaných dat

Počet řádků patří vnějšímu poli. Šířku získáš délkou jeho prvního řádku. Obě délky už znáš z předchozí lekce.

Příště se budou podobné kontroly opakovat pro sousední buňky. Jeden správný pomocník ochrání více různých návštěv.

Procvič ve hře

  • TicTacToe · L03/M04_TicTacToe.java
    TicTacToe potřebuje mayPlay: odmítni konec hry, neplatné číslo a obsazené pole dřív, než dovolíš zápis. Zamítnutí nesmí předat tah.
  • Chomp · L03/M05_Chomp.java
    V Chomp oprav rozsah řádků, aby šlo ukousnout také čtvrtý. Zachovej odmítání neexistující nebo snědené čokolády.
  • Sudoku · L03/M08_Sudoku.java
    V Sudoku přidej guards do place: souřadnice ověř před indexováním, poté hodnotu, pevnou nápovědu, pravidla a konec hry. Valid už je připravené.

Zadání a ovládání najdeš také přímo ve zdrojáku. Vybranou hru ověř pomocí Check.java ve stejné složce; postup připomíná úvodní lekce.
