10.5 Send data through a filter

Your backpack holds several kinds of loot, but a shop window should show only valuable items. A stream describes a sequence of processing steps: choose the elements you need, transform them, and collect the answers. The original collection can stay untouched.

Each operation has one small job

void main() {
    List<String> words = List.of("sun", "moon", "star", "a");
    List<String> loud = words.stream()
        .filter(word -> word.length() >= 4)
        .map(word -> word.toUpperCase(Locale.ROOT))
        .toList();
    IO.println("Selected: " + loud);
    IO.println("Original: " + words);
}

Open code/SpellFilter.java. Stream starts processing the list’s elements. Filter receives a lambda that returns boolean: true keeps the current element, false rejects it. Here sun and a are rejected because they are shorter than four characters.

Map receives another lambda, which returns the replacement value for each retained element. It transforms moon into MOON and star into STAR. This map operation is unrelated to the Map key-value container: one transforms elements, the other stores associations.

ToList finishes the pipeline and collects the resulting values into an unmodifiable list. The line breaks do not end the expression; the dots continue it until the semicolon. Without a finishing operation, merely describing these steps would not perform this processing.

The original list prints unchanged. These lambdas only read each element and return answers; they do not add to the source list. A stream is consumed once. If you need another calculation, start another stream from the collection rather than saving and reusing the old stream.

Predict another word

Adding "gate" to the source produces GATE at the end of Selected. What about adding "go"? It remains only in Original, because filter rejects it before map is reached.

Task: turn useful loot into a name list

Open code/LootFilter.java. Complete valuableNames: keep only Loot whose value is strictly greater than 0, then return their names in original order. Return a List<String>, not the records or one combined text. Do not change the input list.

Expect Names: [Gem, Coin], Empty: [] and Original size: 4. Stone at 0 must be excluded, as must Debt at -2. An empty input list should naturally give an empty output, without reading input or adding a special placeholder name.

Hint 1: separate selection and transformation

The first lambda answers a question about value. The second returns a name. Filtering names before you read value loses information.

Hint 2: track the element type

The stream initially carries Loot. After selecting, it still carries Loot. After mapping names, it carries Strings ready for toList.

What do the double colons in the supplied conversion mean?

Nonogram already supplies its final conversion. Integer::intValue is a method reference, a short form of behaviour equivalent to value -> value.intValue(). mapToInt creates a stream of primitive int values, and toArray() turns them into an int[]. This puts the collected group lengths into a fixed array for display. Leave this part unchanged while repairing the final group.
