8.1 Rows become a map

A single row of tiles is no longer enough for a map. You need rows above one another, each with several columns. Two numbers identify a place: first choose a row, then a place within it.

Y chooses a row; X chooses a column

Open 08-grids/P01_Example_ArenaCells.java. Coordinates x = 2 and y = 1 point to the bottom-right corner.

/// # Worked example · 8.1 Rows become a map
/// Lesson: 01-grids.html

void main() {
    int[][] arena = {
        {1, 0, 2},
        {0, 3, 5}
    };
    int x = Integer.parseInt(IO.readln("X: ").strip());
    int y = Integer.parseInt(IO.readln("Y: ").strip());
    IO.println("Value: " + arena[y][x]);
    IO.println("Rows: " + arena.length);
    IO.println("Columns: " + arena[0].length);
}

The type int[][] means an array of arrays. The outer braces contain two rows; the inner braces contain each row's values. The first index selects a row, and the second selects its element. You can therefore read arena[y][x] as two steps, not one mysterious place number.

       x=0 x=1 x=2
y=0     1   0   2
y=1     0   3   5

The number of rows is arena.length. The first row is itself an array, so arena[0].length gives its length: the number of columns here. In this chapter, we work with nonempty rectangular grids: every row has the same length.

Coordinates start at zero. X increases to the right and y downwards because that is how we print the map. Java's square brackets do not define a geometric convention; we chose to arrange rows and columns this way.

Prediction: x = 1, y = 0

You choose the first row and its second place: the value is 0. For x = 1, y = 1, it would be 3.

Task: a label for the selected place

Open 08-grids/P02_Task_TileMap.java. The map has two rows and three columns. Fix the place-name lookup using the coordinates, and fix the column count. The row and column counts differ, so swapping them must not stay hidden.

For x = 2, y = 1, expect Tile: camp, Rows: 2 and Columns: 3. For 1, 0, the place is pond; for 0, 1, it is tree. For now, enter only x from 0 to 2 and y from 0 to 1. Handling coordinates outside the map will be a separate next step.

Hint 1: keep the coordinates straight

Find the correct row using y. Only then choose x inside it. The same convention applies throughout this example.

Hint 2: the length of what?

The outer array contains rows, not individual columns. Read the column count from a row.

Next, you will protect the map from coordinates that do not identify any place.
