8.2 Check the boundary first

A radar can receive coordinates outside the map. These are not extra hidden cells. The program must first decide whether a place exists, and only then read its contents.

Four conditions for a rectangle

Open 08-grids/P05_Example_MapBoundary.java. Try x = 2, y = 1, then x = 3, y = 1.

/// # Worked example · 8.2 Check the boundary first
/// Lesson: 02-bounds.html

void main() {
    int[][] map = {{2, 0, 1}, {0, 3, 7}};
    int x = Integer.parseInt(IO.readln("X: ").strip());
    int y = Integer.parseInt(IO.readln("Y: ").strip());
    if (inside(map, x, y)) {
        IO.println("Value: " + map[y][x]);
    } else {
        IO.println("Outside");
    }
}

boolean inside(int[][] map, int x, int y) {
    return x >= 0 && x < map[0].length && y >= 0 && y < map.length;
}

The method inside returns a boolean. It needs four requirements to hold together: x is not negative, x is less than the number of columns, y is not negative, and y is less than the number of rows. AND combines all these requirements.

The highest valid coordinate is one less than the corresponding length. A map three cells wide has x from 0 to 2, not through 3. The exact upper boundary therefore uses less than, not less than or equal to.

The check in main happens before array access. Printing Outside does not require reading any cell. As before, we assume a nonempty rectangular grid; this helper does not handle rows of different lengths or a missing array.

Prediction: x = 0, y = -1

X is fine, but negative y rejects the whole selection. The result is Outside. Having only one valid coordinate is not enough.

Task: unlock the radar only inside the map

Open 08-grids/P06_Task_DroneRadar.java. The supplied main already uses inside to decide whether to show a signal. The helper currently rejects everything. Complete its rule using the actual dimensions of the array it receives; do not hard-code dimension numbers.

For 3, 1, expect Signal: 9; for 1, 0, expect Signal: 4. For 4, 1 and 0, 2, expect Outside. Also reject -1, 0 and 3, -1. Notice that the map is wider than it is tall: swapping the dimensions would break the right edge.

The method must not repair coordinates or move them to the nearest edge. It only answers whether they exist. An invalid selection must therefore not display another cell's contents.

Hint 1: write the bounds separately

For each coordinate, first write its lowest and highest allowed values. Then build the combined test.

Hint 2: dimensions of the supplied data

The outer array gives the row count. The length of its first row gives the width. You know both lengths from the previous lesson.

Next, similar checks will repeat for neighbouring cells. One correct helper can protect several different visits.
