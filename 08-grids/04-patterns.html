8.4 Vyrob vzor podle souřadnic

Vzor nemusíš ukládat jako dlouhý seznam ručně napsaných znaků. U šachovnice nebo rámečku může o každém místě rozhodnout malé pravidlo souřadnic. Změna velikosti pak sama vytvoří jinou mapu.

Vytvoř, naplň, zobraz

Otevři 08-grids/P18_CheckerTiles.java. Zadej velikost 3.

void main() {
    int size = Integer.parseInt(IO.readln("Size: ").strip());
    String[][] tiles = new String[size][size];
    for (int y = 0; y < size; y++) {
        for (int x = 0; x < size; x++) {
            if ((x + y) % 2 == 0) {
                tiles[y][x] = "#";
            } else {
                tiles[y][x] = ".";
            }
        }
    }
    show(tiles);
}

void show(String[][] tiles) {
    for (String[] row : tiles) {
        String line = "";
        for (String tile : row) {
            line += tile;
        }
        IO.println(line);
    }
}

Výraz new String[size][size] vytvoří čtvercovou mřížku. Textová místa zatím neobsahují naše symboly, proto každé z nich následně vyplníme. Vnější cyklus vybírá řádek y, vnitřní projde všechny jeho sloupce x. Pro každý nový řádek začíná x znovu od nuly.

Pravidlo střídá symbol podle parity součtu souřadnic. Na 0, 0 je součet sudý a vznikne #. Na 1, 0 lichý a vznikne tečka. Na 0, 1 je také tečka. Díky tomu se sousední řádky nezačínají stejným symbolem.

Pomocník show pouze zobrazuje hotová data. První for-each dostane celé řádky typu String[], druhý jednotlivé texty. Proměnná line začíná pro každý řádek prázdná a připojí jeho symboly. Tento výstup je textová mapa v Output, nikoli grafické okno.

Předpověď: velikost 2

Vzniknou tyto dva řádky:

#.
.#

Pro velikost 0 není žádná řada, takže za výzvou nic dalšího nepřibude. Příklad zkoušej pro velikosti 0 až 6.

Úkol: dutý panel

Otevři 08-grids/P19_HollowPanel.java. Doplň frame: každý okraj čtverce má být # a všechna vnitřní místa tečky. Metody main a show zůstávají hotové. Měň pravidlo pro jednotlivou buňku, nikoli ručně vypsané řádky.

Zkoušej velikosti 1 až 6. Pro 1 je celý výsledek jediný #. Pro 2 jsou oba řádky ##. Pro 4 čekej horní a dolní řadu #### a dvě prostřední řady #..#. Jediné místo velikosti 1 je současně všemi čtyřmi okraji.

Nápověda 1: čtyři možnosti okraje

Buňka je na okraji, pokud patří prvnímu nebo poslednímu řádku, případně prvnímu nebo poslednímu sloupci. Stačí jedna možnost.

Nápověda 2: poslední index

Poslední platný index je o jednu menší než velikost. Výplň musí dostat i ostatní buňky, jinak nezískají textový symbol.

Příště pravidlo nebude záviset jen na souřadnicích, ale na okolí v předchozím stavu mřížky.
