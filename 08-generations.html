8.5 Minulost čti, budoucnost zapisuj

Světelná mapa se mění v jednotlivých krocích. Všechny buňky mají reagovat na stejnou minulost. Kdybys už upravenou buňku použil pro výpočet jejího souseda, dostala by část mapy náskok.

Dva stavy místo přepisování při čtení

Otevři code/SignalShift.java. Podívej se na obě řady před posunem a po něm.

void main() {
    boolean[][] old = {{true, false, false, false}, {false, true, false, false}};
    boolean[][] next = shiftRight(old);
    IO.println("Old");
    show(old);
    IO.println("Next");
    show(next);
}

boolean[][] shiftRight(boolean[][] old) {
    boolean[][] next = new boolean[old.length][old[0].length];
    for (int y = 0; y < old.length; y++) {
        for (int x = 1; x < old[y].length; x++) {
            next[y][x] = old[y][x - 1];
        }
    }
    return next;
}

void show(boolean[][] board) {
    for (boolean[] row : board) {
        IO.println(Arrays.toString(row));
    }
}

Metoda shiftRight vytvoří nové pole next. Každé jeho místo od sloupce 1 čte hodnotu o sloupec vlevo v old. První sloupec zůstává false: to je počáteční hodnota nově vytvořeného boolean pole. Signál za pravým okrajem zmizí, nepřeskočí doleva.

Pravidlo old nikdy nepřepisuje. Metoda main proto může po výpočtu stále zobrazit původní řady. Dvě různá pole oddělují čtení minulosti a zápis budoucnosti. Říkáme tomu double buffering (dvojice oddělených stavů). Samotné nové jméno by nestačilo, jak už znáš z kopírování polí.

Předpověď: posuň výsledek ještě jednou

První řada bude [false, false, true, false], druhá [false, false, false, true]. Do dalšího volání předáš výsledek předchozího. Původní pole stále zůstane stejné.

Úkol: světlo se šíří jedním krokem

Otevři code/LightBloom.java. Zpočátku svítí jen střed třířádkové mapy. Doplň spread: v příštím stavu buňka svítí, pokud svítí nyní nebo má alespoň jednoho svítícího souseda vlevo, vpravo, nahoře či dole. Diagonála nestačí.

Vrať nové pole a původní neměň. Metoda main provede zadaný počet kroků a zobrazí Start i After. Pro 0 zůstane jediný střed. Po 1 vznikne kříž pěti true, rohy jsou false. Po 2 svítí všech devět míst. Zkoušej 0 až 3 kroky.

Připravené isOn bezpečně vrátí false za okrajem. Použij ho pro sousedy i vlastní buňku. Pravidlo není počet sousedů z předchozí lekce: tentokrát stačí jedna kladná odpověď. Propojíš tedy otázky pomocí OR.

Nápověda 1: rozliš vstup a výstup

Vytvoř nové boolean pole stejných rozměrů. Všechny otázky pokládej nad now, všechna přiřazení dělej do nového pole.

Nápověda 2: kontrola náskoku

Pokud po prvním kroku svítí roh, použil výpočet příliš čerstvou informaci nebo započítal diagonálu. Pokud se změnil výpis Start, přepisuješ minulost.

Teď už můžeš pro jiný svět zvolit jiné pravidlo buňky a zachovat stejný bezpečný způsob výpočtu dalších kroků.
