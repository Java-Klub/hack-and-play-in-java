11.4 Náhoda navrhuje, pravidlo rozhoduje

Kostka dává malé bitvě nejistotu. Náhodný hod a pravidlo převádějící jej na poškození jsou dvě různé práce. Oddělení dovolí ověřit pravidlo pro každou stěnu místo čekání na šťastný testovací běh.

Požádej jeden generátor o další hodnotu

void main() {
    Random random = new Random();
    int die = roll(random);
    IO.println("Roll: " + die);
    IO.println("Damage: " + damage(die));
}

int roll(Random random) {
    return random.nextInt(1, 7);
}

int damage(int die) {
    if (die <= 2) {
        return 0;
    }
    return die - 2;
}

Otevři 11-state/P17_DiceDamage.java a spusť jej několikrát. New Random() vytvoří pseudorandom generator (generátor zdánlivě náhodných čísel): objekt tvořící posloupnost hodnot. Uchovává vnitřní stav, takže další požadavek pokračuje v posloupnosti místo opakování pevné odpovědi.

NextInt(1, 7) zahrnuje dolní mez 1 a vylučuje horní mez 7: možné výsledky jsou 1 až 6. Na mezích záleží. NextInt(1, 6) by nikdy nehodilo 6. Opakované hody mohou být stejné; náhodnost neslibuje pokaždé jiný výsledek.

Generátor se předává jako parametr roll. Pravidlo damage dostane jen výsledné int: stěny 1 a 2 minou, vyšší způsobí hodnotu stěny minus 2. Toto pravidlo nepotřebuje Random, vstup ani výpis, proto jej můžeš volat se záměrně vybranými argumenty.

Předpověz pravidlo, ne hod

Pokud je Roll 5, Damage musí být 3. Jaké poškození patří ke 2? Nula. Ze samotné této obrazovky nemůžeš poctivě předpovědět další hod, ale můžeš předpovědět správnou reakci na libovolný daný hod.

Úkol: hoď skutečnou dvojicí

Otevři 11-state/P18_DoubleDice.java. Rozšiř rollPair z jedné kostky na součet dvou samostatných šestistěnných hodů. Dodaný generátor požádej dvakrát, ulož obě hodnoty stěn a vrať jejich součet. Uvnitř pomocné metody další generátor nevytvářej.

Každý výsledek musí ležet od 2 do 12. Stejné stěny jsou povolené. Jediný rovnoměrný výběr od 2 do 12 je jiný pokus: u dvou kostek má 7 více kombinací než 2. Krátký běh nemusí ukázat každý možný součet.

Nápověda 1: počítej náhodné požadavky

Zdvojnásobení jedné hozené stěny by dalo jen sudé součty. Dvě volání dodají dva postupné vzorky, které mohou být i stejné.

Nápověda 2: zachovej generátor

Převezmi generátor v parametru a používej jej. Jeho životnost určuje volající; pomocná metoda si vyžádá pouze potřebné vzorky.

Příště dáš generátoru počáteční seed (semeno), aby šlo překvapivou posloupnost přesně zopakovat a sdílet jako opakovatelnou hádanku.
