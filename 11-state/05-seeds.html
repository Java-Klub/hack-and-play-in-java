11.5 Stejný začátek, stejný pokus

Náhodné bludiště může vytvořit zvláštní trasu, kterou chceš někomu ukázat. Seed (počáteční semeno) dovolí zopakovat stejný pokus místo popisování zpaměti. Opakovatelnost je užitečná pro sdílení výzev i pro zkoumání nečekaného výsledku programu.

Semeno zahájí posloupnost; není každou odpovědí

/// # Hotový příklad · 11.5 Stejný začátek, stejný pokus
/// Lekce: 05-seeds.html

void main() {
    int[] first = sequence(42);
    int[] replay = sequence(42);
    IO.println("First: " + Arrays.toString(first));
    IO.println("Replay: " + Arrays.toString(replay));
    IO.println("Same: " + Arrays.equals(first, replay));
}

int[] sequence(int seed) {
    Random random = new Random(seed);
    int[] values = new int[4];
    for (int i = 0; i < values.length; i++) {
        values[i] = random.nextInt(10);
    }
    return values;
}

Otevři 11-state/P20_Example_ReplayNumbers.java. New Random(seed) zahájí generátor z určeného počátečního stavu. Konstruktor přijímá celé číslo long; naše int seed se na tento typ automaticky rozšíří bez ztráty hodnoty. Generátor nepotřebuje žádnou zvláštní hodnotu semene, aby fungoval.

Jeden generátor vznikne před smyčkou. NextInt(10) dodá hodnotu od 0 do 9 a posune jeho stav. Čtyři volání proto pokračují v jedné posloupnosti. Arrays.toString zobrazí prvky; Arrays.equals ověří jejich hodnoty místo totožnosti polí.

Dvojí volání sequence(42) vytvoří dva generátory se stejným začátkem i stejnými požadavky, proto oba vytvoří [0, 3, 8, 4]. Samotné semeno není celý recept: změna mezí, přidání náhodného volání nebo změna pořadí může změnit pozdější výsledky.

Předpověz restartovaný generátor

Kdyby nový Random(42) vznikal před každým vzorkem, všechny čtyři hodnoty by byly 0. Proč? Každý generátor by provedl jen první požadavek ze stejného počátečního stavu. Jakou hodnotu vrátí další nextInt(10) po prvním volání při používání jednoho generátoru? 3.

Úkol: oprav opakovatelnou trasu dveří

Otevři 11-state/P21_Task_ReplayDoors.java. Každá trasa má použít jeden generátor pro čtyři postupná čísla dveří od 1 do 6. Oprav jeho životnost: každá trasa začne z dodaného semene, ale jednotlivé dveře pokračují v posloupnosti této trasy. Zachovej obě volání v main.

Pro semeno 42 očekávej [3, 4, 1, 3]; pro semeno 0 očekávej [1, 5, 2, 6]. Obě musejí hlásit Replay matches: true. Opakované dveře v trase jsou povolené. Jiné semeno nemusí vytvořit jiné hodnoty na každé pozici.

Nápověda 1: najdi restart

Najdi místo provedení new Random. Rozhodni, zda má proběhnout jednou pro trasu, nebo jednou pro dveře.

Nápověda 2: ponech stav místní jedné trase

Vytvoř generátor uvnitř route, ale mimo její smyčku. Sdílení jednoho generátoru mezi oběma voláními route by pokračovalo v posloupnosti místo jejího zopakování.

Nyní umíš volit mezi neměnnými snímky dat, rostoucími kolekcemi a objekty se stavem. Příště tyto nástroje použiješ k uspořádání interaktivních programů, jejichž události nastávají v čase.
