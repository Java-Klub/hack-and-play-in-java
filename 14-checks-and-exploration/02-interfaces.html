14.2 Skládej objekty podle jejich chování

Volající může požádat o pozdrav, aniž by věděl, který objekt pozdravu dostane. Interface (rozhraní) pojmenuje potřebné chování. Record (datový záznam) může toto chování dodat a nést přitom vlastní malou část dat.

14-checks-and-exploration/P08_GreetingRoles.java

interface Greeting {
    String message(String name);
}

record Welcome(String prefix) implements Greeting {
    public String message(String name) {
        return prefix + ", " + name + "!";
    }
}

String greet(Greeting greeting, String name) {
    return greeting.message(name);
}

void main() {
    Greeting greeting = new Welcome("Hello");
    IO.println(greet(greeting, "Nova"));
    IO.println(greet(new Welcome("Welcome"), "Mika"));
}

Greeting deklaruje method signature (podpis metody) zakončený středníkem: implementace musí dodat message s jedním parametrem String a výsledkem String. Tato deklarace nemá tělo.

Implements připojí Welcome k této smlouvě. Implementovaná metoda je public (veřejná), protože operace rozhraní jsou veřejné. Record dál dodává známý konstruktor a přístup k prefix. Samotné rozhraní nelze vytvořit pomocí new.

Proměnná deklarovaná jako Greeting může odkazovat na Welcome. Volání message použije implementaci skutečného objektu. Pomocné greet závisí na slíbeném chování, nikoli na jednom konkrétním typu záznamu.

Předpověz jinou hodnotu implementace

První volání vrátí Hello, Nova!, druhé Welcome, Mika!. Co vrátí greet(new Welcome("Ahoy"), "Sol")? Volající kvůli tomuto prefixu nepotřebuje novou větev.

Úkol: sestav dvě pravidla pro slovo

Dokonči 14-checks-and-exploration/P09_RuleGate.java na dvou místech. Both smí přijmout slovo jen tehdy, když je přijmou obě obsažená pravidla. Potom zapoj do gateRule Both obsahující Minimum(4) a NotWord("robot").

Po odstranění okrajových mezer volajícím je moon povoleno, cat je příliš krátké a robot zakázané bez ohledu na velikost písmen. Prázdný vstup je příliš krátký. Jednotlivá pravidla zachovej použitelná samostatně; nevkládej jeden zvláštní spojený vzorec do main.

Both obsahuje dva odkazy Rule: jde o composition (skládání). Předá otázky obsaženým objektům a spojí jejich odpovědi. Obsažené pravidlo může být také další Both; větší pravidlo tak nevyžaduje změnu volající části.

Nápověda 1: obě znamená víc než kterákoli

Vyber logický operátor, který slovo odmítne, jakmile je odmítne kterékoli obsažené pravidlo.

Nápověda 2: připoj složené pravidlo k programu

Oba dílčí záznamy vytvoř uvnitř nového Both vraceného z gateRule. Opravené, ale nepoužité Both nemůže změnit tento vstupní program.

Obnov dočasnou roli pomocí finally

Pokus někdy dočasně nahradí uloženou roli. Ke Greeting, Welcome a greet z vypracovaného příkladu přidej tento field (uloženou hodnotu objektu) a pomocnou metodu:

Greeting active = new Welcome("Hello");

String preview(Greeting temporary, String name) {
    Greeting previous = active;
    try {
        active = temporary;
        return greet(active, name);
    } finally {
        active = previous;
    }
}

První následující volání vrátí Ahoy, Nova!; druhé dá Hello, Nova!, protože active znovu odkazuje na původní Welcome. Vrácená hodnota se vypočítá předtím, než finally obnoví starý odkaz. Pro pokus nahraď dvě tisková volání v main příkladu:

IO.println(preview(new Welcome("Ahoy"), "Nova"));
IO.println(greet(active, "Nova"));

Finally (závěrečné zpracování) se provede při běžném opuštění try, při return i kvůli výjimce. Výjimku samo nezachytí: po úklidu selhání dál putuje k volajícímu, který je může zachytit. Obnovu nech ve finally, aby úspěšný i neúspěšný pokus obnovily stejnou roli.

Dále použiješ jiný druh rozhraní: záměrně uzavřenou rodinu datových variant, kterou switch dokáže úplně prozkoumat.
