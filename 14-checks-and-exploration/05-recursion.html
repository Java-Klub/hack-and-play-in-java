14.5 Prozkoumej menší problémy a volby

Recursive method (rekurzivní metoda) řeší problém voláním sebe sama pro menší problém. Potřebuje base case (základní případ), který odpoví hned, a krok, který se k němu přibližuje. Nejprve přečti celé pravidlo a potom sleduj jednotlivá volání.

14-checks-and-exploration/P24_Example_RecursiveSum.java

/// # Hotový příklad · 14.5 Prozkoumej menší problémy a volby
/// Lekce: 05-recursion.html

int sumTo(int number) {
    if (number == 0) return 0;
    return number + sumTo(number - 1);
}

void main() {
    String reply = IO.readln("Steps: ");
    if (reply == null) return;
    try {
        int number = Integer.parseInt(reply.strip());
        if (number < 0 || number > 12) {
            IO.println("Use 0..12.");
            return;
        }
        IO.println("Sum: " + sumTo(number));
    } catch (NumberFormatException failure) {
        IO.println("Use a whole number.");
    }
}

Pro trojku Java potřebuje 3 + sumTo(2). Toto volání potřebuje 2 + sumTo(1), potom 1 + sumTo(0). Nulové volání vrátí nulu a čekající volání postupně vrátí jedna, tři a nakonec šest.

Každé nedokončené volání zabírá místo na stack (zásobníku). Tento součet potřebuje čas i místo na zásobníku úměrné vstupu; smyčka jej spočítá s konstantním dodatečným místem. Kontrola vstupu drží tento malý pokus v mezích. Rekurze se hodí zvlášť tehdy, když se problém přirozeně větví.

Předpověz zastavení

SumTo(0) vrátí nulu bez dalšího volání. SumTo(1) vrátí jedna. Co vrátí sumTo(4) a který argument dojde k základnímu případu?

Operace String endsWith porovnává přesný konec textu: "STAR".endsWith("R") je true, zatímco "STAR".endsWith("S") je false. Na velikosti písmen záleží. Prázdný text nekončí na R. Co vrátí "MOON".endsWith("ON")?

Úkol: prozkoumej každý dovolený kód trasy

V 14-checks-and-exploration/P25_Task_RouteCodes.java trasa obsahuje L a R, ale dva kroky R za sebou jsou zakázané. Dokonči build tak, aby prozkoumalo obě volby v pořadí nejprve L a shromáždilo každý platný kód požadované délky právě jednou.

Délka dva musí vypsat [LL], [LR], [RL] a počet tři. Délka nula má jednu platnou prázdnou trasu vypsanou jako []; neznamená to žádné trasy. Přijímají se pouze délky nula až osm.

Jde o malý backtracking search (prohledávání s návratem): vyber další krok, prozkoumej jeho dokončení, vrať se a zkus druhou volbu. Texty jsou neměnné, takže každá větev dostane nový prefix a starý nepotřebuje vracet. Hledání na měnitelném plánu by muselo změněné buňky obnovovat.

Nápověda 1: dokonči před větvením

Zachovej případ nulového remaining i jeho return. Každá rekurzivní volba musí od remaining odečíst jedna.

Nápověda 2: vynech jen zakázanou volbu

L je vždy možným dalším písmenem. Větev R přidej jen tehdy, když prefix nekončí na R.

Dvě volby na pozici mohou vytvořit exponenciálně mnoho kandidátů: neomezená horní mez je dvě na délku. Prořezání strom zmenší, ale uložený výstup stále rychle roste. Zachovej mez a před většími případy ověř drobné. Teď máš prostředky pro tvorbu, zkoumání a ověřování vlastních malých programů.
