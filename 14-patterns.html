14.3 Ask which kind of data arrived

A stage instruction might contain spoken text or a pause duration. Store each kind with only the data it needs. A sealed interface lists the permitted variants; a pattern switch can then handle each one explicitly.

sealed interface Message permits Text, Pause {}
record Text(String words) implements Message {}
record Pause(int seconds) implements Message {}

String describe(Message message) {
    return switch (message) {
        case null -> "No message";
        case Text text -> "Say " + text.words();
        case Pause(var seconds) -> "Wait " + seconds + "s";
    };
}

void main() {
    IO.println(describe(new Text("Hello")));
    IO.println(describe(new Pause(2)));
    IO.println(describe(null));
}

The permits list closes this direct family to Text and Pause. Both records implement Message. Because their data shapes differ, callers cannot accidentally give a spoken sentence to Pause’s int constructor parameter.

case Text text is a type pattern: it checks the kind and binds the whole object as text. Its accessor words() reads a component. case Pause(var seconds) is a record pattern: it recognises the record and binds its component directly.

The compiler derives the local seconds type from the record declaration. The component position matters; the local name does not search for a similarly named field. A null input matches the explicit null case instead of a record.

All permitted variants are covered, so no catch-all default is needed. Adding another permitted variant makes this switch require a corresponding branch. This catches forgotten cases during compilation instead of hiding them behind a generic message.

Predict misleading local names

For a Light record declared as Light(String colour, int seconds), a pattern written Light(var seconds, var colour) would bind the first name to the text and the second to the number. For Light("red",5), what values do those two names receive?

The misleading name seconds receives red; colour receives five. Names document roles, but position determines the binding.
