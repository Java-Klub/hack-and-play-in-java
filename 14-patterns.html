14.3 Zjisti, která datová varianta přišla

Jevištní pokyn může obsahovat mluvený text nebo délku přestávky. Každý druh ulož jen s daty, která potřebuje. Sealed interface (uzavřené rozhraní) vyjmenuje dovolené varianty; pattern switch (výběr podle vzoru) potom každou výslovně zpracuje.

sealed interface Message permits Text, Pause {}
record Text(String words) implements Message {}
record Pause(int seconds) implements Message {}

String describe(Message message) {
    return switch (message) {
        case null -> "No message";
        case Text text -> "Say " + text.words();
        case Pause(var seconds) -> "Wait " + seconds + "s";
    };
}

void main() {
    IO.println(describe(new Text("Hello")));
    IO.println(describe(new Pause(2)));
    IO.println(describe(null));
}

Seznam permits uzavírá tuto přímou rodinu na Text a Pause. Oba záznamy implementují Message. Jejich datové tvary se liší, takže volající nemůže omylem předat mluvenou větu parametru int konstruktoru Pause.

case Text text je type pattern (typový vzor): ověří druh a celý objekt pojmenuje text. Přístup words() čte jednu složku. case Pause(var seconds) je record pattern (vzor záznamu): rozpozná záznam a jeho složku přímo pojmenuje.

Překladač odvodí místní typ seconds z deklarace záznamu. Rozhoduje poloha složky; místní jméno nehledá podobně pojmenované pole. Vstup null odpovídá výslovné větvi null, nikoli záznamu.

Všechny povolené varianty jsou pokryté, takže není potřeba všeobecné default. Přidání další povolené varianty vyžádá odpovídající větev i zde. Zapomenutý případ se tak odhalí při překladu místo ukrytí za obecnou zprávu.

Předpověz zavádějící místní jména

Pro záznam deklarovaný jako Light(String colour, int seconds) by vzor Light(var seconds, var colour) navázal první jméno na text a druhé na číslo. Jaké hodnoty dostanou tato dvě jména pro Light("red",5)?

Zavádějící jméno seconds dostane red a colour dostane pět. Jména dokumentují role, ale navázání určuje poloha.

Úkol: oprav popis pokynu

Dokonči code/CueBoard.java. Implementuj timed tak, aby spojilo popisek, for , délku a s. Použij je z obou nenulových větví describe. Barvu a délku zachovej v jejich správných rolích.

Modré světlo na tři sekundy musí popsat Light blue for 3s; dvousekundový klid dá Rest for 2s; null dá No cue. Ověř také jinou barvu a klid s nulovou délkou.

Nápověda 1: sleduj deklaraci záznamu

Před sestavením popisku přečti složky zleva doprava.

Nápověda 2: jedno pravidlo sestavení

Předej hotový popisek Light nebo Rest a číselnou délku do timed; společný konec nech přidat tuto pomocnou metodu.

Dále procvičíš vyčlenění opakované operace se zachováním chování běžícího programu.
