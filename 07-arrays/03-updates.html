7.3 Change the actual place

A panel has several lights. Here, a number typed into Output stands in for a click: the selected light should switch state while the others stay unchanged. Changing a working copy of a value is not enough.

Square brackets on both sides

Open 07-arrays/P10_ChargeSlot.java. Enter slot 1.

void main() {
    int[] charges = {2, 5, 1};
    int slot = Integer.parseInt(IO.readln("Slot: ").strip());
    if (slot >= 0 && slot < charges.length) {
        charges[slot] = charges[slot] + 2;
    } else {
        IO.println("Invalid slot");
    }
    IO.println(Arrays.toString(charges));
}

The expression on the right reads the selected place's old value and adds two. The statement charges[slot] = charges[slot] + 2; stores the result back in that place. The state 2, 5, 1 becomes 2, 7, 1.

The method Arrays.toString(charges) provides readable text containing all the values and square brackets. We use it only for display; it makes no changes. Its result is useful for comparing the state before and after a move.

For a numeric array, assigning to the variable power inside for-each would change only that local variable. To write to a particular element, you need the array itself and its index. That is why the program checks the selected index first.

Prediction: slot -1

It prints Invalid slot, followed by the unchanged [2, 5, 1]. A rejected choice performs no assignment to the array.

Task: a light switch

Open 07-arrays/P11_LightSwitch.java. All four lights start off. For a valid slot, change only the selected light to the opposite boolean value. This makes the same step able to switch a light both on and off.

For slot 2, expect [false, false, true, false]. For 0, only the first value should be true; for 3, only the last. For -1 or 4, print Invalid slot followed by four false values. An invalid choice must not change any other light either.

After fixing it, change the second starting light to true and enter 1. It must switch off. Then restore the original starting array. This experiment distinguishes toggling from simply assigning true.

Hint 1: the opposite answer

You already know NOT from conditions. It turns true into false and false into true.

Hint 2: the assignment target

Store the result in the element at the chosen index, not in the slot number or the whole variable lights.

Next, the player will not know the required index. You will write a search that chooses the right place by its contents.

Practise in a game

  • Chopsticks · 07-arrays/P12_Chopsticks.java
    Chopsticks must validate both indices before looking up both living hands. HandsAlive only answers; it does not add fingers.
  • WordleStyleWordHunt · 07-arrays/P13_WordleStyleWordHunt.java
