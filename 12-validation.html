12.1 Rozhodni, které hodnoty dávají smysl

Stroj může úspěšně přečíst číslo a přesto dostat nesmyslný požadavek. Záporný počet lístků je číslo, ale nepopisuje platnou rezervaci. Conversion (převod) a validation (ověření přípustnosti) jsou dvě různé otázky.

Otevři příklad a zadej 4, potom 0. Při tomto prvním pokusu pokaždé napiš celé číslo. Odpověďmi, které čísla nejsou, se zabývá následující lekce.

boolean allowed(int players) {
    return players >= 1 && players <= 4;
}

void main() {
    String reply = IO.readln("Players: ");
    if (reply == null) return;
    int players = Integer.parseInt(reply.strip());
    if (allowed(players)) {
        IO.println("Ready for " + players + " players.");
    } else {
        IO.println("Use 1..4 players.");
    }
}

parseInt změní podobu hodnoty z textu na int. Pravidla hry nezná. Samostatná metoda allowed se ptá, zda číslo patří do povoleného intervalu.

Oba konce patří dovnitř: >= přijme dolní mez a <= horní. Metoda vrací odpověď, aniž by rezervovala hráče nebo měnila uložený stav. Volající část rozhodne, co s odpovědí udělá.

Předpověz obě meze

Co vrátí allowed(1), allowed(4) a allowed(5)?

Vrátí true, true a false. Teď před spuštěním předpověz výsledek pro -1.

Pro energii nula a cenu jedna je otázka dostatečné kapacity nepravdivá, přestože samostatné požadavky na znaménka platí. Pro dva a dva projdou všechny požadavky. Sleduj odmítnutý požadavek, aniž bys měnil kterýkoli parametr.

Úkol: zavři cestu k energii zdarma

Otevři code/EnergyPermit.java. Zadej dvě celá čísla oddělená mezerou: dostupnou energii a požadovanou cenu. Oprav allowed: energie nesmí být záporná, cena musí být alespoň jedna a musí se vejít do dostupné energie.

Zkus 5 5, 5 6, 5 0, 5 -2 a -1 1. Povolený je pouze první požadavek. Připravené rozdělení vstupu přečte obě hodnoty; měň pravidlo, nikoli zadaná data.

Nápověda 1: odděl požadavky

Napiš tři otázky s odpovědí ano/ne. Levný požadavek ještě automaticky není přípustný požadavek.

Nápověda 2: platí všechny požadavky

Spoj tři porovnání pomocí &&. Cenu porovnej s parametrem energy, nikoli s pevným číslem z ukázky.

Jiný vadný vstup, například slovo místo celého čísla, selže ještě před tímto pravidlem. Dále odlišíš takové selhání od obyčejného zamítnutí.
