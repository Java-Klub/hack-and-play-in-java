6.4 Zastav na prvním nálezu

Radar prochází očíslované okamžiky. První vhodný signál mu stačí: nechce poslední signál ani počet všech signálů. To mění okamžik, kdy lze práci ukončit.

Nález a předčasný konec

Otevři code/RadarWindow.java. Limit 7 dovolí zkoušet okamžiky 1 až 7.

void main() {
    int limit = Integer.parseInt(IO.readln("Limit: ").strip());
    int found = -1;
    for (int moment = 1; moment <= limit; moment++) {
        if (moment % 4 == 0) {
            found = moment;
            break;
        }
    }
    if (found == -1) {
        IO.println("None");
    } else {
        IO.println("Signal: " + found);
    }
}

Proměnná found začíná na -1. Tento sentinel (zástupná hodnota) zde znamená „nenalezeno“, protože skutečné kandidáty vybíráme jen od 1 výš. Při nalezení násobku čtyř se uloží jeho číslo a break (ukončení cyklu) ihned opustí nejbližší cyklus.

Za break už se v tomto kole nic dalšího neprovede a neproběhne ani posun počítadla. Program ale nekončí: pokračuje výpisem za cyklem. Return by naproti tomu ukončil celé nynější volání metody, jak už znáš.

Pro limit 7 se vyzkouší 1, 2, 3 a 4. U čtyřky hledání skončí. Pro limit 3 neprojde žádný kandidát a found zůstane -1. Tak rozlišíš „nenalezeno“ od běžného výsledku bez zvláštního výpisu uvnitř každého kola.

Předpověď: limit 12 bez break

Každý další násobek přepíše found. Na konci by tam bylo 12 místo prvního nálezu 4. Samotné přiřazení tedy hledání nezastaví.

Úkol: první měsíční okno

Otevři code/MoonWindow.java. Program hledá včetně obou zadaných mezí. Vhodné číslo je dělitelné třemi a zároveň liché. Zatím si pamatuje poslední vhodné číslo; změň ho, aby vrátil první.

Zkoušej meze od 0 do 30, start nejvýše end. Pro 3 až 15 čekej Window: 3, pro 4 až 11 Window: 9. Rozsah 3 až 3 obsahuje platný jediný prvek. Rozsah 10 až 10 nemá řešení a vypíše None.

Nápověda 1: nepoškoď pravidlo

Podmínka už rozpoznává správné kandidáty. Problém je v tom, co se stane po prvním úspěšném přiřazení.

Nápověda 2: co má skončit?

Potřebuješ opustit průchod, ale zachovat konečný výpis z main. Porovnej význam break a return.

V další lekci bude cyklus čekat na hráčovy povely. Jeho konec pak nebude určovat číslo poslední návštěvy, ale zvláštní povel.
